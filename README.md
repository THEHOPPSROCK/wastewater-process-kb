# 污水处理工艺知识库 · SLUDGE-TECH DATABASE // 2077

> 站点/看板品牌名为「污泥处理工艺知识库」。内容覆盖污水处理全流程，污泥处理处置是其中 1 个工艺族（4 个大类）。仓库名 `wastewater-process-kb` 即按此内容口径取名。

一个把污水处理工艺体系按「化学元素周期表」范式重新组织的可视化知识库：**37 个工艺大类、171 个变种分支、104 条设计计算公式**，覆盖自 1840s 土地处理系统到 2015 年 AOA（厌氧-好氧-缺氧）工艺的完整演进脉络。

## 在线预览

- 站点：见仓库的 **GitHub Pages** 地址（或另行发布的托管链接）
- 站点为纯静态页面，**数据已内嵌为 JS，可完全离线运行**——直接双击 `site/index.html` 即可打开，无需服务器、无需联网。

## 站点特性

- **工艺周期表**：横轴 = 9 个工艺族（family），纵轴 = 8 个诞生年代段（era）。每个格子是一张工艺卡片，卡片上的 `St`、`Ca`、`An` 等「元素符号」由程序按英文名自动生成，保持全局唯一。
- **三级钻取**：周期表卡片 → 大类抽屉（定位 / 简介 / 文献来源 / 变种清单）→ 变种弹窗（SVG 工艺流程图 + 设计参数 + 适用场景 + 优缺点）。
- **公式手册**：10 章 65 条精选设计公式，含符号表、取值范围与规范出处（如 GB 50014-2021）。
- **语义化配色**：成熟度 4 档（成熟经典 / 成熟主流 / 商业化初期 / 前沿研发）、流程线型 4 类（水线 / 污泥线 / 回流线 / 辅助线）、工艺族 9 色。
- **深链分享**：支持 `#view=formulas`、`#cat=<大类id>`、`#var=<大类id>:<变种id>`，可直接定位到某个具体变种。
- 原生 HTML + CSS + ES6，无框架、无构建步骤。

## 本地运行

```bash

#   双击 site/index.html

cd site && node server.js --port 7100

```

## 维护工作流

**`site/data/processes.json` 是唯一权威数据源**，`kb/processes/*.md` 与 `site/data/processes.js` 都是生成物，请勿手改。

```bash
# 改完 JSON 后依次执行：
python3 site/tools/embed_data.py   # 同步到网页（生成 site/data/*.js）
python3 build_kb.py                # 同步到 Markdown（生成 kb/processes/*.md）
```

新增大类或变种时，除上述两步外还需同步三处计数基准：`kb/README.md`（总览 / 分类树 / 按族汇总）、`README-使用说明.md`（数据规模）、`site/js/app.js` 顶部的 `EXPECTED` 常量。完整清单见 `kb/README.md` 的「使用说明」。

## 重要提示

- 所有设计参数均为**文献与厂商资料中的典型范围**，仅作快速参考。**工程设计必须按项目水质、现行规范与厂商数据复核**。
- 年份存在多源分歧的条目，已在 `kb/README.md` 的「交叉审核结论摘要」中双注口径；仍有单源未核实的条目列在「仍存疑条目」中，使用时请注意。
- 各条目附有来源列表，可追溯至原始文献或工程报道。
