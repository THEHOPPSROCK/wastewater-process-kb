## 预处理与一级处理 | Preliminary & Primary Treatment
- 诞生: 约 1840s–1900s（英国/美国；污水沉淀与化学沉淀于 19 世纪中叶起用于伦敦等城市；1904 年美国建成首个沉砂池）
- 成熟度: 成熟
- 定位: 所有污水处理厂的前置屏障，去除砂砾、悬浮物，保护后续生化单元
- 简介: 预处理包括格栅（筛除粗大漂浮物）、沉砂池（去除比重大的无机砂粒）与初次沉淀池（重力沉降去除可沉固体，SS 去除率 50–70%、BOD 去除率 25–40%）。化学强化一级处理（CEPT）在初沉前投加铁盐/铝盐与聚合物，将 SS 去除率提高到 80% 以上、TP 去除率 70–90%。化学沉淀在英国 19 世纪下半叶已有实践；现代 CEPT 于 1960s 由 DOW 化学等推动、1980s 在北美与北欧大规模应用（如 1997 年香港昂船洲，40 m³/s，世界最大 CEPT）。初沉污泥进入污泥线处理。
- 来源: https://digitalcommons.memphis.edu/cgi/viewcontent.cgi?article=2741&context=etd ; https://www.irjet.net/archives/V2/i8/IRJET-V2I8161.pdf ; https://www.epd.gov.hk/eia/register/report/eiareport/eia_1452008/EIA%20Study%20Report/pdf/Appendix/App%202-1.pdf

### 变种: 格栅与筛网 | Bar Screens & Fine Screens
- 年份: 约 1884（美国首次使用格栅）
- 差异点: 纯物理截留，粗格栅（间隙 50–100 mm）→ 细格栅（6–25 mm）→ 精细筛网（1–6 mm）分级
- 流程步骤: 进水 → 粗格栅（栅渣外运）→ 提升泵房 → 细格栅（栅渣压榨外运）→ 沉砂池 → 初沉池 → …（污泥线：栅渣脱水→填埋）
- 设计参数: 过栅流速 0.6–1.0 m/s; 栅前水深 0.5–1.0 m; 水头损失 0.1–0.3 m
- 适用: 一切市政/工业污水厂的头部单元
- 优点: 构造简单；保护水泵与后续设备；维护成熟
- 缺点: 栅渣恶臭需密闭处理；细格栅易堵塞、需反冲洗

### 变种: 沉砂池 | Grit Chamber
- 年份: 约 1904（美国首批沉砂池）
- 差异点: 只去除无机砂粒而保留有机悬浮物；分平流式、曝气沉砂池（1920s 起）、旋流/涡流沉砂池（1960s 起）
- 流程步骤: 格栅出水 → 沉砂池（曝气或旋流）→ 砂水分离器 → 砂外运填埋；水 → 初沉池
- 设计参数: 平流式 HRT=30–60 s，流速 0.15–0.3 m/s; 曝气沉砂 HRT=2–5 min，曝气量 0.1–0.2 m³空气/m³水
- 适用: 合流制/砂量大的城市污水厂必备
- 优点: 保护泵与消化池不积砂；占地小
- 缺点: 砂含水与有机质，处置易臭；曝气沉砂略增能耗

### 变种: 初次沉淀池 | Primary Clarifier
- 年份: 约 1860s–1890s（英美化粪/沉淀池演化而来；1904 Travis 双层池、1905–06 Imhoff 双层沉淀池为代表工程化节点）
- 差异点: 纯重力沉淀，不加药；去除可沉固体并撇除浮渣，削减二级负荷
- 流程步骤: 沉砂出水 → 初沉池（辐流/平流，HRT 1.5–2.5 h）→ 初沉出水去二级生化；初沉污泥 → 浓缩/消化；浮渣 → 处置
- 设计参数: 表面负荷 q=1.5–3.0 m³/(m²·h)（高峰 4–5）; HRT=1.5–2.5 h; SS 去除 50–70%; BOD 去除 25–40%
- 适用: 大中型市政污水厂；二级处理前的标准配置
- 优点: 显著节能（削减曝气负荷）；产初沉污泥可消化产沼气
- 缺点: 占地大；低碳源污水削弱下游反硝化碳源

### 变种: 化学强化一级处理 CEPT | Chemically Enhanced Primary Treatment
- 年份: 化学沉淀 19 世纪下半叶（英国）；现代 CEPT 约 1960s（DOW 化学中试）→ 1970s 北欧、1985 加州 Point Loma/Hyperion、1997 香港昂船洲
- 差异点: 初沉前投加 FeCl₃/铝盐+聚合物，絮凝沉淀去除胶体与溶解态磷，取消或简化二级生化
- 流程步骤: 进水 → 格栅 → 沉砂 → 快速混合（投 FeCl₃ 10–50 mg/L）→ 絮凝（聚合物 0.1–1 mg/L）→ 初沉池（高负荷或斜板）→ 出水（或接二级/消毒）→ 化学污泥 → 浓缩 → 消化/脱水 → 处置
- 设计参数: q=3–8 m³/(m²·h)（斜板/Actiflo 更高）; FeCl₃ 10–50 mg/L; 聚合物 0.1–1 mg/L; TSS 去除 80–90%; TP 去除 70–90%; BOD 去除 50–70%
- 适用: 用地紧张的大型厂、合流制溢流处理、一级 A 提标前段、海水排放前置处理
- 优点: 占地小、抗冲击、除磷高效；碳源导向（carbon redirection）利于产能
- 缺点: 药耗与化学污泥量大；污泥难脱水；长期运行费高

## 传统活性污泥法及其负荷/流态变型 | Conventional Activated Sludge & Loading/Flow Variants
- 诞生: 1914（英国曼彻斯特，Edward Ardern & William T. Lockett，导师 Gilbert J. Fowler；1914-04-03 在曼彻斯特宣读经典论文；1916 年美国 Texas San Marcos 首座活性污泥厂）
- 成熟度: 主流（全球最广泛应用的二级生物处理工艺）
- 定位: 悬浮生长好氧生物处理的母工艺，一切活性污泥变型的基础
- 简介: 污水与回流活性污泥在曝气池中混合曝气，好氧微生物将有机物氧化为 CO₂ 与细胞物质，硝化菌将氨氮氧化为硝酸盐；混合液在二沉池泥水分离，污泥大部分回流、少量作为剩余污泥排出。核心参数为 SRT（泥龄）、F/M（食微比）与回流比。1914 年发明后迅速扩散，衍生出推流、完全混合、阶段曝气、接触稳定、延时曝气等一系列负荷与流态变型。
- 来源: https://www.iwa-network.org/news/call-for-nominations-for-mewe-sg-awards-ardern-lockett-award-2025-early-and-mid-career-awards-2025/ ; https://civilengineering.softecks.in/1070/ ; https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf

### 变种: 传统推流式活性污泥法 | Conventional Plug-Flow Activated Sludge
- 年份: 1917（美国 Lawrence 实验站发展出推流池型）
- 差异点: 狭长廊道池、水流推流前进，沿程污染物浓度递减、需氧前高后低
- 流程步骤: 进水 → 格栅 → 沉砂池 → 初沉池 → 曝气池（推流廊道，鼓风曝气）→ 二沉池 → 消毒 → 出水；二沉污泥 → 回流污泥泵房（RAS 回流至曝气池首端）/ 剩余污泥 WAS → 浓缩 → 消化 → 脱水 → 处置
- 设计参数: HRT=4–8 h; SRT=5–15 d; F/M=0.2–0.4 kgBOD/(kgMLVSS·d); MLSS=1500–3000 mg/L; 回流比 R=25–75%; 二沉池表面负荷 1.0–1.5 m³/(m²·h)
- 适用: 大中型市政污水厂、水质水量较稳定场景
- 优点: 出水水质好（可硝化）；处理效率高；运行经验丰富
- 缺点: 首端需氧集中易缺氧；抗冲击负荷差；占地大

### 变种: 完全混合式活性污泥法 | Completely Mixed Activated Sludge (CMAS)
- 年份: 约 1927（为应对高浓度/有毒工业废水冲击而发展；1960 年 McKinney 系统化理论）
- 差异点: 入流迅速与全池混合液均匀混合，池内各点浓度一致，抗冲击负荷强
- 流程步骤: 进水 → 预处理 → 完全混合曝气池（机械表曝或鼓风曝气）→ 二沉池 → 消毒 → 出水；RAS 回流 / WAS 排放至污泥线
- 设计参数: HRT=3–6 h; SRT=5–15 d; F/M=0.2–0.6 kgBOD/(kgMLVSS·d); MLSS=2000–4000 mg/L; R=50–100%
- 适用: 工业废水、有毒/冲击负荷废水、小型市政厂
- 优点: 抗冲击强；进水稀释快；运行稳定
- 缺点: 出水水质略逊于推流；动力学上不及推流利于丝状菌控制（低 F/M 易膨胀）

### 变种: 阶段曝气/分步进水 | Step Aeration / Step-Feed
- 年份: 1939–1942（美国纽约 Tallman Island 厂，工程师 Richard H. Gould 首创并应用）
- 差异点: 进水沿曝气池 3–4 个点位分段进入，均衡全池需氧量，提高容积利用率；战时高峰可切换为接触稳定模式
- 流程步骤: 进水 → 预处理 → 初沉 → 曝气池（4 廊道，进水分点注入；首廊道常为污泥再曝气）→ 二沉池 → 消毒 → 出水；RAS 至首端 / WAS 至污泥线
- 设计参数: HRT=3–5 h; SRT=5–10 d; F/M=0.2–0.4; MLSS=2000–3500 mg/L; R=25–75%
- 适用: 大中型厂扩容改造；峰值流量调节；兼作 BNR 分步进水脱氮
- 优点: 池容省约 1/3；需氧均衡；可灵活切换运行模式
- 缺点: 自控阀门多；运行管理较复杂

### 变种: 接触稳定法 | Contact Stabilization (Biosorption)
- 年份: 1951（美国德州 Austin，Ullrich & Smith 提出并工程化；类似思想见 Kraus 1945、Hatfield 工艺）
- 差异点: 有机物先在接触池（0.5–1 h）被污泥快速吸附，污泥单独在稳定池（3–6 h）再曝气氧化，曝气总池容大幅减少
- 流程步骤: 进水 → 预处理 → 接触池（与回流污泥混合短曝气）→ 二沉池 → 出水；沉淀污泥 → 稳定池（再曝气）→ 回流至接触池 / WAS 排放
- 设计参数: 接触 HRT=0.5–1.0 h; 稳定 HRT=3–6 h（SRT 按全系统计 5–10 d）; MLSS（接触池）=1000–3000 mg/L; R=50–150%; 总池容约为传统法 50–60%
- 适用: 中小规模市政污水、可生化性好且含较多悬浮/胶体有机物的废水
- 优点: 池容小、基建省；抗冲击好
- 缺点: 对溶解性有机物为主的废水不适用；硝化能力弱；出水水质一般

### 变种: 延时曝气 | Extended Aeration
- 年份: 约 1940s（美国，小型分散处理兴起；1950s 成套设备化）
- 差异点: 极低负荷、长泥龄运行，污泥自身氧化（内源呼吸）比例高，剩余污泥少且基本稳定，常不设初沉池
- 流程步骤: 进水 → 格栅/沉砂 → 曝气池（HRT 16–24 h）→ 二沉池 → 消毒 → 出水；RAS 回流 / WAS 少量排放（可直接脱水）
- 设计参数: HRT=16–24 h; SRT=18–30 d; F/M=0.05–0.15 kgBOD/(kgMLVSS·d); MLSS=2000–4000 mg/L; R=50–200%
- 适用: 小型社区、乡镇、度假村、学校等分散式污水
- 优点: 污泥量少且稳定（可不设消化系统）；硝化彻底；管理简单
- 缺点: 占地与曝气能耗大；低温下氨氮波动；成套设备规模受限

### 变种: 高负荷/改良曝气 | High-Rate & Modified Aeration
- 年份: 约 1940s（Setter & Edwards 1943 提出改良曝气；高负荷法同期发展）
- 差异点: 短 HRT、低 MLSS、高 F/M，只作部分处理（BOD 去除 60–70%），作粗处理或前段
- 流程步骤: 进水 → 预处理 → 短曝气池（1.5–3 h）→ 二沉池 → 出水（或接二级单元）；RAS 回流
- 设计参数: HRT=1.5–3 h; SRT=1–3 d; F/M=0.5–1.5; MLSS=300–1000 mg/L
- 适用: 工业废水预处理、负荷削减前段、排放标准不高的过渡性工程
- 优点: 池容极小；投资省
- 缺点: 出水水质差；污泥产率高、沉降性差

## 两段活性污泥法（AB 法）| Adsorption–Biooxidation (AB) Process
- 诞生: 1977（德国亚琛工业大学 RWTH Aachen，Botho Böhnke 教授发表首篇论文并取得专利；首座全规模厂德国 Krefeld，文献记为 1980–1985 之间，见自查表）
- 成熟度: 成熟商用（特定场景：高浓度、需产能回收或分期建设的市政厂）
- 定位: 无初沉池的两段活性污泥系统，A 段高负荷吸附、B 段低负荷精制
- 简介: A 段以极高负荷（F/M 3–6 kgBOD/(kgMLSS·d)）、极短泥龄（0.2–0.5 d）运行，主要靠絮凝-吸附与快速代谢去除 50–70% 有机物；B 段为常规低负荷活性污泥法完成深度去除与硝化。两段各自独立沉淀、独立回流，形成不同的微生物群落。近年作为 HRAS（高负荷活性污泥/碳捕捉）重新受到重视。
- 来源: https://en.wikipedia.org/wiki/Adsorption/bio-oxidation_process ; https://libstore.ugent.be/fulltxt/RUG01/002/839/694/RUG01-002839694_2020_0001_AC.pdf ; https://www.sciencedirect.com/science/article/abs/pii/S0043135422009903

### 变种: 经典 AB 法 | Classical AB Process (A-Stage + B-Stage)
- 年份: 1977（专利）；1980–1985（首座全规模，Krefeld）
- 差异点: 取消初沉池；A 段相当于"生物增强一级处理"，B 段保障出水达标
- 流程步骤: 进水 → 格栅 → 沉砂 → A 段曝气池（高负荷，HRT 0.5–1 h）→ A 段中间沉淀池 → B 段曝气池（低负荷）→ B 段二沉池 → 消毒 → 出水；A/B 段各自污泥回流，剩余污泥 → 浓缩 → 消化（A 段污泥产气率高）→ 脱水
- 设计参数: A 段 F/M=3–6 kgBOD/(kgMLSS·d); A 段 SRT=0.2–0.5 d（<2 d）; A 段 HRT=0.5–1 h; B 段 F/M=0.15–0.30; B 段 SRT=15–20 d; B 段 HRT=2–4 h; A 段 COD 去除 50–70%
- 适用: 有机物浓度高或含工业废水比例高的市政污水；分期建设；能源回收导向
- 优点: 总池容小、耐冲击；A 段污泥易消化产甲烷（能源回收）；不设初沉池
- 缺点: 两级沉淀回流、构筑物多；A 段碳捕捉过多会削弱 B 段反硝化碳源；脱氮除磷受限

### 变种: 现代高负荷活性污泥 HRAS（A 段单用）| High-Rate Activated Sludge / A-Stage
- 年份: 约 2010s 复兴（源于 1977 AB 法 A 段，作为"主流碳捕捉"技术重新推广）
- 差异点: 只保留 A 段，后端接膜过滤/厌氧氨氧化等新型工艺，目标是最大化碳能源回收
- 流程步骤: 进水 → 格栅 → 沉砂 → HRAS 池（HRT 15–30 min）→ 高效沉淀/膜分离 → 出水去后续脱氮单元；A 污泥 → 厌氧消化产沼气
- 设计参数: HRT=0.25–1 h; SRT=0.5–2 d; F/M=2–10; MLSS=1500–3000 mg/L; COD 去除（吸附）26–80%
- 适用: 能源自给型污水厂（碳中和目标）、与侧流厌氧氨氧化组合
- 优点: 曝气能耗最低；沼气产量最大化
- 缺点: 出水不能直接达标，必须后接二级/深度单元；运行窗口窄

## 纯氧曝气活性污泥法 | High-Purity Oxygen Activated Sludge (UNOX/HPO)
- 诞生: 1967–1970（美国 Union Carbide 联合碳化物公司，John R. McWhirter 团队；1969 年纽约 Batavia 全规模示范，1970 年商业化命名 UNOX）
- 成熟度: 成熟商用（高峰时约占美国二级处理能力 15%，Detroit 720 MGD、LA Hyperion 450 MGD 等）
- 定位: 用地受限的大型市政/工业污水厂的高强度曝气解决方案
- 简介: 以 90–95% 纯氧替代空气，在加盖分段曝气池中氧分压提高约 5 倍，氧转移速率大增，可维持高 MLSS 与高 DO，曝气时间缩短至空气法的 1/3 左右，污泥产率降低约 30%。配套 PSA 或深冷空分制氧。氧利用率可达 90% 以上。
- 来源: https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=20008RE1.TXT ; https://www.winnipeg.ca/finance/findata/matmgt/documents/2009/100-2009/100-2009_SEWPCC_Upgrading_Expansion_Preliminary_Design_Report_FINAL/Section_8.0/rpt-preliminary_design_report_section8_bnrprocessoptions_Final.pdf ; https://www.hydromantis.com/blog/water-tech-success-stories.html

### 变种: 加盖分段纯氧曝气（UNOX）| Covered Staged HPO (UNOX)
- 年份: 1969–1970（Batavia 示范与商业化）
- 差异点: 曝气池加盖密封分 3–4 段，氧气从首段注入、尾气逐段回用、末段放空，控制氧利用率 ≥90%
- 流程步骤: 进水 → 预处理 → 初沉 → 加盖纯氧曝气池（多段串联，表面曝气机/涡轮）→ 二沉池 → 消毒 → 出水；RAS 回流 / WAS → 污泥线；制氧站（PSA/深冷）→ 供氧
- 设计参数: HRT=4–6 h（空气法 8–10 h）; MLSS=2000–5000 mg/L; DO=4–8 mg/L; SRT=5–10 d; 氧利用率 ≥90%
- 适用: 大型市政厂、扩建无地、高浓度工业废水
- 优点: 池容约为空气法 1/2；污泥量少且沉降好；臭气易封闭收集
- 缺点: 制氧能耗与安全要求高；pH 下降（CO₂ 蓄积）需关注硝化；投资大

### 变种: 敞开式纯氧/微气泡溶氧系统 | Open-Basin HPO & Side-stream Oxygenation
- 年份: 约 1970s–1980s（Lotepro、Air Products 等公司发展氧锥/侧流溶氧路线）
- 差异点: 不加盖，用微气泡扩散器或侧流加压溶氧（oxygen cone）把纯氧溶入部分回流液，降低密封造价
- 流程步骤: 进水 → 预处理 → 初沉 → 曝气池（底部微气泡供纯氧或侧流溶氧注入）→ 二沉池 → 出水；RAS/WAS → 污泥线
- 设计参数: HRT=4–8 h; MLSS=2500–5000 mg/L; 氧转移效率 60–90%（视系统）
- 适用: 改建扩容、加盖困难的老厂
- 优点: 改造灵活；池体无需密封
- 缺点: 氧利用率低于加盖式；运行成本仍高于空气法

## 序批式活性污泥法 SBR 家族 | Sequencing Batch Reactor Family
- 诞生: 1914（充排式活性污泥即 Ardern & Lockett 原始形式）；现代 SBR 1971（美国，Robert L. Irvine & William Davis 在德州 Corpus Christi CPC 工业废水厂首次命名 SBR）；1980 年印第安纳 Culver 厂连续流改 SBR 奠定推广基础
- 成熟度: 主流（中小规模市政与工业废水广泛应用）
- 定位: 在时间维度上交替完成进水-反应-沉淀-排水的一体化活性污泥工艺
- 简介: SBR 在同一池内按周期顺序完成 5 个阶段：进水（Fill）→ 反应（React，曝气）→ 沉淀（Settle）→ 滗水（Decant）→ 闲置（Idle）。不需二沉池与污泥回流系统，通过时间分割实现空间分割的功能；借助 1980s 后自控技术进步得以大规模推广，并衍生出 ICEAS、CASS、DAT-IAT、UNITANK、MSBR 等连续进水变型。
- 来源: https://www.chemengonline.com/sequencing-batch-reactors-for-water-treatment/ ; https://huanbao.bjx.com.cn/tech/20190617/163101-4.shtml ; https://smartwatermagazine.com/news/invent/unleashing-full-potential-sequencing-batch-reactors

### 变种: 经典序批式 SBR | Conventional SBR
- 年份: 1971（命名与首座工程，Corpus Christi）
- 差异点: 间歇进水、间歇排水，单池时间分割；周期通常 4–8 h
- 流程步骤: 进水（可搅拌/曝气）→ 反应曝气（可设缺氧搅拌段脱氮）→ 静置沉淀 → 滗水器排水 → 闲置/排泥（WAS）→ 下一周期；污泥线：剩余污泥 → 浓缩 → 消化/脱水
- 设计参数: 周期 4–8 h; HRT（按周期折算）12–24 h; SRT=10–20 d; F/M=0.05–0.15; MLSS=2000–5000 mg/L; 滗水深度 0.5–2.0 m; 充水比 0.2–0.4
- 适用: 中小城镇、开发区、水质水量波动大的工业废水
- 优点: 无二沉池与回流系统；抗冲击强；可通过时序调整实现脱氮除磷
- 缺点: 滗水器等关键设备要求高；间歇运行设备闲置；大型化受滗水能力限制

### 变种: 间歇循环延时曝气 ICEAS | Intermittent Cycle Extended Aeration System
- 年份: 1968（澳大利亚新南威尔士大学与美国 ABJ 公司合作开发）；1976（首座工程投产）
- 差异点: 连续进水、间歇排水；池前端设预反应区缓冲，无独立闲置段
- 流程步骤: 进水（连续）→ 预反应区 → 主反应区（曝气/搅拌）→ 静置沉淀 → 滗水 → 排泥（WAS）；下一周期
- 设计参数: 周期 4–6 h; SRT=15–25 d; MLSS=3000–5000 mg/L; 充水比小（连续进水）
- 适用: 中小型市政厂，水量连续稳定场景
- 优点: 连续进水不需调节池；延时曝气污泥稳定；造价低于经典 SBR
- 缺点: 沉淀期进水影响泥水分离；脱氮除磷能力有限

### 变种: 循环式活性污泥 CAST/CASS | Cyclic Activated Sludge Technology/System
- 年份: 1979–1985（Mervyn Goronszy 在 ICEAS 基础上开发 CASS/CAST）
- 差异点: 以生物选择器（厌氧/缺氧）替代预反应区，池内分选择器-缺氧-好氧三区（容积比约 1:5:30），污泥回流至选择器，抑制丝状菌并强化脱氮除磷
- 流程步骤: 进水（连续或间歇）→ 生物选择器（与回流污泥接触）→ 缺氧区 → 好氧主曝气区 → 静置沉淀 → 滗水 → 排泥；污泥回流：主区 → 选择器
- 设计参数: 周期 4–6 h; SRT=15–25 d; MLSS=3000–5000 mg/L; 选择器 HRT=0.5–1 h; 回流比 20–30%
- 适用: 有脱氮除磷要求的中小市政厂
- 优点: 防污泥膨胀；脱氮除磷效果好；连续进水
- 缺点: 自控复杂；滗水期仍有进水干扰

### 变种: 需氧-间歇曝气 DAT-IAT | Demand Aeration Tank–Intermittent Aeration Tank
- 年份: 约 1980s 末–1990s（中国天津市政工程设计研究院提出）
- 差异点: 双池串联：DAT 连续进水连续曝气，IAT 连续进水间歇排水；IAT 污泥回流 DAT
- 流程步骤: 进水（连续）→ DAT 需氧池（连续曝气）→ IAT 间歇池（曝气/沉淀/滗水循环）→ 出水；IAT 污泥回流至 DAT；WAS 排放
- 设计参数: 总 HRT=12–20 h; SRT=15–20 d; MLSS=3000–4500 mg/L; IAT 周期 3–4 h
- 适用: 中小规模、高排放标准（脱氮除磷）项目
- 优点: 抗冲击负荷强（DAT 缓冲）；可连续进水；脱氮除磷
- 缺点: 两池构造与自控较复杂；回流泵增加能耗

### 变种: 一体化三池交替系统 UNITANK | UNITANK
- 年份: 1987（比利时 SEGHERS 公司提出，1990s 推广，全球约 200 座）
- 差异点: 三个矩形池连通，边池交替作曝气池与沉淀池，中池恒为曝气；系统整体连续进出水、恒定水位
- 流程步骤: 进水（连续，可进入任一边池）→ 边池 A（曝气）→ 中池（曝气）→ 边池 C（沉淀出水）→ 半周期后换向：进水改至边池 C，边池 A 沉淀出水；剩余污泥自沉淀边池排放
- 设计参数: 周期约 7 h（主阶段 2×3 h + 过渡 2×0.5 h）; SRT=15–25 d; MLSS=3000–5000 mg/L; 可不设初沉池
- 适用: 中小市政厂（新加坡、澳门、石家庄高新区等有案例）
- 优点: 无独立二沉池、占地省；恒水位运行；可时间/空间双调控脱氮除磷
- 缺点: 闸门与自控系统复杂；大规模应用时配水均匀性难保证

### 变种: 改良式序批反应器 MSBR | Modified Sequencing Batch Reactor
- 年份: 约 1980s 初（C.Y. Yang 等将 SBR 与 A²/O 结合开发；专利后归美国 Aqua-Aerobic Systems）
- 差异点: 单池多格（厌氧 A、厌氧 B、缺氧、主曝气、两个交替序批格、泥水分离格），恒定水位连续运行，实质为 A²/O 与 SBR 的串联集成
- 流程步骤: 进水 → 厌氧格 A（释磷/脱氮）→ 厌氧格 B（释磷）→ 缺氧格 → 主曝气格 → 序批格 1 或 2（缺氧-好氧/沉淀-出水，交替运行）→ 出水；污泥回流：序批格 → 泥水分离 → 缺氧格；WAS 排放
- 设计参数: 周期分 6 时段（两半周期各 3 时段）; 总 HRT=12–18 h; SRT=15–25 d; MLSS=3000–5000 mg/L
- 适用: 脱氮除磷要求高的中型市政厂
- 优点: 集约化程度最高；恒水位；脱氮除磷强
- 缺点: 格间连通与自控复杂；国内工程经验相对少

### 变种: 间歇排水延时曝气 IDEA | Intermittently Decanted Extended Aeration
- 年份: 约 1980s（澳大利亚，新南威尔士州乡村污水处理体系）
- 差异点: 连续进水、间歇曝气与间歇滗水的单池系统，前端加厌氧选择区强化除磷
- 流程步骤: 进水（连续）→ 厌氧选择区 → 主池（曝气/沉降/滗水时序运行）→ 滗水排放；WAS 定期排放
- 设计参数: SRT=15–30 d; HRT=18–36 h; MLSS=3000–5000 mg/L
- 适用: 小型乡村与社区污水（澳新广泛应用）
- 优点: 极简单、运行费用低；出水 TN<5、TP<1 mg/L 可达
- 缺点: 规模受限；滗水器依赖进口

## 氧化沟家族 | Oxidation Ditch Family
- 诞生: 1954（荷兰 Voorschoten，TNO 卫生工程研究所 A. Pasveer 博士设计首座氧化沟，服务人口当量 360；1920 年英国 Sheffield 桨板曝气沟渠被视为雏形；1950s 前转刷由 Kessener 于 1925 年开始研制）
- 成熟度: 主流（全球数千座，中小型市政厂经典选择）
- 定位: 环形沟渠中的延时曝气活性污泥法，兼有推流与完全混合特征
- 简介: 氧化沟是首尾相连的环形曝气沟渠，混合液在沟内循环流动（流速 0.25–0.35 m/s），转刷/转盘/表曝机兼作充氧与推流。低负荷长泥龄（SRT 15–30 d）运行，污泥稳定、硝化彻底；沟内沿程形成好氧-缺氧分区，可同步硝化反硝化。一般不设初沉池。
- 来源: https://www.ircwash.org/sites/default/files/341.1-90EV-8226.pdf ; https://baike.sogou.com/v2346990.htm ; https://hj.afzhan.com/tech/585082.html

### 变种: 帕斯维尔氧化沟 | Pasveer Oxidation Ditch
- 年份: 1954（Voorschoten 首座）
- 差异点: 单沟跑道型，Kessener 转刷曝气，早期间歇运行（进水-曝气-沉淀-排水四序），后期加二沉池连续运行；水深一般 ≤1.5 m
- 流程步骤: 进水 → 格栅/沉砂 → 氧化沟（转刷曝气，循环流）→ 二沉池 → 消毒 → 出水；RAS 回流至沟首 / WAS → 污泥线
- 设计参数: HRT=16–24 h; SRT=15–30 d; F/M=0.05–0.10; MLSS=3000–5000 mg/L; R=50–100%
- 适用: 小城镇、农村地区市政污水
- 优点: 工艺极简、污泥稳定；出水水质好
- 缺点: 水深浅、占地大；转刷充氧效率一般

### 变种: 卡鲁塞尔氧化沟 | Carrousel
- 年份: 1967–1968（荷兰 DHV 公司开发；文献分别记 1967 与 1968，见自查表）
- 差异点: 多廊道串联、立式低速表曝机置于廊道端部，水深可达 4–5 m，占地小于 Pasveer
- 流程步骤: 进水 → 格栅/沉砂 → Carrousel 氧化沟（表曝机+廊道循环）→ 二沉池 → 消毒 → 出水；RAS/WAS → 污泥线
- 设计参数: HRT=18–24 h; SRT=15–30 d; MLSS=3000–4500 mg/L; 沟深 4–5 m
- 适用: 中型市政厂
- 优点: 水深大占地省；表曝机单机服务面积大、维护少
- 缺点: 脱氮除磷能力一般（基础型）

### 变种: 卡鲁塞尔 2000 / 3000 | Carrousel 2000 / 3000
- 年份: 约 1990s（DHV 与美国 EIMCO 在原 Carrousel 基础上开发）
- 差异点: 沟前增设厌氧/缺氧选择区（2000 型）或前置反硝化区+内回流（3000 型），实现生物脱氮除磷
- 流程步骤: 进水 → 厌氧选择区 → 缺氧区 → Carrousel 好氧沟 → 二沉池 → 出水；混合液内回流（缺氧）; RAS 回流 / WAS 排放
- 设计参数: SRT=15–25 d; MLSS=3500–5000 mg/L; 内回流比 100–300%
- 适用: 有 TN/TP 排放标准的中型市政厂
- 优点: 保留氧化沟稳定优点同时脱氮除磷
- 缺点: 内回流能耗；池体改造受限

### 变种: 奥贝尔氧化沟 | Orbal
- 年份: 约 1970（美国 Envirex 公司推出；南非工程师 Orbal 命名来源见自查表）
- 差异点: 三条同心椭圆沟，污水自外沟→中沟→内沟串联流动，溶解氧沿程 0→1→2 mg/L 梯度分布，外沟同步硝化反硝化；转盘曝气机充氧
- 流程步骤: 进水 → 格栅/沉砂 → Orbal 外沟（缺氧/厌氧，转盘）→ 中沟 → 内沟（好氧）→ 二沉池 → 消毒 → 出水；RAS 回流至外沟 / WAS 排放
- 设计参数: HRT=16–24 h; SRT=15–30 d; MLSS=3000–5000 mg/L; 外沟容积约占 50–60%
- 适用: 中型市政厂、脱氮要求较高场景
- 优点: 外沟反硝化节能（利用原水碳源）；氧梯度高、传氧效率好
- 缺点: 同心圆布置占地形状受限；转盘设备维护量大

### 变种: 交替工作式氧化沟（D 型/T 型/三沟式）| Alternating (DE, T-type, Tri-ditch)
- 年份: 约 1970s（丹麦 Krüger 公司开发 DE 型与三沟式 T 型）
- 差异点: 双沟（DE）或三沟串联，边沟交替承担曝气与沉淀功能，省掉二沉池；转刷曝气
- 流程步骤: 进水 → 沟 A（曝气）→ 沟 B（沉淀出水）→ 出水；半周期切换：沟 B 曝气、沟 A 沉淀出水；三沟式中沟恒曝气、两边沟交替；剩余污泥自沉淀沟排出
- 设计参数: HRT=16–24 h; SRT=15–30 d; MLSS=3000–4500 mg/L; 周期 4–8 h
- 适用: 中小市政厂，无二沉池一体化需求
- 优点: 省二沉池与回流系统；可时序脱氮（硝化/反硝化交替）
- 缺点: 设备利用率低（转刷闲置时段）；自控阀门多

### 变种: 一体化氧化沟 | Integrated Oxidation Ditch (ICC)
- 年份: 约 1980s（美国等将沉淀区建于沟内形成合建式）
- 差异点: 沉淀区（船式/侧沟式/内置斜板）置于沟内，泥水在沟内分离回流，真正单构筑物
- 流程步骤: 进水 → 格栅/沉砂 → 一体化氧化沟（曝气循环 + 内置沉淀区）→ 出水；污泥自动回流，WAS 排放
- 设计参数: HRT=16–24 h; SRT=15–30 d; MLSS=3000–5000 mg/L
- 适用: 小型市政与工业点源
- 优点: 占地最省；流程最短
- 缺点: 内置沉淀区水力条件苛刻、出水 SS 波动；大型化困难

## 生物脱氮工艺（A/O 系）| Biological Nitrogen Removal Processes
- 诞生: 1932（Wuhrmann 后置反硝化，瑞士）→ 1962（Ludzack & Ettinger 前置反硝化，美国）→ 1973（Barnard 改良 Ludzack-Ettinger 即 MLE/A/O，并创立 Bardenpho，南非）
- 成熟度: 主流
- 定位: 以硝化-反硝化生物途径去除总氮的经典工艺族
- 简介: 好氧区硝化菌将 NH₄⁺ 氧化为 NO₃⁻，缺氧区反硝化菌以原水有机物为碳源将 NO₃⁻ 还原为 N₂ 逸出。前置反硝化（缺氧在前）利用进水碳源、节省曝气（反硝化回收部分氧当量）；后置反硝化需外加碳源或内源反硝化。内回流比决定脱氮率上限。
- 来源: https://sthj.ln.gov.cn/sthj/hjgl/swrfz/czws/F6B4CECEB15743ECB21658765FEDF235/index.shtml ; https://www.wrc.org.za/wp-content/uploads/mdocs/TT-83-97.pdf

### 变种: 后置反硝化 Wuhrmann 工艺 | Wuhrmann Process (Post-denitrification)
- 年份: 1932（Wuhrmann，瑞士）
- 差异点: 好氧硝化在前、缺氧反硝化在后，反硝化靠内源碳，速率低、池容大
- 流程步骤: 进水 → 初沉 → 好氧池（碳化+硝化）→ 缺氧池（内源反硝化）→ 二沉池 → 出水；RAS 回流 / WAS 排放
- 设计参数: 总 HRT=10–16 h; SRT=15–25 d; 缺氧段 HRT 长（内源反硝化慢）
- 适用: 历史意义为主；低碳氮比研究场景
- 优点: 流程直观；理论奠基
- 缺点: 反硝化速率极低、占地大；工程上基本被淘汰

### 变种: 前置反硝化 Ludzack-Ettinger | Ludzack-Ettinger Process
- 年份: 1962（Ludzack & Ettinger，美国）
- 差异点: 缺氧池前置，利用进水碳源反硝化；但回流路径未受控，脱氮率有限
- 流程步骤: 进水 → 缺氧池（反硝化）→ 好氧池（碳化+硝化）→ 二沉池 → 出水；RAS 回流至缺氧池
- 设计参数: 总 HRT=8–12 h; SRT=10–20 d; R=50–100%
- 适用: 历史过渡工艺
- 优点: 首次利用原水碳源
- 缺点: 好氧池硝酸盐无法受控回流，脱氮不彻底

### 变种: 改良 Ludzack-Ettinger（MLE/A/O 脱氮型）| Modified Ludzack-Ettinger (MLE)
- 年份: 1973（Barnard，南非）
- 差异点: 在好氧池末端增设混合液内回流至缺氧池，硝酸盐受控回流，脱氮率显著提高；是现代前置反硝化标准构型
- 流程步骤: 进水 → 初沉 → 缺氧池 → 好氧池（硝化）→ 二沉池 → 出水；内回流（硝化液）好氧池末端 → 缺氧池首端（100–400%）; RAS 回流 / WAS 排放
- 设计参数: 总 HRT=8–14 h（缺氧 2–4 h）; SRT=10–20 d; MLSS=2500–4000 mg/L; 内回流 100–400%; R=50–100%; TN 去除 60–80%
- 适用: 以脱氮为主、出水 TN≤15 mg/L 的市政厂
- 优点: 结构简单、脱氮稳定；利用原水碳源
- 缺点: 内回流受出水硝酸盐下限约束，不能彻底脱氮；无生物除磷功能

### 变种: 四段 Bardenpho | Four-Stage Bardenpho
- 年份: 1973（Barnard，南非；1975 年在工程中验证）
- 差异点: 在 MLE 后再加二级缺氧（后反硝化）+ 快速再曝气段，理论上可完全脱氮
- 流程步骤: 进水 → 一级缺氧池 → 一级好氧池（硝化）→ 二级缺氧池（后反硝化，必要时外加碳源）→ 再曝气池（脱气、防二沉池上浮）→ 二沉池 → 出水；内回流：一级好氧 → 一级缺氧；RAS/WAS
- 设计参数: 总 HRT=12–18 h; SRT=15–25 d; 内回流 200–400%; TN 去除 85–95%
- 适用: 出水 TN≤10 mg/L 的严格脱氮场景
- 优点: 脱氮率最高的传统构型之一；无需化学除氮
- 缺点: 池容大；二级缺氧碳源不足时脱氮受限

## 同步脱氮除磷工艺（A²/O 系/BNR）| Combined N & P Removal (BNR) Processes
- 诞生: 1976（Barnard 在 Bardenpho 前加厌氧段 → 五段 Phoredox/改良 Bardenpho，南非）→ 1980（Rabinowitz & Marais 三段化即传统 A²/O；同年 UCT 由开普敦大学 Marais 团队提出）；1987 VIP（美国 CH2M Hill/Daigger 等，弗吉尼亚 HRSD）；JHB（南非约翰内斯堡 Northern Works 工程改造）
- 成熟度: 主流（全球市政脱氮除磷的事实标准族）
- 定位: 单污泥系统内同步实现碳、氮、磷去除的工艺族
- 简介: 厌氧段聚磷菌（PAO）释磷并储存 VFA 为 PHA；缺氧段反硝化；好氧段完成碳化、硝化与过量吸磷，通过排放富磷剩余污泥除磷。各变种的本质区别在于三条回流（污泥回流 S、好氧内回流 A、缺氧内回流 R）的落点安排，目标是让尽量少的硝酸盐进入厌氧段。
- 来源: https://sthj.ln.gov.cn/sthj/hjgl/swrfz/czws/F6B4CECEB15743ECB21658765FEDF235/index.shtml ; https://www.epa.gov/sites/default/files/2019-02/documents/nutrient-control-design-manual-state-tech.pdf ; https://www.wrc.org.za/wp-content/uploads/mdocs/TT-83-97.pdf

### 变种: 传统 A²/O（三段 Phoredox）| Anaerobic-Anoxic-Oxic (A²/O)
- 年份: 1980（Rabinowitz & Marais，南非开普敦大学）
- 差异点: 五段 Bardenpho 简化为厌氧-缺氧-好氧三段，污泥回流直接进厌氧段；流程最短的总氮总磷同步去除工艺
- 流程步骤: 进水 → 初沉 → 厌氧池（释磷）→ 缺氧池（反硝化）→ 好氧池（碳化+硝化+吸磷）→ 二沉池 → 消毒 → 出水；内回流：好氧 → 缺氧（100–300%）; RAS 至厌氧池（50–100%）/ WAS 富磷污泥 → 污泥线
- 设计参数: 总 HRT=7–14 h（厌氧 1–2 h；缺氧 2–3 h；好氧 4–8 h）; SRT=10–20 d; MLSS=2500–4000 mg/L; SVI<100 mL/g; 污泥含磷 2.5% 以上
- 适用: 出水 TN≤15 mg/L、TP≤1 mg/L 的市政污水厂（中国主流工艺）
- 优点: 流程最简、HRT 最短；不易污泥膨胀；剩余污泥富磷可作肥料
- 缺点: 回流污泥携带硝酸盐进入厌氧段，抑制释磷；脱氮与除磷对泥龄需求矛盾（硝化菌需长泥龄、除磷需短泥龄排泥）

### 变种: 五段 Phoredox/改良 Bardenpho | Five-Stage Phoredox / Modified Bardenpho
- 年份: 1976（Barnard，南非中试后提出）
- 差异点: 在四段 Bardenpho 首端加厌氧池，脱氮与除磷能力均为族内最强
- 流程步骤: 进水 → 厌氧池 → 一级缺氧池 → 一级好氧池 → 二级缺氧池 → 再曝气池 → 二沉池 → 出水；内回流：一级好氧 → 一级缺氧；RAS → 厌氧池 / WAS → 污泥线
- 设计参数: 总 HRT=14–20 h; SRT=15–25 d; 内回流 200–400%; TN 去除 >90%; TP 可达 <1 mg/L
- 适用: 出水要求极严（TN<10、TP<0.5 mg/L）的大型厂
- 优点: 氮磷去除深度最大
- 缺点: 池容与能耗最大；运行管理复杂

### 变种: UCT 工艺 | University of Cape Town Process
- 年份: 1980（南非开普敦大学，Marais 团队）
- 差异点: 污泥回流至缺氧段而非厌氧段，另设缺氧→厌氧混合液回流（R 回流），隔绝硝酸盐进入厌氧段，保护释磷
- 流程步骤: 进水 → 厌氧池 → 缺氧池 → 好氧池 → 二沉池 → 出水；回流 1（A）：好氧 → 缺氧；回流 2（R）：缺氧 → 厌氧；RAS（S）：二沉池 → 缺氧池
- 设计参数: 总 HRT=10–16 h; SRT=15–25 d; A 回流 100–300%; R 回流 100–200%; S 回流 50–100%
- 适用: 进水 C/N 偏低、需强化除磷的市政厂
- 优点: 厌氧段几乎无硝酸盐干扰，除磷稳定
- 缺点: 三条回流管线、运行调控复杂；A 回流需精确控制避免缺氧段过载

### 变种: 改良 UCT（MUCT）| Modified UCT
- 年份: 约 1980s 中（南非/美国工程界在 UCT 基础上改进）
- 差异点: 缺氧段一分为二：第一缺氧段专受 RAS 并反硝化后再回流厌氧段；第二缺氧段接受好氧内回流，免除 UCT 对 A 回流的精细控制
- 流程步骤: 进水 → 厌氧池 → 缺氧段 1（受 RAS，反硝化）→ 缺氧段 2（受内回流）→ 好氧池 → 二沉池 → 出水；回流：缺氧段 1 → 厌氧；好氧 → 缺氧段 2；RAS → 缺氧段 1
- 设计参数: 总 HRT=10–16 h; SRT=15–25 d; 缺氧段 1 约占缺氧总泥量 10%
- 适用: 低 C/N 污水、运行控制要求简化的除磷场景
- 优点: 运行控制简化；厌氧段保护可靠
- 缺点: 回流系统更多；整体脱氮能力略降

### 变种: VIP 工艺 | Virginia Initiative Plant Process
- 年份: 1987（美国 CH2M Hill 公司，Daigger 等，弗吉尼亚 Hampton Roads 卫生区）
- 差异点: 类 UCT 构型但按高负荷（SRT≤10 d）运行，各区段用隔板分成 2 个以上完全混合小室串联，提高前端反应速率
- 流程步骤: 进水 → 厌氧段（2 格串联）→ 缺氧段（2 格串联）→ 好氧段 → 二沉池 → 出水；回流同 UCT（S 至缺氧、R 缺氧至厌氧、A 好氧至缺氧）
- 设计参数: 总 HRT=6–10 h; SRT=5–10 d; MLSS=2000–3000 mg/L; 污泥产率较高（短泥龄）
- 适用: 北美高负荷市政厂；用地紧张改造
- 优点: 池容小；短泥龄除磷效率高（净产泥率大则排磷多）
- 缺点: 短泥龄下低温硝化风险；污泥产量较大

### 变种: 约翰内斯堡工艺 JHB | Johannesburg Process
- 年份: 约 1980s（南非约翰内斯堡 Northern Works 厂改造中形成）
- 差异点: 回流污泥先经一个独立的小型缺氧池（内源反硝化脱除硝酸盐）再进入厌氧段，厌氧段保护最彻底
- 流程步骤: 进水 → 厌氧池 → 缺氧池 → 好氧池 → 二沉池 → 出水；RAS → 回流污泥缺氧池（脱硝）→ 厌氧池；内回流：好氧 → 缺氧
- 设计参数: 总 HRT=10–16 h; 污泥脱硝池 HRT≈1 h; SRT=15–25 d
- 适用: 进水 C/N 低、出水 TP 要求严格的场景
- 优点: 厌氧段硝酸盐最少、释磷最充分
- 缺点: 多一座脱硝池；可反硝化的缺氧容积被分走，脱氮率略降

### 变种: 倒置 A²/O | Inverted A²/O (Anoxic-Anaerobic-Oxic)
- 年份: 约 1981–1990（美国德州大学阿灵顿分校 Qasim 等小试中试；1990s 中国同济大学高廷耀、张波等在改造工程中推广命名）
- 差异点: 缺氧段置于厌氧段之前，取消混合液内回流，回流污泥与进水（部分）先入缺氧段耗尽硝酸盐，再进厌氧段释磷
- 流程步骤: 进水（部分直入缺氧、部分直入厌氧）→ 缺氧池（受 RAS，反硝化）→ 厌氧池（释磷）→ 好氧池 → 二沉池 → 出水；污泥回流比 100–200%（合一回流）；无内回流
- 设计参数: 缺氧 HRT=1–3 h; 总 HRT=8–14 h; SRT=10–20 d; 污泥回流 100–200%
- 适用: 碳源紧张、以脱氮为主兼顾除磷的市政厂（中国多个改造案例，如上海松江、广州大坦沙三期）
- 优点: 碳源优先满足反硝化，脱氮能力强；取消内回流、流程简化
- 缺点: 厌氧段优质碳源少，除磷效率不如常规 A²/O；大回流加重二沉池负荷

## 滴滤池（生物滤池）| Trickling Filter
- 诞生: 1890（美国麻省 Lawrence 实验站建成首个真正意义的滴滤池）/1893（英国 Salford（曼彻斯特附近）首座市政滴滤池，J. Corbett）；1901 年美国 Madison, WI 首座市政应用
- 成熟度: 经典（20 世纪上半叶二级处理主力；现多用于中小厂、工业废水与粗滤前段）
- 定位: 固定床生物膜法的鼻祖——污水喷淋通过填料床，生物膜氧化有机物
- 简介: 污水经旋转布水器均匀洒布于碎石或塑料填料表面，自上而下渗滤，填料表面生物膜中的微生物降解有机物与氨氮；空气靠自然通风或强制通风自下而上供氧。脱落的生物膜（腐殖污泥）由后沉池分离。按负荷分低负荷（标准）与高负荷两类。
- 来源: https://sleigh-munoz.co.uk/wash/Mara/History/HistSewTreat.pdf ; https://web.deu.edu.tr/atiksu/ana52/ani4041.html ; https://prod.wef.org/link/a427bcee209149c1aeae8106cffee185.aspx

### 变种: 低负荷（标准）滴滤池 | Low-Rate / Standard-Rate Trickling Filter
- 年份: 1893（Salford 起）
- 差异点: 无回流或低回流，负荷低，可达到完全硝化；滤蝇问题突出
- 流程步骤: 进水 → 格栅 → 沉砂 → 初沉 → 滴滤池（碎石填料 1.5–2 m 深）→ 后沉池 → 出水；腐殖污泥 → 污泥线（常与初沉污泥合并消化）
- 设计参数: 水力负荷 1–4 m³/(m²·d); 有机负荷 0.08–0.32 kgBOD/(m³·d); BOD 去除 80–90%（可硝化）
- 适用: 小型市镇、气候温和地区
- 优点: 能耗极低（靠自然通风）；管理简单
- 缺点: 占地大；滤蝇与孳生虫害；冬季效率下降

### 变种: 高负荷滴滤池 | High-Rate Trickling Filter
- 年份: 约 1930s–1940s（美国，Aero-filter/Bio-filter/Accelo-filter 等商业系统推动回流式高负荷设计）
- 差异点: 出水回流稀释进水、提高喷淋密度冲刷生物膜，负荷提高 5–10 倍；塑料填料允许 4–12 m 塔式构型
- 流程步骤: 进水 → 初沉 → 高负荷滴滤池（回流比 0.5–2）→ 后沉池 → 出水（或二级串联）；污泥 → 污泥线
- 设计参数: 水力负荷 8–40 m³/(m²·d); 有机负荷 0.4–1.2 kgBOD/(m³·d); BOD 去除 65–85%（单级）
- 适用: 中型厂、工业废水粗处理
- 优点: 占地比低负荷小得多；不易堵塞
- 缺点: 出水一般不达标需二级串联；回流泵能耗

### 变种: 塔式生物滤池 | Biotower (Plastic Media Tower)
- 年份: 约 1950s–1960s（Dow 化学等开发塑料填料 Surfpac 后兴起）
- 差异点: 轻质塑料填料堆高 4–12 m，垂直塔式布置，占地极小
- 流程步骤: 进水 → 初沉 → 塔式滤池（顶部布水）→ 后沉池 → 出水；常作活性污泥前粗滤（TF/AS 组合）
- 设计参数: 有机负荷 0.8–2.0 kgBOD/(m³·d)（粗滤可更高）; 水力负荷 20–80 m³/(m²·d)
- 适用: 工业废水预处理、用地紧张改扩建
- 优点: 占地极小；抗冲击；能耗低
- 缺点: 出水水质有限；填料投资高

### 变种: 滴滤池-活性污泥组合 | Trickling Filter / Solids Contact (TF/SC) & TF/AS
- 年份: 约 1970s–1980s（美国 EPA 二级标准收紧后的改造路线）
- 差异点: 滴滤池后接短曝气固体接触池，絮凝脱膜污泥、稳定出水水质
- 流程步骤: 进水 → 初沉 → 滴滤池 → 固体接触曝气池（HRT 1–2 h）→ 二沉池 → 出水；RAS 回流 / WAS 排放
- 设计参数: 接触池 HRT=1–2 h; MLSS=1500–2500 mg/L; 组合出水 BOD/SS ≤20 mg/L
- 适用: 老滴滤池厂提标改造
- 优点: 旧设施利用、能耗低于全活性污泥
- 缺点: 流程单元多

## 生物转盘 | Rotating Biological Contactor (RBC)
- 诞生: 概念 1920s 德国（"旋转好氧体"）；1929 年美国 Doman 专利"生物轮"；现代 RBC 1960（联邦德国首套商业装置，Hartmann 1961 专利；1964 Popel 中试）；1969 年美国首套商业装置（Allis-Chalmers Bio-Disc，奶酪厂）
- 成熟度: 成熟商用（中小规模、分散式；1970s–80s 盛行，后因机械故障问题热度下降）
- 定位: 半浸没旋转盘片上的生物膜工艺，能耗低、操作简
- 简介: 一系列轻质盘片（直径 2–3.5 m）固定在水平轴上，约 40% 浸没在污水槽中缓慢旋转（1–2 rpm）。生物膜在盘片浸入时吸附有机物、转出时从空气获氧，交替完成降解。多级串联可实现硝化。盘片脱落生物膜由二沉池分离。
- 来源: https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=20007IWK.TXT ; https://dspace.lib.cranfield.ac.uk/bitstream/handle/1826/9746/Rotating_biological_contractors_for_wastewater_treatment-a review-2015.pdf ; https://web.deu.edu.tr/atiksu/ana52/biofilm4.pdf

### 变种: 常规多级 RBC | Conventional Staged RBC
- 年份: 1960（首套商业装置，西德）
- 差异点: 3–4 级串联，逐级 BOD 递减，末级可硝化；无需曝气设备与污泥回流
- 流程步骤: 进水 → 格栅/沉砂 → 初沉 → RBC 一级 → RBC 二级 → RBC 三级（硝化）→ 二沉池 → 出水；脱落膜污泥 → 污泥线
- 设计参数: 盘面负荷 3–15 gBOD/(m²·d); 转速 1–2 rpm; 浸没率 40%; HRT（槽内）1–2 h
- 适用: 小型社区、度假村、加油站服务区等分散污水
- 优点: 能耗低（仅电机）；运行简单；耐冲击
- 缺点: 轴/轴承/盘片机械故障史多；低温需加盖保温

### 变种: 高密度介质/硝化 RBC | High-Density Media & Nitrification RBC
- 年份: 约 1972（Autotrol 公司波纹聚乙烯薄盘片，比表面积大增）
- 差异点: 高密度波纹盘片（比表面积提高 2 倍以上），末级专作硝化或变速浸没实现同步硝化反硝化（日本久保田专利）
- 流程步骤: 进水 → 初沉 → RBC 碳化级（高密度盘片）→ RBC 硝化级（低负荷）→ 二沉池 → 出水
- 设计参数: 硝化级盘面负荷 1.5–3 gBOD/(m²·d); 氨氮负荷 0.5–1.5 gN/(m²·d)
- 适用: 需硝化的小型厂
- 优点: 占地更省；硝化稳定
- 缺点: 机械维护依旧；规模上限约 1000–5000 人口当量

## 曝气生物滤池 | Biological Aerated Filter (BAF)
- 诞生: 约 1980s 初（欧洲，法国 Degrémont BIOFOR、Krüger BIOSTYR 等为代表；源头可追溯 1913 年板岩层曝气池与 1939 年首个淹没式接触曝气）
- 成熟度: 主流（全球 500+ 座，尤适合用地紧张的提标与深度处理）
- 定位: 集生物降解与过滤截流于同一池体的紧凑型固定膜工艺
- 简介: 污水上流或下流通过淹没的颗粒滤料层（陶粒/浮石/聚苯乙烯小球），滤料表面生物膜降解碳氮污染物，滤层同时截留悬浮物；定期气水联合反冲洗排出截留物与老化生物膜。可取消二沉池。
- 来源: https://politesi.polimi.it/retrieve/a81cb05c-2d31-616b-e053-1605fe0a889a/2016_12_Tastekin.pdf ; https://vtechworks.lib.vt.edu/bitstream/handle/10919/76663/Thomas_A_T_2015.pdf ; https://www.veoliawatertechnologies.com/en/solution/technologies/biostyr

### 变种: 上向流沉水滤料 BIOFOR | BIOFOR (Upflow, Sunken Media)
- 年份: 约 1982（法国 Degrémont 公司工程化）
- 差异点: 上向流+重于水的陶粒滤料，曝气管置于滤层中部，可分区实现碳化/硝化
- 流程步骤: 进水 → 初沉/CEPT → BIOFOR 滤池（底部进水、中部曝气、顶部出水）→ 出水（或消毒）；反冲洗：气洗→气水联合→水洗，反洗废水 → 回流至初沉/污泥线
- 设计参数: 滤速 2–6 m/h; 有机负荷 2–6 kgBOD/(m³滤料·d); 硝化负荷 0.4–1.0 kgNH₄-N/(m³·d); 反洗周期 24–48 h
- 适用: 大型市政厂二级+深度处理（多格并联）
- 优点: 占地为活性污泥法 1/4–1/6；出水 SS 极低；可模块化扩容
- 缺点: 反洗系统复杂；滤料与专用滤头投资高

### 变种: 上向流漂浮滤料 BIOSTYR | BIOSTYR (Upflow, Floating Media)
- 年份: 约 1980s 末（法国 Krüger（现 Veolia）开发）
- 差异点: 轻质聚苯乙烯滤珠漂浮于水面被出水顶板压持，滤床膨胀截污；曝气位置可调实现好氧/缺氧分区
- 流程步骤: 进水 → 预处理 → BIOSTYR（底部进水，上浮滤珠层，中部曝气）→ 顶部清水区出水；反洗为向下脉冲式；反洗水 → 污泥线
- 设计参数: 滤速 3–8 m/h; 负荷同 BIOFOR; 反洗周期 24–72 h
- 适用: 用地紧张的新建与提标项目、回用水前处理
- 优点: 滤速高；可同步硝化反硝化（分区）
- 缺点: 滤珠磨损需补充；专利设备

### 变种: 下向流反硝化滤池 | Downflow Denitrification Filter
- 年份: 约 1970s（美国，用于三级深度脱氮）
- 差异点: 下向流粗粒滤料，外加甲醇/乙酸碳源，缺氧运行专作反硝化；兼具过滤
- 流程步骤: 二级出水 → 反硝化滤池（投加甲醇，缺氧）→ 出水（短暂曝气脱氮气）→ 消毒；反洗 → 回流
- 设计参数: 滤速 4–10 m/h; 硝酸盐负荷 0.5–2 kgNO₃-N/(m³·d); 碳氮比（甲醇/NO₃-N）≈3:1
- 适用: 出水 TN≤3–5 mg/L 的深度脱氮
- 优点: TN 可达极低；兼有 SS 过滤
- 缺点: 外加碳源成本与安全（甲醇）问题；微气泡氮气上浮需控制

## 生物接触氧化与流化床 | Biological Contact Oxidation & Fluidized/Expanded Bed
- 诞生: 淹没式接触曝气 1939（首个 submerged contact aeration 工艺）；1943 年美国 74 座厂应用（>80% BOD 去除）；生物接触氧化 1970s 在日本与中国系统化推广；厌氧/好氧流化床 1970s（美国，Jeris 等）
- 成熟度: 成熟商用（生物接触氧化在中国/日本小型市政与工业废水极普遍）
- 定位: 淹没式固定膜工艺——填料浸没于曝气池中，生物膜+悬浮污泥协同降解
- 简介: 曝气池中装填弹性填料/组合填料/蜂窝填料，池底曝气，生物膜附着在填料上、不随水流失，无需污泥回流（或少量回流）；兼具活性污泥法与生物滤池优点。流化床则以砂/活性炭微粒为载体、以上向水流使其流态化，生物膜厚度可控、传质极佳。
- 来源: https://moscow.sci-hub.ru/2148/ce1f75f8c9dbca2bebefb929e5a20ad0/10.1007@978-94-007-4204-8.pdf ; https://www.sciencedirect.com/topics/engineering/anaerobic-filter

### 变种: 生物接触氧化（淹没式）| Submerged Biological Contact Oxidation
- 年份: 1939（首个淹没式接触曝气）；1970s（日本、中国系统化与填料化发展）
- 差异点: 填料全浸没、鼓风曝气；常分 2–3 段串联，可挂膜脱氮（缺氧段+好氧段）
- 流程步骤: 进水 → 初沉/水解酸化 → 接触氧化池一段 → 接触氧化池二段 → 二沉池（或沉淀+过滤）→ 出水；脱落膜污泥 → 污泥线
- 设计参数: 容积负荷 1.0–3.0 kgBOD/(m³填料·d); HRT=4–8 h; 气水比 10–15:1; 填料填充率 60–75%
- 适用: 小型市政、小区中水、工业废水（印染、食品）
- 优点: 无污泥膨胀之虞；抗冲击；启动快、无需驯化回流
- 缺点: 填料老化更换成本；布气不均易短流

### 变种: 好氧/厌氧流化床与膨胀床 | Aerobic/Anaerobic Fluidized & Expanded Bed
- 年份: 约 1970s 初（美国 Jeris 等开发厌氧流化床；好氧流化床同期商业化）
- 差异点: 微粒载体（砂、活性炭）在上升流中流态化，单位体积生物量极高；膨胀床流速较低、床层部分膨胀
- 流程步骤: 进水 → 预处理 → 流化床反应器（底部布水，床层膨胀 20–50%）→ 载体分离/淘洗回流 → 出水（好氧需后沉池）
- 设计参数: 上升流速 10–30 m/h（流化床）/ 2–10 m/h（膨胀床）; 容积负荷 5–30 kgCOD/(m³·d)（厌氧）
- 适用: 高浓度工业废水、地下水硝酸盐/难降解污染物处理
- 优点: 容积负荷最高；占地极小
- 缺点: 流化能耗与载体磨损；运行控制要求高

## 稳定塘（氧化塘）| Waste Stabilization Ponds
- 诞生: 天然塘利用已有 3000 年历史；美国首座有记录的塘系统 1901（德州 San Antonio，275 ha、深约 1.4 m）；1924 年加州 Santa Rosa 塘运行数据推动工程化认知；1950s 起成为小城镇经济选择
- 成熟度: 成熟（美国 8000+ 座、占处理设施一半以上；欧非拉美广泛）
- 定位: 利用自然生态过程（菌藻共生）处理污水的最经济土地密集型工艺
- 简介: 稳定塘依靠藻类光合作用供氧、细菌降解有机物、长停留时间沉淀与灭活病原体。按溶解氧分层分为厌氧塘、兼性塘、好氧塘与熟化塘，常串联使用：厌氧塘→兼性塘→熟化塘。曝气塘以机械曝气强化，介于塘与活性污泥法之间。
- 来源: https://www.epa.gov/sites/default/files/2014-09/documents/lagoon-pond-treatment-2011.pdf ; https://www.sciencedirect.com/science/article/pii/S0959652618302270

### 变种: 好氧塘 | Aerobic (High-Rate) Pond
- 年份: 约 1950s（Oswald 等系统研究，加州）
- 差异点: 全塘好氧、水深最浅（0.3–0.5 m），藻类高产，常作高负荷藻塘养殖用途
- 流程步骤: 进水（经前处理）→ 好氧塘（浅层、可搅拌）→ 藻类分离（沉淀/气浮）→ 出水
- 设计参数: 水深 0.3–0.5 m; HRT=3–10 d; BOD 负荷 80–200 kg/(ha·d)
- 适用: 温暖日照充足地区、资源回收（藻蛋白）
- 优点: 处理效率高、产藻类资源
- 缺点: 藻水分离难；仅限温暖气候

### 变种: 兼性塘 | Facultative Pond
- 年份: 1901（San Antonio 为代表工程）——最常见的塘型
- 差异点: 上层好氧（藻类供氧）、中层兼性、底层厌氧（污泥消化），三层协同
- 流程步骤: 进水（格栅/沉砂）→ 兼性塘（水深 1–2.5 m）→ 熟化塘 → 出水灌溉/排放；塘底污泥数年清掏一次 → 干化/土地利用
- 设计参数: 水深 1–2.5 m; HRT=20–60 d; BOD 表面负荷 20–60 kg/(ha·d)（随纬度调整）
- 适用: 小城镇、土地充裕地区
- 优点: 几乎无能耗；耐冲击；BOD/病原体去除好
- 缺点: 占地巨大；受季节温度影响；底泥长期累积

### 变种: 厌氧塘 | Anaerobic Pond
- 年份: 约 1920s–1950s（作为高负荷前段塘应用）
- 差异点: 水深 2–5 m、全塘厌氧，承接高负荷有机废水，BOD 去除 40–70%，后续必须接好氧/兼性塘
- 流程步骤: 进水 → 厌氧塘（深塘，HRT 1–7 d）→ 兼性塘 → 熟化塘 → 出水
- 设计参数: 水深 2–5 m; HRT=1–7 d; 容积负荷 100–400 gBOD/(m³·d)
- 适用: 高浓度有机废水（屠宰、食品）前处理、热带地区
- 优点: 负荷高、污泥产率低
- 缺点: 臭气（H₂S）；出水必须后处理

### 变种: 曝气塘 | Aerated Lagoon
- 年份: 约 1950s–1960s（机械曝气引入塘系统）
- 差异点: 表面曝气机或鼓风曝气供氧，水深 2–5 m；分完全混合好氧曝气塘与部分混合兼性曝气塘
- 流程步骤: 进水 → 曝气塘（曝气机）→ 沉淀塘/二沉池 → 出水；污泥定期排放
- 设计参数: HRT=3–10 d; 水深 2–5 m; 功率输入 1–6 W/m³（部分混合）或 >10 W/m³（完全混合）
- 适用: 用地有限但不足以建活性污泥厂的小城镇
- 优点: 占地小于兼性塘；出水优于自然塘
- 缺点: 有电耗；藻类/SS 出水偏高

### 变种: 熟化塘（精制塘）| Maturation Pond
- 年份: 约 1950s 起作为系列塘末段
- 差异点: 浅（0.5–1.5 m）、负荷极低，主要靠光照与 pH 升高灭活病原体
- 流程步骤: 兼性塘出水 → 熟化塘 1 → 熟化塘 2（串联）→ 出水
- 设计参数: 水深 0.5–1.5 m; 单塘 HRT=5–10 d; 粪大肠菌群去除可达 99.99%
- 适用: 出水回用（灌溉）前的卫生学屏障
- 优点: 无动力去除病原体；脱氮（氨挥发/藻吸收）
- 缺点: 占地；藻类致出水 SS 偏高

## 人工湿地 | Constructed Wetlands (CW)
- 诞生: 1950s 初（德国马普学会 Plön 湖沼站 Käthe Seidel 首次系统研究湿地植物处理污水）；1967 年荷兰首座表流湿地（"种植污水农场"）；1960s 末 Kickuth 根区法（Root Zone Method）；1974 年德国 Liebenburg-Othfresen 首座市政潜流湿地
- 成熟度: 成熟（欧洲/北美乡村与分散处理、深度处理广泛）
- 定位: 以基质-植物-微生物协同作用净化污水的生态工程工艺
- 简介: 污水通过种植挺水植物（芦苇、香蒲等）的砂砾/土壤基质床，污染物经吸附、过滤、植物吸收、微生物硝化反硝化去除。按水流形态分为表流（FWS）、水平潜流（HF）与垂直流（VF）三类；潜流床无臭味蚊蝇、欧洲主流，垂直流充氧好、可硝化。
- 来源: https://www.sciencedirect.com/science/article/abs/pii/S0925857405001588 ; https://www.mdpi.com/2073-4441/2/3/530 ; https://en.wikipedia.org/wiki/K%C3%A4the_Seidel

### 变种: 表流人工湿地 | Free Water Surface CW (FWS)
- 年份: 1967（荷兰首座）
- 差异点: 水面开放、水深 0.1–0.6 m，类似天然沼泽；北美主流
- 流程步骤: 进水（二级出水或初沉出水）→ 表流湿地（挺水植物带）→ 出水；沉积物定期清理
- 设计参数: 水力负荷 0.7–5 cm/d; HRT=5–14 d; 面积指标 5–10 m²/人
- 适用: 二级出水深度净化、暴雨径流、景观回用
- 优点: 景观生态价值高；投资低
- 缺点: 有蚊蝇风险；占地大；冬季冰封效率降

### 变种: 水平潜流湿地 | Horizontal Subsurface Flow CW (HF)
- 年份: 1950s–1960s（Seidel 提出）；1969 前后 Kickuth 根区法工程化；1980s 丹麦/英国大规模推广（1987 丹麦近百座）
- 差异点: 污水在砾石床内水平潜流，不暴露表面；对有机物与 SS 去除好，硝化能力弱
- 流程步骤: 进水（化粪池/初沉出水）→ 布水区 → 潜流床（砾石 10–20 mm，芦苇）→ 集水区 → 出水；床体不排泥，有机质矿化
- 设计参数: 面积指标 3–5 m²/人口当量; 床深 0.5–0.8 m; 水力负荷 3–8 cm/d; BOD 负荷 5–10 g/(m²·d)
- 适用: 乡村、小型社区、度假村分散处理
- 优点: 无臭味蚊蝇；运行几乎无能耗；管理粗放
- 缺点: 脱氮（硝化）除磷弱；床体堵塞风险（早期粘土根区床多失败）

### 变种: 垂直流湿地 | Vertical Flow CW (VF)
- 年份: 1950s–60s（Seidel 首创，用于化粪池出水充氧，是最早的垂直流形式）
- 差异点: 间歇批式布水、垂直下渗，床体复氧充分，硝化能力强；占地最小
- 流程步骤: 进水 → 间歇布水（泵+管网洒布床面）→ 垂直渗滤（砂基质）→ 底部集水管 → 出水；可与 HF 串联成混合系统（VF 硝化 + HF 反硝化）
- 设计参数: 面积指标 1–3 m²/人口当量; 水力负荷 8–20 cm/d（间歇）; 硝化率 >90%
- 适用: 分散式高标准处理、欧洲小型市政（法国上千座两段式 VF）
- 优点: 硝化彻底；占地小
- 缺点: 需间歇泵送；反硝化需后续单元；砂基质级配要求高

## 土地处理系统 | Land Treatment Systems
- 诞生: 约 1840s（英国污水农场 sewage farms，如 1870s Edward Frankland 在 Croydon 污水农场的过滤-硝化实验奠定生物处理概念）；1871 年威尔士 Merthyr Tydvil 首个全规模间歇灌溉系统（Bailey-Denton）；美国 1887 年麻省 Medford 首个间歇砂滤
- 成熟度: 成熟（特定场景：小城镇、干旱区回用、林灌）
- 定位: 污水经土壤-植物系统净化与回用的最古老土地密集型工艺
- 简介: 污水以灌溉方式施用于土地，经土壤过滤、吸附、微生物降解与作物吸收实现净化。按水力负荷与土壤渗透性分为慢速渗滤（SR）、快速渗滤（RI）与地表漫流（OF）三类。需预处理与防地下水污染的监测井。
- 来源: https://actuary365.blob.core.windows.net/restroomrentalsvirginia/portapottyrental/manassas/index.pdf ; https://web.deu.edu.tr/atiksu/ana52/ani4041.html ; https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf

### 变种: 慢速渗滤 | Slow Rate (SR) Irrigation
- 年份: 1840s 起（污水农场传统形式）
- 差异点: 低负荷灌溉农田/林地，净化+回用一体；作物吸收氮磷
- 流程步骤: 进水 → 初沉/稳定塘 → 贮水池 → 灌溉管网（喷灌/沟灌）→ 土壤-作物系统 → 蒸散/深层渗透；污泥塘渣定期清理
- 设计参数: 年负荷 0.5–6 m/年; 周负荷 1–10 cm/周; BOD 负荷极低; 面积 20–200 ha/(1000 m³·d)
- 适用: 干旱半干旱区农业回用、林地灌溉
- 优点: 水肥双收；出水水质极佳
- 缺点: 占地最大；受作物季节与降雨量约束

### 变种: 快速渗滤 | Rapid Infiltration (RI)
- 年份: 约 1870s（间歇渗滤概念）/ 20 世纪系统化
- 差异点: 高负荷入渗砂质土，主要为地下水回补或回收，不依赖作物
- 流程步骤: 进水 → 一级/二级处理 → 渗滤池（批式充水-落干循环）→ 地下渗流 → 回收井/自然补给
- 设计参数: 水力负荷 6–125 m/年; 充水:落干周期 1–7 d 量级; 土壤渗透系数要求高
- 适用: 砂质土壤区、地下水回补
- 优点: 占地小于 SR；除氮好（干湿交替）
- 缺点: 对土壤条件挑剔；重金属长期累积需监控

### 变种: 地表漫流 | Overland Flow (OF)
- 年份: 约 1960s（美国 USDA/EPA 系统化）
- 差异点: 污水沿缓坡草地坡面薄层漫流，坡底收集；适用于弱透水土壤
- 流程步骤: 进水 → 格栅/沉砂 → 坡面布水（上部喷淋）→ 草坡漫流（坡长 30–60 m，坡降 2–8%）→ 坡底集水沟 → 消毒/排放
- 设计参数: 水力负荷 3–20 m³/(m·d) 每米坡宽; 坡长 30–60 m
- 适用: 粘土区小城镇、食品工业废水
- 优点: 不需渗透土壤；除 SS/BOD 好
- 缺点: 脱氮除磷一般；雨季运行受限

## 化粪池与双层沉淀池 | Septic Tank & Two-Storey (Travis/Imhoff) Tanks
- 诞生: 1860（法国 L.H. Mouras 设计水封粪池"fosses Mouras"；1881 年《Cosmos》期刊报道其"自动清掏器"厌氧液化效应）；1895（英国 Exeter 市测量师 Donald Cameron 与 Cummins 专利并命名"septic tank"）；1904（Travis 双层池，英国 Hampton）；1905–1906（Karl Imhoff 双层沉淀池/隐化池，德国 Emscher 流域局）
- 成熟度: 经典（化粪池至今全球分散处理标配；Imhoff 池在 1930s 末占美国处理厂近半，现为小型厂保留方案）
- 定位: 沉淀与厌氧消化合一的最早期污水（污泥）处理构筑物
- 简介: 化粪池让污水在密闭池中停留 1–2 d，固体沉降并厌氧液化；双层池（Travis/Imhoff）把沉淀室（上）与消化室（下）竖向叠置，污泥经缝口落入下层厌氧消化，消化气从侧室排出。Imhoff 池首次实现"水流与污泥消化分室"，是污泥单独消化的前身。
- 来源: https://sleigh-munoz.co.uk/wash/Mara/History/HistSewTreat.pdf ; https://catalogimages.wiley.com/images/db/pdf/9780813823461.excerpt.pdf ; https://anaerobic-digestion.com/septic-tanks-anaerobic-digestors/

### 变种: 化粪池 | Septic Tank
- 年份: 1860（Mouras 原型）/1895（Cameron 专利命名）
- 差异点: 单/多室密闭池，沉淀+厌氧液化一体；出水去渗滤场/湿地
- 流程步骤: 入户污水 → 化粪池（2–3 室，HRT 24–48 h）→ 出水 → 土壤渗滤场/人工湿地；积泥（1–3 年）→ 吸污车 → 污水厂污泥线
- 设计参数: HRT=24–48 h; 容积≈1 m³/人 + 清掏周期储泥容积; SS 去除 50–70%; BOD 去除 30–50%
- 适用: 无管网地区单户/小社区
- 优点: 无能耗、无运行费；构造极简
- 缺点: 出水仍有机耗氧高；渗滤场占地与地下水风险

### 变种: Travis 双层池 | Travis Tank (Two-Storey Septic Tank)
- 年份: 1904（英国 Hampton，W.O. Travis）
- 差异点: 首次将沉淀与污泥消化上下分室，污泥缝口落入消化室
- 流程步骤: 进水 → 上层沉淀室 → 出水；污泥经缝隙 → 下层消化室（厌氧消化）→ 定期排熟污泥 → 干化场
- 设计参数: 沉淀 HRT=2–4 h; 消化室储泥 60–120 d
- 适用: 19 世纪末–20 世纪初小型市政厂（历史）
- 优点: 占地省；污泥初步稳定
- 缺点: 消化室翻渣易污染出水；被 Imhoff 池与独立消化池取代

### 变种: 隐化池（Imhoff 池/双层沉淀池）| Imhoff Tank
- 年份: 1905–1906（德国 Karl Imhoff，Emscher 流域局；文献记 1905 与 1906 两种，见自查表）
- 差异点: 改进 Travis：沉淀室斗底缝隙不积泥、消化室设气室与排泥管，出水不受消化干扰
- 流程步骤: 进水 → 沉淀室（V 形斗底）→ 出水去滤池/水体；污泥缝隙 → 消化室（厌氧消化 30–60 d）→ 熟污泥 → 干化床 → 农用；沼气 → 逸散或收集
- 设计参数: 沉淀室 HRT=1.5–2.5 h，表面负荷 1–1.5 m³/(m²·h); 消化室容积按 0.05–0.1 m³/人; 池总深 7–10 m
- 适用: 小型市政厂（<1 万 m³/d）、发展中国家
- 优点: 单构筑物完成一级处理+污泥消化；无机电设备
- 缺点: 池深大、土建贵；夏季浮渣臭味；出水仅一级水平

## 厌氧处理大家族 | Anaerobic Treatment Family
- 诞生: 1881（Mouras 自动清掏器，法国，首次全规模厌氧处理生活污水）；1895（Cameron 化粪池收集甲烷照明）；1927（德国 Essen-Rellinghausen 首个加热独立污泥消化池）；1950（Stander 提出 SRT 概念，奠基高速厌氧）；1955（Schroepfer 厌氧接触法）；1969（Young & McCarty 厌氧滤池 AF）；1974–1977（Lettinga 瓦赫宁根大学 UASB）；1981–1982（McCarty & Bachmann 斯坦福大学 ABR）；约 1992（van der Last & Lettinga EGSB）；1986/1990s（Paques 公司 IC 反应器）
- 成熟度: 成熟商用（工业高浓度废水的主流前段工艺；市政污泥消化标配）
- 定位: 无氧条件下有机物经水解-酸化-产乙酸-产甲烷四阶段降解产沼气的工艺族
- 简介: 厌氧工艺把 SRT 与 HRT 解耦，使慢生长的产甲烷菌得以持留：消化池靠长 HRT，厌氧接触靠污泥回流，AF 靠填料挂膜，UASB/EGSB/IC 靠颗粒污泥自固定化，ABR 靠隔室折流。容积负荷从消化池的 1–2 kgCOD/(m³·d) 提高到 IC 的 20–30 kgCOD/(m³·d)。
- 来源: https://catalogimages.wiley.com/images/db/pdf/9780813823461.excerpt.pdf ; https://pubmed.ncbi.nlm.nih.gov/12397675/ ; https://link.springer.com/article/10.1007/s11157-015-9375-5 ; https://www.apec.org/docs/default-source/Publications/2009/11/Workshop-and-Report-on-Implications-of-Biorefineries-for-Energy-and-Trade-in-the-APEC-Region-Novembe/09_ewg_Implications_Bio-refineries_Energy-and-Trade.pdf

### 变种: 标准（低速）厌氧消化 | Standard-Rate (Low-Rate) Digestion
- 年份: 1927（德国 Essen-Rellinghausen 首座加热消化池）
- 差异点: 不搅拌或间歇搅拌，分层（浮渣-清液-消化层），HRT 30–60 d
- 流程步骤: 初沉+剩余污泥 → 消化池（加热 33–35 ℃，不搅拌）→ 消化污泥 → 贮泥/脱水；上清液 → 回流污水线；沼气 → 利用
- 设计参数: HRT=30–60 d; 负荷 0.5–1.6 kgVS/(m³·d); 温度 33–35 ℃
- 适用: 小型污水厂污泥稳定（历史主流）
- 优点: 简单、运行费低
- 缺点: 池容大；易分层短路、效率低

### 变种: 高速完全混合消化 | High-Rate Completely Mixed Digestion (CSTR Digester)
- 年份: 约 1930s–1950s（搅拌+加热成为标配）
- 差异点: 连续搅拌、全混合、恒定温度，负荷提高 3–5 倍；常两级串联（一级消化、二级储泥）
- 流程步骤: 污泥 → 一级消化池（35 ℃ 中温或 55 ℃ 高温，搅拌，HRT 15–20 d）→ 二级消化/储泥池 → 脱水；沼气 → 锅炉/发电；上清液回流
- 设计参数: HRT=15–20 d（中温）/ 10–15 d（高温）; 负荷 1.6–4.8 kgVS/(m³·d); VS 破坏率 45–60%; 产气 0.8–1.1 m³/kgVS
- 适用: 大中型市政厂污泥稳定（当今主流）
- 优点: 稳定高效；产沼气能源化
- 缺点: 投资与温控能耗；浮渣泡沫管理

### 变种: 厌氧接触法 | Anaerobic Contact Process
- 年份: 1955（美国 Schroepfer 等提出；1960s 食品工业废水推广）
- 差异点: 消化池后加沉淀池与污泥回流，SRT 与 HRT 解耦，可处理溶解性有机废水
- 流程步骤: 废水 → 厌氧接触池（35 ℃，搅拌）→ 脱气器 → 沉淀池 → 出水；厌氧污泥回流 / 剩余污泥排放
- 设计参数: HRT=12–24 h; SRT=20–50 d; 负荷 1–5 kgCOD/(m³·d); MLSS=5000–10000 mg/L
- 适用: 高浓度溶解性工业废水（屠宰、酿酒）
- 优点: 比消化池负荷高；出水稳定
- 缺点: 厌氧污泥难沉降（气泡夹带）；脱气器增加复杂度

### 变种: 厌氧滤池 AF | Anaerobic Filter
- 年份: 1969（美国 Young & McCarty；首个全规模 1970s，1982 年 Bacardi 10 万 m³ 酒厂废水工程）
- 差异点: 上向流填料挂膜持留生物量，无污泥回流；微生物以生物膜+截留絮体存在
- 流程步骤: 废水 → 厌氧滤池（填料层，上流）→ 出水；顶部集气；定期反冲/排泥
- 设计参数: HRT=1–3 d; 容积负荷 2–10 kgCOD/(m³·d); 填料比表面积 90–300 m²/m³
- 适用: 低到中等浓度溶解性废水、制药/化工废水
- 优点: 无需三相分离器；耐冲击与毒物
- 缺点: 填料堵塞风险；不适合高 SS 废水

### 变种: 升流式厌氧污泥床 UASB | Upflow Anaerobic Sludge Blanket
- 年份: 1974（荷兰瓦赫宁根大学 Gatze Lettinga 团队开发）/1977（开始工程应用；1980 年 Lettinga 等发表系统论文；1983 年首用于造纸废水）
- 差异点: 无填料，靠颗粒污泥（沉降速度 10–80 m/h）与顶部三相分离器持留生物量；结构最简的高速厌氧工艺
- 流程步骤: 废水 → 底部布水系统 → 污泥床层（颗粒污泥，上流 0.5–1.5 m/h）→ 三相分离器（气/固/液分离）→ 出水；沼气 → 收集利用；剩余颗粒污泥 → 排放（可作种泥出售）
- 设计参数: HRT=4–12 h; SRT=30–100+ d; 容积负荷 4–15 kgCOD/(m³·d)（颗粒污泥可达 25）; 上流速度 0.5–1.5 m/h; MLSS 可达 80 g/L（床层）
- 适用: 食品、酿造、造纸等高浓度工业废水；热带/亚热带市政污水（巴西、印度大量应用）
- 优点: 无填料、能耗近零、产沼气；占地小；全球装机最多的高速厌氧工艺
- 缺点: 颗粒污泥培养启动慢（2–6 个月）；不耐高 SS；出水需后处理（无脱氮除磷）

### 变种: 膨胀颗粒污泥床 EGSB | Expanded Granular Sludge Bed
- 年份: 约 1992（van der Last & Lettinga；部分中文文献记 1981，见自查表）
- 差异点: 高径比加大+出水回流，上流速度 2.5–6 m/h 使颗粒床膨胀，传质显著改善；适于低浓度与低温废水
- 流程步骤: 废水+回流出水 → 底部布水 → 膨胀颗粒床 → 三相分离器 → 出水（部分回流稀释）→ 后续；沼气收集
- 设计参数: 上流速度 2.5–6 m/h; 高径比 >5; 容积负荷 10–30 kgCOD/(m³·d); HRT=2–8 h
- 适用: 低浓度、低温废水；含微量毒物废水（稀释效应）
- 优点: 负荷高于 UASB；低温适应好
- 缺点: 回流泵能耗；对颗粒沉降性能要求更高

### 变种: 内循环厌氧反应器 IC | Internal Circulation Reactor
- 年份: 1986（Vellinga 等提出概念）/1990s（荷兰 Paques 公司商业化 BIOPAQ IC）
- 差异点: 相当于上下两级 UASB 叠置，利用下层沼气气提实现内循环稀释进水；两级三相分离
- 流程步骤: 废水 → 底部混合区 → 下层高负荷反应区（膨胀床）→ 下层三相分离（沼气经上升管气提内循环）→ 上层精制区 → 上层三相分离 → 出水；沼气 → 气液分离器 → 收集；泥水经下降管回流底部
- 设计参数: 上流速度 10–30 m/h; 容积负荷 15–30 kgCOD/(m³·d); 高度 16–25 m
- 适用: 超高浓度工业废水（啤酒、淀粉、造纸）
- 优点: 负荷族内最高；占地最小；抗冲击（内循环稀释）
- 缺点: 结构复杂、投资高；需专业调试

### 变种: 厌氧折流板反应器 ABR | Anaerobic Baffled Reactor
- 年份: 1981–1982（美国斯坦福大学 McCarty & Bachmann 等）
- 差异点: 竖向折流板分隔成 4–8 个串联隔室，各室为独立上流污泥床，实现产酸/产甲烷相沿程分离（分阶段多相厌氧 SMPA 思想）
- 流程步骤: 废水 → 隔室 1（下流-上流折流，酸化为主）→ 隔室 2–4（渐次产甲烷）→ 末隔室 → 出水（可设沉淀室）；各室沼气汇总收集；污泥基本不流失，定期排泥
- 设计参数: HRT=6–20 h; SRT 可达 100 d; 容积负荷 5–30 kgCOD/(m³·d); 隔室上流速度约 1–2 m/h
- 适用: 高浓度难降解、有毒工业废水；热带分散式市政污水前段
- 优点: 无运动部件与三相分离器、结构简单；相分离提高稳定性与抗毒性
- 缺点: 首格负荷过高易酸化；布水均匀性随规模放大变差

## 消毒工艺 | Disinfection
- 诞生: 污水加氯 1835（英国早期实验）→ 1906（Phelps 在美国演示污水氯化消毒）→ 1914（美国首个出水液氯消毒工程）；臭氧 1893（荷兰 Oudshoorn 首个技术规模）/1906（法国 Nice 饮用水全规模臭氧消毒，此后连续运行）；紫外 1910（法国马赛首个饮用水 UV 消毒系统；1960s 中 UV 进入污水消毒领域）
- 成熟度: 成熟（氯消毒全球装机最大；UV 为近 30 年增长最快的替代工艺；臭氧用于高标准/回用）
- 定位: 杀灭出水病原体、保障受纳水体与回用卫生安全的末端屏障
- 简介: 氯及次氯酸盐以次氯酸分子穿透细胞壁氧化灭活微生物，余氯提供持续保护但生成三卤甲烷等副产物并对水生生物有毒；臭氧氧化能力最强且无残留，但需现场制备；UV（254 nm）破坏微生物 DNA，不产生副产物但无持续余氯。
- 来源: https://www.asau.ru/files/pdf/2638035.pdf ; https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf ; https://ui.adsabs.harvard.edu/abs/1981JAWWA..73a..44R/abstract ; https://link.springer.com/chapter/10.1007/978-3-642-01999-9_1

### 变种: 液氯/次氯酸盐消毒 | Chlorination (Cl₂ / NaOCl)
- 年份: 1906（Phelps 污水氯化演示）/1914（美国首个出水液氯工程）
- 差异点: 化学氧化灭活+余氯持续；需接触池与（可选）脱氯
- 流程步骤: 二级出水 → 加氯混合（Cl₂ 或 NaOCl）→ 接触池（HRT 15–30 min）→ 脱氯（SO₂/亚硫酸氢钠，可选）→ 排放
- 设计参数: 投氯量 2–10 mg/L（污水）; 接触时间 15–30 min; 余氯 0.2–1.0 mg/L
- 适用: 大中型厂、需余氯防护的回用系统
- 优点: 成本最低、技术最成熟；有余氯保护
- 缺点: THMs 等消毒副产物；余氯对鱼类有毒；氯气储运安全

### 变种: 二氧化氯消毒 | Chlorine Dioxide
- 年份: 约 1940s（饮用水）→ 1970s 起污水应用
- 差异点: 选择性氧化，不生成氯代副产物；现场发生（亚氯酸钠+氯/盐酸）
- 流程步骤: 出水 → ClO₂ 投加混合 → 接触池 → 排放
- 设计参数: 投加 1–5 mg/L; 接触 15–30 min
- 适用: 对副产物敏感的排放场景
- 优点: 副产物少；pH 适应范围宽
- 缺点: 现场制备成本；亚氯酸根残留限值

### 变种: 紫外消毒 | UV Disinfection
- 年份: 1910（马赛饮用水首套）；约 1960s 中（污水消毒起步）；1980s–90s 大规模替代氯
- 差异点: 物理灭活（DNA 胸腺嘧啶二聚体），无化学残留；低压/中压汞灯明渠浸没式
- 流程步骤: 二级出水 →（必要时过滤提质）→ UV 明渠（浸没灯管组）→ 排放
- 设计参数: 剂量 20–40 mJ/cm²（污水）; 透光率要求 ≥60–65%; 接触时间数秒
- 适用: 对受纳水体生态敏感的排放、中水回用
- 优点: 无副产物、无余氯毒性；接触时间极短、占地小
- 缺点: 无持续消毒能力；灯管结垢需清洗；受 SS/透光率影响大

### 变种: 臭氧消毒 | Ozonation
- 年份: 1893（Oudshoorn 技术规模）/1906（Nice 饮用水全规模）；污水领域 1970s 起
- 差异点: 氧化能力最强，兼脱色除臭与微污染物氧化；现场电晕放电制备、尾气破坏
- 流程步骤: 二级出水 → 臭氧接触池（鼓泡/射流，HRT 5–15 min）→ 尾气破坏器 → 排放
- 设计参数: 投加 5–20 mg/L（污水）; 接触 5–15 min; 转移效率 85–95%
- 适用: 高标准回用、脱色除嗅、微量污染物削减（欧洲第四代提标）
- 优点: 消毒最强；无残留副产物（溴酸盐除外）；改善感官
- 缺点: 能耗与投资最高；溴酸盐风险（含溴水）；无余氯

## 污泥浓缩、稳定与脱水 | Sludge Thickening, Stabilization & Dewatering
- 诞生: 1905–06（Imhoff 池消化）；1921（美国 Milwaukee 真空过滤与离心机械脱水）；1927（加热消化池）；约 1930s（好氧消化、气浮浓缩）；1970s（带式压滤、离心脱水普及）
- 成熟度: 成熟
- 定位: 污泥减量化-稳定化-无害化的标准处理链
- 简介: 污泥含水率 99% 左右，处理链为：浓缩（降至 94–97%）→ 稳定（厌氧/好氧消化或石灰稳定）→ 调理（投加聚合物/铁盐）→ 脱水（降至 75–85%）→ 处置或干化。浓缩分重力、气浮与机械三类；消化产沼气回收能源；脱水以带式压滤、离心、板框为主。
- 来源: https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf ; https://priodeep.weebly.com/uploads/6/5/4/9/65495087/handbook-of-water-and-waste-water-microbiology-141024064919-conversion-gate01_-_copy.pdf

### 变种: 重力浓缩 | Gravity Thickening
- 年份: 约 1920s 起标配
- 差异点: 竖流/辐流浓缩池，靠沉降压缩，适合初沉污泥
- 流程步骤: 初沉/混合污泥 → 浓缩池（栅条慢搅）→ 浓缩污泥（含固 3–6%）→ 消化；上清液回流污水线
- 设计参数: 固体负荷 20–60 kg/(m²·d)（初沉泥可至 90–120）; HRT=12–24 h
- 适用: 初沉污泥与混合污泥
- 优点: 简单低耗
- 缺点: 剩余活性污泥浓缩效果差（仅 2–2.5%）；臭味

### 变种: 气浮浓缩 | Dissolved Air Flotation (DAF) Thickening
- 年份: 约 1950s 起用于剩余污泥
- 差异点: 加压溶气释放微气泡携带轻质活性污泥上浮，适合难沉降的剩余污泥
- 流程步骤: 剩余污泥 → 溶气气浮池（投聚合物）→ 浮渣刮除（含固 3–5%）→ 消化/脱水；清液回流
- 设计参数: 固体负荷 10–25 kg/(m²·h·级); 气固比 0.01–0.04; HRT=15–30 min
- 适用: 纯活性污泥法（氧化沟/SBR）剩余污泥
- 优点: 浓缩快、含固率高于重力式；释磷臭味小
- 缺点: 能耗与药耗

### 变种: 好氧消化 | Aerobic Digestion
- 年份: 约 1950s–60s（小型厂推广）
- 差异点: 敞池曝气让污泥内源呼吸矿化，不产沼气；适合无初沉池的小厂
- 流程步骤: 剩余污泥 → 好氧消化池（曝气 15–20 d）→ 静置浓缩 → 脱水 → 处置
- 设计参数: SRT=15–20 d（中温）; VS 破坏率 30–50%; 曝气功率 20–40 W/m³
- 适用: <5000 人口当量小厂
- 优点: 无臭、上清液质量好；操作简单
- 缺点: 能耗高、不产能；低温效果差

### 变种: 机械脱水（带式/离心/板框）| Mechanical Dewatering (Belt Press / Centrifuge / Filter Press)
- 年份: 1921（真空过滤与离心机，Milwaukee）；1970s（带式压滤机普及）；板框为 19 世纪工业压滤演变
- 差异点: 带式靠滤带挤压（连续）、离心靠离心力（密闭）、板框靠高压压榨（含固最高）
- 流程步骤: 消化/浓缩污泥 → 调理（聚合物 2–8 kg/tDS）→ 脱水机 → 泥饼（带式 16–22%、离心 20–30%、板框 30–45% 含固）→ 外运处置；滤液回流
- 设计参数: 带式进泥含固 2–4%; 离心差速 5–20 rpm; 板框压榨 0.6–1.6 MPa
- 适用: 一切污水厂污泥减量
- 优点: 连续化、占地小（离心/板框）
- 缺点: 药耗；板框间歇操作人工大

## 污泥处置与资源化 | Sludge Disposal & Beneficial Use
- 诞生: 堆肥 1924–1931（印度 Indore 植物产业研究所 Albert Howard & Y.D. Wad 创立 Indore 法；1918 起英国 Sams 已试污泥堆肥专利）；干化床 19 世纪沿用至今；焚烧 1930s 初（美国芝加哥首批污泥烘干与焚烧工程；多膛炉 1930s 起）；土地利用（1840s 污水农场即为污泥农田利用前身）
- 成熟度: 成熟（路线选择取决于法规：欧盟/北美以土地利用与焚烧为主，填埋趋于禁止）
- 定位: 污泥的最终出路——减容、稳定与养分/能源回收
- 简介: 脱水泥饼的出路包括：土地利用（农肥/园林绿化，受重金属与病原体标准约束）、好氧堆肥（55–65 ℃ 高温杀菌制肥）、热干化（100–300 ℃ 蒸发至含固 90%+，制颗粒肥或燃料）、焚烧（多膛炉/流化床，850 ℃ 以上彻底减容并可发电）、卫生填埋（日趋受限）。处置路线须与前端稳定化匹配。
- 来源: https://pmc.ncbi.nlm.nih.gov/articles/PMC7617516/ ; https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf ; https://rke.abertay.ac.uk/ws/portalfiles/portal/15228568/Irvine_2002_Temperature_and_physical_modelling_studies_PhD.pdf

### 变种: 好氧堆肥 | Composting (Windrow / In-vessel)
- 年份: 1924–1931（Indore 法创立）；1950s–70s 污泥堆肥工业化（条垛/仓式）
- 差异点: 污泥与调理剂（秸秆/木屑）混合，好氧发酵升温至 55–65 ℃ 灭活病原体，4–8 周腐熟
- 流程步骤: 脱水污泥（含固 20%+）→ 混合调理剂（C/N 25–35）→ 条垛/发酵仓（翻堆或强制通风）→ 高温期（55–65 ℃，≥3–15 d）→ 腐熟陈化（2–4 周）→ 筛分 → 有机肥
- 设计参数: C/N=25–35; 含水率 55–65%; 温度 55–65 ℃ 维持 ≥3 d（仓式）/15 d（条垛）; 周期 4–8 周
- 适用: 中小厂、农业区就近消纳
- 优点: 产品可销售；病原体灭活彻底
- 缺点: 占地与臭味管理；重金属制约农用

### 变种: 热干化 | Thermal Drying
- 年份: 1930s（首批污泥烘干工程，芝加哥）；1970s–90s 流化床/带式干化成套化
- 差异点: 直接/间接加热把泥饼含水率降至 5–15%，制颗粒，体积缩减至 1/4–1/5
- 流程步骤: 脱水污泥 → 干化机（流化床/带式/桨叶，200–300 ℃ 热风或导热油）→ 颗粒产品（含固 90–95%）→ 肥料/燃料；尾气 → 冷凝除臭 → 污水线
- 设计参数: 蒸发能耗 ≈700–900 kWh/t 水; 产品含固 90–95%; 颗粒粒径 2–6 mm
- 适用: 长距离运输、土地利用或焚烧前预处理
- 优点: 产品卫生化、易储运；减容最大
- 缺点: 能耗高；粉尘爆炸风险管控

### 变种: 焚烧 | Incineration (Multiple-Hearth / Fluidized Bed)
- 年份: 1930s 初（芝加哥首批污泥焚烧；多膛炉 1930s、流化床炉 1960s 起）
- 差异点: 多膛炉层落式焚烧 vs 流化床剧烈混合焚烧；彻底矿化有机物，灰烬减量 90%
- 流程步骤: 脱水污泥（含固 20–30%）→ 焚烧炉（850–950 ℃）→ 灰烬 → 填埋/磷回收；烟气 → 余热锅炉 → 除尘 → 脱酸脱硝 → 排放
- 设计参数: 炉温 850–950 ℃; 自持燃烧要求泥饼热值（消化污泥需辅助燃料）; 灰分为绝干污泥 25–45%
- 适用: 大城市污泥、重金属超标不可农用污泥
- 优点: 减容最彻底；可发电供热；灰中可回收磷
- 缺点: 烟气治理投资大；公众接受度低

### 变种: 卫生填埋 | Sanitary Landfill
- 年份: 20 世纪上半叶沿用至今（欧盟 2020s 起多国禁止有机质填埋）
- 差异点: 泥饼与垃圾混填或专区填埋，需防渗与渗滤液收集
- 流程步骤: 脱水/石灰稳定污泥 → 运输 → 填埋场（摊铺压实、日覆盖）→ 渗滤液收集回污水厂；填埋气收集
- 设计参数: 入场含固率要求 ≥30–40%（多数法规）
- 适用: 应急与兜底处置
- 优点: 简单、兜底可靠
- 缺点: 占地、渗滤液风险；法规日趋禁止

### 变种: 土地利用 | Land Application (Biosolids)
- 年份: 1840s 起（污水农场传统）；1970s 起规范化（美国 40 CFR Part 503 等）
- 差异点: 消化/堆肥稳定后的生物泥作为土壤改良剂与缓释肥；分 A 级（可接触）/B 级（限用）
- 流程步骤: 消化/堆肥污泥 → 检测（重金属、病原体）→ 撒施/注入农田林地 → 土壤-作物利用；轮作与施用率受氮负荷控制
- 设计参数: 年施用率 2–70 tDS/(ha·a)（按氮磷负荷与土壤）；重金属限值执行国标（如 GB 4284）
- 适用: 农业区、矿山修复、园林绿化
- 优点: 养分循环、成本最低；碳足迹小
- 缺点: 重金属/微污染物长期累积争议；公众与法规敏感
