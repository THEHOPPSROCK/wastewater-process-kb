# 37. 厌氧-好氧-缺氧工艺（AOA） | Anaerobic-Oxic-Anoxic (AOA) Process

- 诞生: 2015（2012 年发现后置内源反硝化现象，2014 年形成 AOA 运行模式，2015 年建立污泥双回流 AOA 系统）
- 成熟度: 商业化初期
- 族/周期: 悬浮生长生物 / 2010s-至今
- 定位: 把 A²/O 的缺氧段整体后移到流程末端，形成「厌氧储碳 → 好氧硝化吸磷 → 缺氧内源反硝化」，用胞内碳源替代外加碳源，在低碳氮比条件下实现深度脱氮除磷
- 简介: 对传统 A²/O「厌氧—缺氧—好氧」的结构性重排，改为「厌氧—好氧—缺氧」，把反硝化段整体后置。厌氧段反硝化菌（DNB）与聚磷菌（PAOs）把原水有机物转化为 PHA、糖原等胞内碳源并释放磷酸盐，同时用原水碳源去除回流污泥携带的硝态氮；好氧段由 AOB/NOB 完成硝化、PAOs 分解胞内碳源过量吸磷（靠排放富磷剩余污泥除磷），HRT 被刻意压缩以免内碳源被氧化；末端缺氧段反硝化菌与反硝化聚磷菌（DPAO/DGAO）分解胞内碳源完成内源反硝化与反硝化除磷，实现「一碳两用」。三项判别特征：①无好氧区至缺氧区的硝化液内回流；②好氧区 HRT 远小于缺氧区；③碳源全部来自原水，后置缺氧区是强化脱氮的关键。因取消内回流，脱氮率不再受回流比阈值限制，理论上可接近 100%。实测进水 C/N=2.67 时氮去除率 97.7%、出水 TIN 1.56 mg/L；C/N=5 的百吨级中试近 300 d 稳定运行，出水 TN 3.60±1.55、TP 0.24±0.13 mg/L。主要功能菌为 Tetrasphaera（PAO）与 Candidatus Competibacter（GAO）。工程侧已由北控水务与北京工业大学转化为 BEAOA 技术产品，2021 年首座 3 万 m³/d 污水厂投运，至 2025 年全国已有 12 座新建或改造污水厂采用（分布于深圳、中山、东莞、贵阳、宜兴、济南、洛阳等地）；深圳滨河水质净化厂 30 万 m³/d 生产线二沉池出水 TN 日均 2.19 mg/L、脱氮效率 94.8%，较同厂 AAO 工艺电耗降约 15.1%、药剂成本降约 91.2%、污泥处理处置成本降约 17.1%。当前待突破方向为除磷稳定性、低温调控策略与 N₂O/CH₄ 等温室气体排放评估。（综述：高歆婕, 彭永臻. 厌氧-好氧-缺氧(AOA)污水处理工艺的原理、发展与应用. 给水排水, 2025, 51(10): 27-35）

### 变种: 污泥双回流 AOA（SDR-AOA，初代模型） | Sludge Double Recirculation AOA (SDR-AOA)

- 年份: 2015
- 差异点: 连续流 AOA 反应器 + 二沉池，污泥回流分两路：第一路回厌氧区前端提供活性污泥，第二路回后置缺氧区，把二沉池的低 DO 污泥引入缺氧段以提高污泥浓度与内源反硝化速率；缺氧段反硝化速率由 0.1 提升至 0.17 kgN/(m³·d)，是 AOA 技术的初代模型
- 流程: 进水（原水）〔水〕 → 厌氧区（储碳+释磷）〔水〕 → 好氧区（硝化+吸磷）〔水〕 → 后置缺氧区（内源反硝化）〔水〕 → 二沉池 → 出水〔水〕 → 污泥回流①：二沉池→厌氧区前端〔回流〕 → 污泥回流②：二沉池→后置缺氧区〔回流〕 → WAS 富磷污泥→污泥线〔泥〕
- 设计参数: 厌氧:好氧:缺氧 体积比 1:1:2（海口百吨级中试，总 HRT≈10.8 h）; SRT=25–35 d; 第一污泥回流比 50%–100%、第二回流比 100%–150%（第二回流由 100% 提至 150%，TIN 去除率 86.91%→91.81%；取消第二回流则 TIN 去除率降 16.4%）; 无好氧→缺氧硝化液内回流; 进水 C/N=2.7–5.0
- 适用: 低碳氮比（C/N=3–5）城镇污水厂的新建与提标改造；低温地区（15 ℃ 仍达 83.45% 的 TIN 去除率）
- 优点: 第二回流直击后置缺氧段，脱氮率比单回流高约 16 个百分点；零外加碳源，进水 C/N=2.67 时氮去除率达 97.7%；无硝化液内回流，省去内回流泵能耗
- 缺点: 内源反硝化速率慢，缺氧区容积占比大（约占全池一半）；双回流增加管路布置与运行控制复杂度

### 变种: 单污泥回流 AOA | Single Sludge Recirculation AOA

- 年份: 2015–2020（AOA 迭代期）
- 差异点: 取消回后置缺氧区的第二污泥回流，仅保留至厌氧区前端的一路回流，流程与控制最简；同工况下 TIN 去除率降至 79.4%，从反面印证了第二回流对后置缺氧脱氮的贡献
- 流程: 进水（原水）〔水〕 → 厌氧区（储碳+释磷）〔水〕 → 好氧区（硝化+吸磷）〔水〕 → 后置缺氧区（内源反硝化）〔水〕 → 二沉池 → 出水〔水〕 → 污泥回流：二沉池→厌氧区前端〔回流〕 → WAS 富磷污泥→污泥线〔泥〕
- 设计参数: 污泥回流比 50%–100%; 重庆百吨级中试按厌氧:好氧:缺氧=3:3:4、SRT=10–30 d 运行，实现 TN 去除 90.4%、TP 去除 96.0%; 需靠提高整体 MLSS 补偿后置缺氧段的污泥浓度
- 适用: 占地与投资受限的存量厂原位改造；进水碳源相对充足的中高 C/N 污水
- 优点: 流程最简、管路与回流泵能耗最少；运行控制难度低，便于既有工艺原位改造
- 缺点: 缺氧段污泥浓度偏低，脱氮率比双回流低约 10–16 个百分点；对进水碳源与水温更加敏感

### 变种: AOAO（后置好氧型） | Anaerobic-Oxic-Anoxic-Oxic (AOAO)

- 年份: 2015–2020（AOA 迭代期）
- 差异点: 在后置缺氧区之后再接一段短时曝气，用于改善污泥沉降性能、抑制二沉池反硝化浮泥，并吹脱残余氨氮与磷，解决后置缺氧段容易带来的浮泥与氨氮穿透问题
- 流程: 进水（原水）〔水〕 → 厌氧区（储碳+释磷）〔水〕 → 好氧区（硝化+吸磷）〔水〕 → 缺氧区（内源反硝化）〔水〕 → 后置好氧区（复氧+吹脱）〔辅助〕 → 二沉池 → 出水〔水〕 → 污泥回流：二沉池→厌氧区/缺氧区〔回流〕 → WAS 富磷污泥→污泥线〔泥〕
- 设计参数: 后置好氧 HRT≈0.5–1 h（远小于缺氧段）; DO=1.0–2.0 mg/L; 其余参数同污泥双回流 AOA; 中山百吨级中试采用 AOA/AOAO 可切换运行
- 适用: 对出水氨氮与 SS 稳定性要求高、易发生反硝化浮泥的污水厂
- 优点: 污泥沉降性与出水 SS 明显改善；出水氨氮、磷更稳定，达标裕度更大
- 缺点: 增设一段曝气，部分内碳源被氧化，脱氮率可能小幅下降；增加池容与曝气能耗

### 变种: 后置内源反硝化除磷 AOA（好氧区投载体） | Post-Endogenous Denitrification & P Removal AOA (post-EDPR)

- 年份: 2018
- 差异点: 好氧区投加悬浮生物载体富集硝化菌，用低 DO（1–2 mg/L）促成同步硝化反硝化，并把好氧 HRT 压到极短，避免 PHA 被过度氧化，把内碳源留给后置缺氧段；处理 C/N=4.4 实际生活污水连续运行 132 d
- 流程: 进水（原水）〔水〕 → 厌氧区（3.1 h）〔水〕 → 好氧区（3.9 h，投载体低 DO）〔水〕 → 缺氧区（7 h，内源反硝化+反硝化除磷）〔水〕 → 二沉池 → 出水〔水〕 → 污泥回流：二沉池→厌氧区〔回流〕 → 载体截留（硝化菌富集）〔辅助〕 → WAS 富磷污泥→污泥线〔泥〕
- 设计参数: 厌氧:好氧:缺氧 HRT=3.1:3.9:7 h（好氧远小于缺氧）; 好氧 DO=1–2 mg/L; 好氧区投加悬浮生物载体; 连续运行 132 d; 出水 TIN≤3 mg/L、PO₄³⁻-P≤0.2 mg/L，去除率分别达 92.15% 与 92.67%
- 适用: 低 C/N 生活污水的强化同步脱氮除磷；需兼顾抑制 PHA 过度氧化的场合
- 优点: 低 DO + 载体实现同步硝化反硝化，节省曝气；载体富集硝化菌后好氧 HRT 可压缩，内碳源得以保全；PHA 同时服务于好氧吸磷与后置内源反硝化
- 缺点: 载体流化、拦截与更换增加运维工作量；低 DO 工况下硝化稳定性依赖精细控制

### 变种: 浓缩污泥双回流 AOA | Concentrated Sludge Double Recirculation AOA

- 年份: 约2025
- 差异点: 先把回流污泥浓缩再分两路回流，用更高的 MLSS 补偿降低的回流量，在保障脱氮效果的前提下把污泥回流比降低 40%，直接削减回流能耗，解决 AOA 回流比普遍达 100% 的能耗短板
- 流程: 进水（原水）〔水〕 → 厌氧区（储碳+释磷）〔水〕 → 好氧区（硝化+吸磷）〔水〕 → 后置缺氧区（内源反硝化）〔水〕 → 二沉池 → 出水〔水〕 → 污泥浓缩后双回流→厌氧区/缺氧区〔回流〕 → WAS 富磷污泥→污泥线〔泥〕
- 设计参数: 污泥回流比比常规 AOA 降低 40%; 出水 NH₃-N 1.22、TN 5.6、COD 22.7、TP 0.63 mg/L; 通过提升污泥浓度强化去除效能
- 适用: 回流能耗占比高、电耗压力大的大型污水厂提标改造
- 优点: 回流比降 40%，回流泵能耗显著下降；富集 Candidatus Competibacter，缺氧段内碳源反硝化能力增强
- 缺点: 需增设污泥浓缩设施，增加占地与设备；高 MLSS 对二沉池固体负荷与污泥沉降性提出更高要求

### 变种: AOA 耦合短程硝化-厌氧氨氧化（PN/A-AOA） | AOA Coupled with Partial Nitritation-Anammox (PN/A)

- 年份: 2020 至今（研发与首批中试）
- 差异点: 把 AOA 的后置缺氧内源反硝化与短程硝化耦合厌氧氨氧化（PN/A）叠加，用 Anammox 缩短生物脱氮路径，进一步压缩有机碳源与曝气需求，被视作 AOA 的下一代方向
- 流程: 进水（原水）〔水〕 → 厌氧区（储碳+释磷）〔水〕 → 好氧区（短程硝化，NO₂⁻ 累积）〔水〕 → 缺氧区（内源反硝化+厌氧氨氧化）〔水〕 → 二沉池 → 出水〔水〕 → 污泥回流：二沉池→厌氧区〔回流〕 → Anammox 污泥接种/回流〔辅助〕 → WAS 富磷污泥→污泥线〔泥〕
- 设计参数: 基于 SBR 的 AOA 模式，按短程硝化污泥与厌氧氨氧化污泥的质量配比接种; 低接种量 L-PN/A 系统 36 d 快速启动，稳定后出水 TIN 仅 2.3 mg/L、TN 去除率 95.8%; 优化模式 AOAOAO 下 NRE 提升至 80.8%; 接种量过高反而不利于功能菌选择性富集
- 适用: 低 C/N 城市污水的超低能耗深度脱氮；与主流厌氧氨氧化结合的新建污水厂
- 优点: 脱氮路径缩短，碳源与曝气需求进一步下降；好氧段与缺氧段脱氮贡献相当，负荷分配更均衡
- 缺点: 厌氧氨氧化菌富集慢，启动与调控难度大；接种配比窗口窄，过高接种量反而抑制功能菌
