# 09. 消毒工艺 | Disinfection

- 诞生: 1906（污水氯化演示）；臭氧 1893 / UV 1910
- 成熟度: 成熟主流
- 族/周期: 高级氧化与深度 / 1880-1909
- 定位: 杀灭出水病原体、保障受纳水体与回用卫生安全的末端屏障
- 简介: 氯及次氯酸盐以次氯酸分子穿透细胞壁氧化灭活微生物，余氯提供持续保护但生成三卤甲烷等副产物并对水生生物有毒；臭氧氧化能力最强且无残留，但需现场制备；UV（254 nm）破坏微生物 DNA，不产生副产物但无持续余氯。1906 年 Phelps 演示污水氯化、1914 年美国建成首个出水液氯消毒工程；臭氧 1893 年荷兰 Oudshoorn 技术规模、1906 年法国 Nice 饮用水全规模连续运行；UV 1910 年法国马赛首套饮用水系统，1960s 中进入污水消毒领域。氯消毒全球装机最大，UV 为近 30 年增长最快的替代工艺。
- 来源:
  - https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf
  - https://ui.adsabs.harvard.edu/abs/1981JAWWA..73a..44R/abstract
  - https://link.springer.com/chapter/10.1007/978-3-642-01999-9_1

共 4 个变种。

### 变种: 液氯/次氯酸盐消毒 | Chlorination (Cl₂ / NaOCl)

- 年份: 1906（演示）/1914（首个工程）
- 差异点: 化学氧化灭活+余氯持续；需接触池与（可选）脱氯
- 流程: 二级出水〔水〕 → 加氯混合（Cl₂ 或 NaOCl）〔辅助〕 → 接触池（HRT 15–30 min）〔水〕 → 脱氯（SO₂/亚硫酸氢钠，可选）〔辅助〕 → 排放〔水〕
- 设计参数: 投氯量 2–10 mg/L; 接触时间 15–30 min; 余氯 0.2–1.0 mg/L
- 适用: 大中型厂、需余氯防护的回用系统
- 优点: 成本最低、技术最成熟；有余氯保护
- 缺点: THMs 等消毒副产物；余氯对鱼类有毒；氯气储运安全

### 变种: 二氧化氯消毒 | Chlorine Dioxide

- 年份: 约1940s（饮用水）/1970s 起污水应用
- 差异点: 选择性氧化，不生成氯代副产物；现场发生（亚氯酸钠+氯/盐酸）
- 流程: 出水〔水〕 → ClO₂ 投加混合〔辅助〕 → 接触池〔水〕 → 排放〔水〕
- 设计参数: 投加 1–5 mg/L; 接触 15–30 min
- 适用: 对副产物敏感的排放场景
- 优点: 副产物少；pH 适应范围宽
- 缺点: 现场制备成本；亚氯酸根残留限值

### 变种: 紫外消毒 | UV Disinfection

- 年份: 1910（饮用水首套）/约1960s 中（污水）
- 差异点: 物理灭活（DNA 胸腺嘧啶二聚体），无化学残留；低压/中压汞灯明渠浸没式；1980s–90s 大规模替代氯
- 流程: 二级出水〔水〕 → （必要时过滤提质）〔水〕 → UV 明渠（浸没灯管组）〔辅助〕 → 排放〔水〕
- 设计参数: 剂量 20–40 mJ/cm²（污水）; 透光率要求 ≥60–65%; 接触时间数秒
- 适用: 对受纳水体生态敏感的排放、中水回用
- 优点: 无副产物、无余氯毒性；接触时间极短、占地小
- 缺点: 无持续消毒能力；灯管结垢需清洗；受 SS/透光率影响大

### 变种: 臭氧消毒 | Ozonation

- 年份: 1893/1906（饮用水）/1970s 起污水
- 差异点: 氧化能力最强，兼脱色除臭与微污染物氧化；现场电晕放电制备、尾气破坏；污水深度氧化应用见「高级氧化」大类
- 流程: 二级出水〔水〕 → 臭氧接触池（鼓泡/射流）〔辅助〕 → 尾气破坏器〔辅助〕 → 排放〔水〕
- 设计参数: 投加 5–20 mg/L（污水）; 接触 5–15 min; 转移效率 85–95%
- 适用: 高标准回用、脱色除嗅、微量污染物削减（欧洲第四代提标）
- 优点: 消毒最强；无残留副产物（溴酸盐除外）；改善感官
- 缺点: 能耗与投资最高；溴酸盐风险（含溴水）；无余氯
