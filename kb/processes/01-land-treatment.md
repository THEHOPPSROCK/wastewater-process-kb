# 01. 土地处理系统 | Land Treatment Systems

- 诞生: 约1840s
- 成熟度: 成熟经典
- 族/周期: 自然生态 / 1840s-1870s
- 定位: 污水经土壤-植物系统净化与回用的最古老土地密集型工艺
- 简介: 污水以灌溉方式施用于土地，经土壤过滤、吸附、微生物降解与作物吸收实现净化。1840s 英国污水农场为其雏形，1871 年威尔士 Merthyr Tydvil 建成首个全规模间歇灌溉系统，1887 年美国麻省 Medford 建成首个间歇砂滤。按水力负荷与土壤渗透性分为慢速渗滤（SR）、快速渗滤（RI）与地表漫流（OF）三类，需预处理并设监测井防地下水污染。
- 来源:
  - https://web.deu.edu.tr/atiksu/ana52/ani4041.html
  - https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf
  - https://actuary365.blob.core.windows.net/restroomrentalsvirginia/portapottyrental/manassas/index.pdf

共 3 个变种。

### 变种: 慢速渗滤 | Slow Rate (SR) Irrigation

- 年份: 约1840s
- 差异点: 低负荷灌溉农田/林地，净化+回用一体；作物吸收氮磷
- 流程: 进水〔水〕 → 初沉/稳定塘〔水〕 → 贮水池〔水〕 → 灌溉管网（喷灌/沟灌）〔辅助〕 → 土壤-作物系统〔水〕 → 蒸散/深层渗透〔水〕
- 设计参数: 年负荷 0.5–6 m/年; 周负荷 1–10 cm/周; 面积 20–200 ha/(1000 m³·d)
- 适用: 干旱半干旱区农业回用、林地灌溉
- 优点: 水肥双收；出水水质极佳
- 缺点: 占地最大；受作物季节与降雨量约束

### 变种: 快速渗滤 | Rapid Infiltration (RI)

- 年份: 约1870s（20 世纪系统化）
- 差异点: 高负荷入渗砂质土，主要为地下水回补或回收，不依赖作物
- 流程: 进水〔水〕 → 一级/二级处理〔水〕 → 渗滤池（批式充水-落干循环）〔水〕 → 地下渗流〔水〕 → 回收井/自然补给〔水〕
- 设计参数: 水力负荷 6–125 m/年; 充水:落干周期 1–7 d 量级; 土壤渗透系数要求高
- 适用: 砂质土壤区、地下水回补
- 优点: 占地小于慢速渗滤；干湿交替除氮好
- 缺点: 对土壤条件挑剔；重金属长期累积需监控

### 变种: 地表漫流 | Overland Flow (OF)

- 年份: 约1960s
- 差异点: 污水沿缓坡草地坡面薄层漫流，坡底收集；适用于弱透水土壤
- 流程: 进水〔水〕 → 格栅/沉砂〔水〕 → 坡面布水（上部喷淋）〔辅助〕 → 草坡漫流（坡长 30–60 m）〔水〕 → 坡底集水沟〔水〕 → 消毒/排放〔水〕
- 设计参数: 水力负荷 3–20 m³/(m·d) 每米坡宽; 坡长 30–60 m; 坡降 2–8%
- 适用: 粘土区小城镇、食品工业废水
- 优点: 不需渗透土壤；除 SS/BOD 好
- 缺点: 脱氮除磷一般；雨季运行受限
