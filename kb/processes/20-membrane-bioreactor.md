# 20. 膜生物反应器 | Membrane Bioreactor (MBR)

- 诞生: 1966（首个专利）
- 成熟度: 成熟主流
- 族/周期: 膜法 / 1950s-1960s
- 定位: 以膜分离替代二沉池的活性污泥强化工艺，占地小、出水可直接回用
- 简介: MBR 将生物反应器与微滤/超滤膜耦合，通过膜截留实现完全的固液分离，可在高 MLSS（8–15 g/L）和长 SRT 下运行，出水浊度与微生物指标接近深度处理水平。1966 年 Dorr-Oliver 申请首个专利（外置式），早期外置式因循环泵能耗高而受限；1989 年山本和夫（东京大学）提出浸没式概念后能耗大幅下降；1990 年代 Kubota（平板膜，1991 首个商业厂）与 Zenon（中空纤维 ZeeWeed，1993）先后商业化，推动 MBR 成为市政与工业废水提标改造的主流选项。主要痛点为膜污染、化学清洗与膜更换成本。

共 4 个变种。

### 变种: 外置式膜生物反应器 | Side-stream MBR (sMBR)

- 年份: 1966–1971
- 差异点: 膜组件置于生物反应器外，靠高压循环泵产生错流；通量高、易清洗，但循环能耗大（典型 2–10 kWh/m³）
- 流程: 预处理（格栅/沉砂）〔水〕 → 生物反应器（缺氧+好氧）〔水〕 → 循环泵升压〔辅助〕 → 外置管式膜错流过滤〔辅助〕 → 产水排放/回用〔水〕 → 膜浓水全量回流至生物池〔回流〕 → 剩余污泥外排至污泥线〔泥〕
- 设计参数: HRT 4–8 h; SRT 15–30 d; MLSS 8–20 g/L; 膜通量 40–120 LMH（管式）; 错流流速 2–4 m/s; 污泥产率约 0.2–0.4 kgVSS/kgCOD
- 适用: 垃圾渗滤液、食品/酿造等高浓度工业废水、小规模高标准排放
- 优点: 膜污染可控、通量高；膜检修不影响生化系统
- 缺点: 循环泵能耗高（约为浸没式的 3–10 倍）；占地与设备成本高

### 变种: 浸没式平板膜 MBR | Immersed Flat-Sheet MBR (Kubota 系)

- 年份: 1991（首个商业厂；1989 首套中试）
- 差异点: 平板膜元件直接浸没于好氧池，靠抽吸负压产水、曝气擦洗控污；无需循环泵，能耗低；单位体积膜面积低于中空纤维
- 流程: 细格栅（≤1–3 mm）〔水〕 → 缺氧池〔水〕 → 好氧膜池（平板膜浸没）〔辅助〕 → 抽吸泵负压产水（间歇，开 8 min/停 2 min）〔辅助〕 → 出水〔水〕 → 缺氧/好氧间内回流〔回流〕 → 剩余污泥排至污泥线〔泥〕
- 设计参数: HRT 6–12 h; SRT 20–40 d; MLSS 8–12 g/L; 设计通量 15–30 LMH; 膜擦洗曝气 0.3–0.6 Nm³/(m²膜·h); 综合能耗约 0.4–0.8 kWh/m³; 膜寿命 8–15 年
- 适用: 中小型市政污水、分散式处理、再生水
- 优点: 运行稳定、清洗频率低、寿命长；出水 SS 近零
- 缺点: 单位占地膜装填密度低；平板膜破损后需整片更换

### 变种: 浸没式中空纤维膜 MBR | Immersed Hollow-Fiber MBR (ZeeWeed 系)

- 年份: 1993
- 差异点: 中空纤维帘式/柱式膜（Zenon ZeeWeed ZW145），装填密度高、可反洗；PVDF 耐氯性好；需更严格细格栅防纤维缠绕
- 流程: 细格栅〔水〕 → 厌氧/缺氧/好氧（A²O 或 MLE）〔水〕 → 膜池（中空纤维浸没、曝气擦洗）〔辅助〕 → 抽吸产水〔辅助〕 → 出水消毒回用〔水〕 → 膜池混合液回流至前端（3–5Q）〔回流〕 → 剩余污泥去污泥线〔泥〕
- 设计参数: HRT 6–10 h; SRT 15–30 d; MLSS 8–15 g/L; 通量 15–25 LMH（峰值 30–40）; 反洗周期每 10–12 min; 综合能耗约 0.3–0.6 kWh/m³
- 适用: 大中型市政污水厂新建/扩容、再生水厂
- 优点: 装填密度高、占地最小；可反洗、自动化程度高
- 缺点: 对毛发/纤维类杂质敏感；膜丝断裂影响出水水质；膜更换成本占比高

### 变种: 气升式外置 MBR | Airlift / Crossflow Hybrid MBR (Norit X-Flow 等)

- 年份: 约2000s
- 差异点: 膜置于生物池外的气升回路中，用曝气代替循环泵产生错流，能耗介于浸没式与传统外置式之间
- 流程: 生化池〔水〕 → 混合液进入气升膜池〔水〕 → 底部曝气驱动循环错流〔辅助〕 → 管式膜产水〔辅助〕 → 浓水借气升回流生化池〔回流〕 → 剩余污泥去污泥线〔泥〕
- 设计参数: MLSS 8–15 g/L; 通量 30–60 LMH; 膜侧能耗约 0.2–0.5 kWh/m³
- 适用: 中型工业废水、渗滤液、对能耗敏感的升级项目
- 优点: 比传统外置式节能 50% 以上；膜易接近、易清洗
- 缺点: 市场占有少于浸没式；大规模应用业绩有限
