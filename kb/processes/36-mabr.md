# 36. 膜曝气生物膜反应器（MABR） | Membrane Aerated Biofilm Reactor

- 诞生: 2014 商业化（OxyMem，爱尔兰，都柏林大学 spin-out；2013 成立 / 2014-06 首客户 Enisca / 2019 被 DuPont 收购）；概念 1960s（Schaffer/Ludzack/Ettinger），"MABR" 命名 1999
- 成熟度: 商业化初期
- 族/周期: 固着生长生物 / 2010s-至今
- 定位: 氧气从膜内无泡扩散进生物膜，节能与同步硝化反硝化兼得
- 简介: MABR 以透气膜（中空纤维或平板）为载体，氧气从膜内侧无泡扩散，生物膜自内向外形成好氧-缺氧分层：内层硝化、外层利用碳源反硝化，实现单池同步硝化反硝化（SND）且传氧效率可达传统曝气的 3–4 倍、能耗省 50% 以上。1960s 即有概念研究，2014 年 OxyMem 实现商业化，随后 GE ZeeLung、Fluence（原 Emefcy）进入，现处于商业化初期向主流过渡阶段，主要定位为既有厂原位提标扩容的嵌件（drop-in）方案。

共 3 个变种。

### 变种: OxyMem 中空纤维 MABR | OxyMem MABR

- 年份: 2014
- 差异点: 中空纤维膜束模块，直接浸入曝气池；2014-06 首客户 Enisca（爱尔兰），2019 被 DuPont 收购
- 流程: 进水〔水〕 → 曝气池（OxyMem 膜模块浸没）〔水〕 → 二沉池〔水〕 → 出水〔水〕
- 设计参数: 传氧效率可达 60–90%; 曝气能耗省 50–70%
- 适用: 市政厂原位提标扩容、乡镇污水
- 优点: 原位嵌入不动土建；同步硝化反硝化；节能显著
- 缺点: 膜成本高；生物膜厚度控制；长期工程业绩仍在积累

### 变种: ZeeLung（GE/Suez/Veolia） | ZeeLung MABR

- 年份: 2015
- 差异点: GE 2015 WEFTEC 发布的细绳式膜丝；2017 首批商业厂 Yorkville-Bristol、Schilde（比利时）；后随水务业务转入 Suez/Veolia
- 流程: 进水〔水〕 → ZeeLung 膜帘浸没池〔水〕 → 出水〔水〕
- 设计参数: 原位提标 TN; 能耗省约 50%
- 适用: 市政提标扩容
- 优点: 大厂背书；膜丝自清洁抖动设计
- 缺点: 品牌多次易主服务连续性；专有耗材

### 变种: 平板膜 MABR（Fluence） | Flat-sheet MABR (Fluence, ex-Emefcy)

- 年份: 2016
- 差异点: 平板膜构型（原 Emefcy 2008 成立，2017 并入 Fluence），主打分散式与村镇污水一体化设备
- 流程: 进水〔水〕 → 平板 MABR 一体化箱体〔水〕 → 出水〔水〕
- 设计参数: 一体化设备吨水电耗约 0.3–0.5 kWh
- 适用: 村镇分散式污水、一体化设备
- 优点: 平板膜强度高；适合标准化设备
- 缺点: 通量密度低于中空纤维；分散运维成本
