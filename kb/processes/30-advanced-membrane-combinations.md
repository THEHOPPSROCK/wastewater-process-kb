# 30. 深度处理膜组合与高压特种膜 | UF/NF/RO Combinations, DTRO, FO, MD, ED/EDR

- 诞生: 约1990s（双膜法再生水兴起）；DTRO 1982、ED 约1950s
- 成熟度: 成熟主流
- 族/周期: 膜法 / 1990s
- 定位: 生化出水之后的「品质把关」膜家族，覆盖再生水、零排放与浓盐水减量
- 简介: 以压力驱动膜为主轴：UF 作 RO 保安过滤，NF 截留二价离子与微污染物，RO 生产高品质再生水（新加坡 NEWater 2003、美国橙郡 GWRS 2008 为标杆）；DTRO 以碟管式宽流道结构耐受垃圾渗滤液等高污染料液（Rochem 1982 研发碟管组件、1988 年德国首套渗滤液工程）；正渗透 FO 利用汲取液渗透压差自发产水；膜蒸馏 MD（1963 年 Bodell 概念）利用疏水膜两侧蒸气压差在 40–80 ℃ 低温余热下运行；电渗析 ED/倒极电渗析 EDR（1950s/1970s，美国 Ionics）以电场驱动离子迁移。组合路线是工业废水零排放（ZLD）的骨架。
- 来源:

  - https://www.rochemamericas.com/s/20260225_Wastewater_Brochure.pdf

共 5 个变种。

### 变种: 双膜法再生水 | UF+RO Dual-Membrane Reuse

- 年份: 约1990s 末–2003
- 差异点: 「微滤/超滤+反渗透+紫外」三屏障，产水达饮用水级；新加坡 NEWater 2003 投运为里程碑，美国橙郡 GWRS 2008
- 流程: 二级出水〔水〕 → 混凝/自清洗过滤〔辅助〕 → UF 超滤（截留细菌/胶体）〔辅助〕 → 保安过滤、RO 反渗透〔辅助〕 → UV（+H₂O₂）高级氧化消毒〔辅助〕 → 调质、再生水管网〔水〕 → RO 浓水去浓水处理线；UF 反洗水回流前端〔回流〕
- 设计参数: UF 通量 40–80 LMH; RO 回收率 75–85%、通量 12–20 LMH、能耗 0.7–1.2 kWh/m³; UV 剂量 >500 mJ/cm²（AOP 工况）
- 适用: 缺水城市再生水、半导体/锅炉补水、污水厂尾水提级
- 优点: 出水品质最高；多重屏障安全性好
- 缺点: 浓水处置难；投资与能耗高；RO 膜 3–5 年更换

### 变种: 碟管式反渗透 DTRO | Disc-Tube RO (DTRO)

- 年份: 1982（组件研发）/1988（首套渗滤液工程）
- 差异点: 碟片+导流盘结构，开放流道 4–6 mm、凸点湍流，耐压 90–160 bar，可直接处理高 COD 高盐渗滤液。首厂地点双注：Rochem 官方与南非 WRC 报告支持德国 Ihlenberg 填埋场（吕贝克附近，RO 系统 1988–1989 投运、1150 t/d 级），另有 ScienceDirect 综述记 Schwabach（1988），本轮采信 Ihlenberg
- 流程: 渗滤液调节池〔水〕 → 砂滤/保安过滤、酸化阻垢加药〔辅助〕 → 一级 DTRO（90–120 bar）〔辅助〕 → 二级 DTRO 提纯〔辅助〕 → 产水达标排放/回用〔水〕 → 浓缩液去蒸发/回灌/固化线〔泥〕
- 设计参数: 回收率 50–80%（渗滤液）; 单级脱盐率 >95%; 能耗 5–25 kWh/m³（随浓度）; 膜寿命 3–5 年
- 适用: 垃圾渗滤液、危废处置废水、高盐工业废水减量
- 优点: 抗污染、耐高压；拆装清洗方便、回收率高
- 缺点: 单支膜柱流量小、设备造价高；浓液仍需二次处置

### 变种: 正渗透 | Forward Osmosis (FO)

- 年份: 约1990s（现代膜，美国 HTI）/2008 后（Oasys 工业废水商业化）
- 差异点: 以高浓度汲取液产生渗透压差「拉」水过膜，无需高压；浓缩液可低温蒸发结晶，主打高难废水浓缩减量
- 流程: 预处理（UF）〔辅助〕 → FO 膜组件（原水侧/汲取液侧双循环）〔辅助〕 → 稀释汲取液去再生单元（热法/RO/蒸馏）〔回流〕 → 产水输出〔水〕 → FO 浓水（高倍浓缩）去结晶/处置〔泥〕
- 设计参数: 通量 5–15 LMH; 浓缩倍数 5–10 倍; 汲取液再生能耗 0.5–2 kWh/m³ 级（热法）
- 适用: 高盐废水浓缩、渗滤液减量、与厌氧/蒸发结晶耦合
- 优点: 低压运行、污染倾向低；浓缩倍率高
- 缺点: 汲取液再生是能耗与成本瓶颈；膜内浓差极化使实际通量远低于理论；商业化业绩有限

### 变种: 膜蒸馏 | Membrane Distillation (MD)

- 年份: 1963（概念）/2010s 起工业示范
- 差异点: 疏水微孔膜（PTFE/PP/PVDF）两侧蒸气分压差驱动，仅水蒸气过膜；可用 40–80 ℃ 低温余热，截留率近 100%，零排放末端浓缩候选
- 流程: 高盐水预热（余热/太阳能）〔水〕 → 疏水膜组件（热侧循环/冷侧冷凝）〔辅助〕 → 蒸气过膜冷凝为纯水、回用〔水〕 → 热侧浓缩至近饱和、结晶器出盐〔泥〕 → 膜定期酸洗防结垢〔辅助〕
- 设计参数: 通量 1–10 LMH; 温差 10–40 ℃; 热耗约 30–200 kWh_th/m³（依赖余热时电耗 <1 kWh/m³）; 截留率 >99.9%
- 适用: RO 浓水再浓缩、电厂/化工余热耦合零排放、太阳能淡化
- 优点: 理论截留率 100%、耐高盐；可利用废热
- 缺点: 膜润湿风险；通量低、热效率依赖余热品位；尚无大规模市政业绩

### 变种: 电渗析与倒极电渗析 | ED / EDR

- 年份: 约1950s（ED）/约1970s（EDR）
- 差异点: 直流电场驱动离子经阴/阳离子交换膜迁移；EDR 周期倒极抑制结垢（美国 Ionics）；新兴用途为分盐（一/二价分离）与氨氮回收
- 流程: 预处理（软化/过滤）〔水〕 → EDR 膜堆（多对阴阳膜交替）〔辅助〕 → 淡水室产水〔水〕 → 浓水室排浓（去结晶/处置）〔泥〕 → 极水循环、周期性倒极换向〔回流〕 → 定期酸洗/CIP〔辅助〕
- 设计参数: 单级脱盐率 40–60%; 回收率 80–95%; 能耗 0.5–2 kWh/m³（苦咸水级）; 电流效率 70–90%
- 适用: 苦咸水淡化、循环排污水回用、零排放分盐、氨氮电浓缩
- 优点: 回收率高、耐硅耐有机物；倒极自清洗
- 缺点: 不去除非离子污染物；电极结垢与膜堆老化；浓缩上限低于 RO/蒸发
