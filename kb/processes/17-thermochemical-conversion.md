# 17. 污泥热化学转化 | Thermochemical Conversion (热解/HTL/SCWO/气化)

- 诞生: 约1950s（WAO）；热解/HTL/SCWO 2010s 起
- 成熟度: 商业化初期
- 族/周期: 污泥处理处置 / 1950s-1960s
- 定位: 把湿污泥直接转化为生物炭、生物原油或洁净水的「终极减量」路线，兼具 PFAS 销毁卖点
- 简介: 热化学家族按温度压力分档：湿式氧化 WAO（150–320 ℃ 亚临界，1950s 美国 Zimpro，改善脱水性并灭菌）；热解炭化（400–700 ℃ 缺氧）产生物炭+可燃气，2010s 商业化；水热液化 HTL（280–370 ℃、10–25 MPa）免干燥把湿污泥变生物原油（PNNL 估算全美污泥年可产约 3000 万桶油当量），截至 2025 年秋全球尚无商业化湿废 HTL 厂，代表示范为加拿大 Annacis Island（约 2 tDS/d）与丹麦 Fredericia Sludge2Fuel（约 15 tDS/d）；超临界水氧化 SCWO（>374 ℃、>22.1 MPa、加氧）数分钟内矿化有机物并销毁 PFAS，374Water 的 AirSCWO 正从 Duke 大学 1 t/d 示范（2015 起）走向 6 t/d 商业撬装（2021 起）。SCWO 1980s 首轮商业化因腐蚀与盐堵衰退，新一代以抗腐蚀反应器与热集成破局。
- 来源:

共 5 个变种。

### 变种: 污泥热解炭化 | Sludge Pyrolysis & Biochar

- 年份: 约2010s 商业化
- 差异点: 400–700 ℃ 缺氧热解；产物生物炭可土地利用、建材掺合或作吸附剂；炭化炉可与干化机集成自供热
- 流程: 污泥干化（至 85–90% DS）〔泥〕 → 热解炉（缺氧 400–700 ℃）〔泥〕 → 生物炭冷却、炭产品〔泥〕 → 热解气+焦油燃烧供热回用〔回流〕 → 尾气净化（除尘/脱酸/二噁英）〔辅助〕
- 设计参数: 减量率 80–90%（对干基）; 炭产率 30–45%; 能耗约 0.8–1.2 kWh/kg 蒸发水（干化段为主）; 重金属固化率 >90%
- 适用: 污泥出路受限城市、重金属稳定化、炭基肥/吸附剂市场
- 优点: 大幅减量、重金属固化；炭产品增值
- 缺点: 干化能耗高；二噁英与焦油管控要求严

### 变种: 水热液化 | Hydrothermal Liquefaction (HTL)

- 年份: 示范阶段（2016 PNNL 授权 Genifuel；约2019 Annacis；约2022 Fredericia）
- 差异点: 280–370 ℃、10–25 MPa 水中直接液化湿污泥，生物原油产率 30–45 wt%（干基）；无需干化是最大优势；副产水相含高浓度氮磷需回收处理
- 流程: 脱水污泥（15–25% DS）高压泵〔泥〕 → 换热预热〔泥〕 → HTL 反应器（350 ℃、约 20 MPa，5–30 min）〔泥〕 → 产物换热降压、三相分离〔泥〕 → 生物原油炼制 / 水相去 Anammox 或催化处理 / 残渣磷回收〔辅助〕
- 设计参数: 350 ℃/约 200 bar/停留 8–30 min; 生物原油产率 30–45%; 能量回收率 50–70%; 水相 COD 3–8 万 mg/L
- 适用: 大型污泥集中处置+燃料替代；与炼厂协同
- 优点: 免干化、产液态燃料；体积减量 >90%
- 缺点: 高压设备投资大；水相治理成本高；尚无商业化业绩（截至 2025）

### 变种: 超临界水氧化 SCWO | SCWO (如 374Water AirSCWO)

- 年份: 1980s 首轮商业化（衰退）/2013 起新一代（374Water）
- 差异点: >374 ℃、>22.1 MPa 超临界水中加氧，有机物数分钟内 >99.9% 矿化；无机盐析出回收；PFAS、药物、微塑料、病原体全销毁
- 流程: 污泥浆（泵升至约 25 MPa）〔泥〕 → 预热〔泥〕 → SCWO 反应器（注氧/空气，500–600 ℃）〔泥〕 → 高温出水换热回收、气液分离〔辅助〕 → 无机盐/磷灰石残渣回收〔泥〕 → 出水回用〔水〕
- 设计参数: >374 ℃ / >22.1 MPa; 停留 <1–5 min; COD 去除 >99.9%; 体积减量 >97%
- 适用: PFAS 污染污泥、危废浆、应急销毁；分布式撬装
- 优点: 彻底销毁新污染物；热自给、占地小
- 缺点: 高压高危设备；腐蚀/盐堵曾致一代技术衰退；业绩刚起步

### 变种: 湿式空气氧化 | Wet Air Oxidation (WAO, Zimpro 类)

- 年份: 约1950s
- 差异点: 亚临界（150–320 ℃、2–15 MPa）加氧部分氧化，不追求完全矿化，主要改善脱水性并灭菌；SCWO 的「温和前辈」
- 流程: 污泥浆高压泵〔泥〕 → 换热〔泥〕 → WAO 反应器（注空气，自热）〔泥〕 → 气液分离〔泥〕 → 氧化泥脱水（泥饼）/液相回生化处理〔回流〕
- 设计参数: 200–300 ℃ / 3–10 MPa; COD 去除 50–80%; 停留 30–60 min
- 适用: 特种污泥减量、含硫废水；历史用于改善脱水
- 优点: 成熟可靠；自热运行
- 缺点: 出水 COD 高需回处理；被 THP/SCWO 挤压市场

### 变种: 污泥气化 | Sludge Gasification

- 年份: 约2000s–2010s 示范
- 差异点: 800–1000 ℃ 部分氧化产合成气（CO+H₂），可发电或制燃料；需深度干化（>90% DS）；与焚烧竞争
- 流程: 污泥干化〔泥〕 → 气化炉（流化床/固定床）〔泥〕 → 合成气净化（除尘/脱焦）〔辅助〕 → 燃气发电或合成〔辅助〕 → 灰渣建材化〔泥〕
- 设计参数: 800–1000 ℃; 冷煤气效率 60–75%; 减量 >90%（干基）
- 适用: 大型处置中心、与发电耦合
- 优点: 能源品位高于焚烧直热；灰渣少
- 缺点: 干化能耗决定全流程能效；焦油与气体净化复杂
