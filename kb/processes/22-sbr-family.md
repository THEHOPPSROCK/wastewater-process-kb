# 22. 序批式活性污泥法 SBR 家族 | Sequencing Batch Reactor Family

- 诞生: 1971（现代 SBR；充排式原型 1914）
- 成熟度: 成熟主流
- 族/周期: 悬浮生长生物 / 1970s
- 定位: 在时间维度上交替完成进水-反应-沉淀-排水的一体化活性污泥工艺
- 简介: 充排式（fill-and-draw）运行正是 Ardern & Lockett 1914 年的原始活性污泥形式；1971 年 Irvine 与 Davis 在德州 Corpus Christi 工业废水厂首次命名 SBR，1980 年印第安纳 Culver 厂连续流改 SBR 奠定推广基础。SBR 在同一池内按周期顺序完成进水（Fill）→ 反应（React）→ 沉淀（Settle）→ 滗水（Decant）→ 闲置（Idle）五个阶段，不需二沉池与污泥回流系统，通过时间分割实现空间分割的功能；借助 1980s 后自控技术进步大规模推广，衍生出 ICEAS、CASS、DAT-IAT、UNITANK、MSBR、IDEA 等变型。

共 7 个变种。

### 变种: 经典序批式 SBR | Conventional SBR

- 年份: 1971
- 差异点: 间歇进水、间歇排水，单池时间分割；周期通常 4–8 h
- 流程: 进水（可搅拌/曝气）〔水〕 → 反应曝气（可设缺氧搅拌段脱氮）〔水〕 → 静置沉淀〔水〕 → 滗水器排水〔水〕 → 闲置/排泥（WAS）〔泥〕 → 下一周期〔回流〕
- 设计参数: 周期 4–8 h; HRT（折算）12–24 h; SRT=10–20 d; F/M=0.05–0.15; MLSS=2000–5000 mg/L; 滗水深度 0.5–2.0 m; 充水比 0.2–0.4
- 适用: 中小城镇、开发区、水质水量波动大的工业废水
- 优点: 无二沉池与回流系统；抗冲击强；可通过时序调整实现脱氮除磷
- 缺点: 滗水器等关键设备要求高；间歇运行设备闲置；大型化受滗水能力限制

### 变种: 间歇循环延时曝气 ICEAS | Intermittent Cycle Extended Aeration System (ICEAS)

- 年份: 1968（开发，早于 SBR 命名）/1976（首座工程）
- 差异点: 连续进水、间歇排水；池前端设预反应区缓冲，无独立闲置段；澳大利亚新南威尔士大学与美国 ABJ 公司合作开发
- 流程: 进水（连续）〔水〕 → 预反应区〔水〕 → 主反应区（曝气/搅拌）〔水〕 → 静置沉淀〔水〕 → 滗水〔水〕 → 排泥（WAS）〔泥〕
- 设计参数: 周期 4–6 h; SRT=15–25 d; MLSS=3000–5000 mg/L
- 适用: 中小型市政厂，水量连续稳定场景
- 优点: 连续进水不需调节池；延时曝气污泥稳定；造价低于经典 SBR
- 缺点: 沉淀期进水影响泥水分离；脱氮除磷能力有限

### 变种: 循环式活性污泥 CAST/CASS | Cyclic Activated Sludge Technology/System

- 年份: 1979–1985
- 差异点: 以生物选择器（厌氧/缺氧）替代预反应区，池内分选择器-缺氧-好氧三区（容积比约 1:5:30），污泥回流至选择器，抑制丝状菌并强化脱氮除磷；Goronszy 在 ICEAS 基础上开发
- 流程: 进水（连续或间歇）〔水〕 → 生物选择器（与回流污泥接触）〔水〕 → 缺氧区〔水〕 → 好氧主曝气区〔水〕 → 静置沉淀、滗水〔水〕 → 污泥回流：主区至选择器；排泥〔回流〕
- 设计参数: 周期 4–6 h; SRT=15–25 d; MLSS=3000–5000 mg/L; 选择器 HRT=0.5–1 h; 回流比 20–30%
- 适用: 有脱氮除磷要求的中小市政厂
- 优点: 防污泥膨胀；脱氮除磷效果好；连续进水
- 缺点: 自控复杂；滗水期仍有进水干扰

### 变种: 需氧-间歇曝气 DAT-IAT | Demand Aeration Tank–Intermittent Aeration Tank

- 年份: 约1980s 末–1990s
- 差异点: 双池串联：DAT 连续进水连续曝气，IAT 连续进水间歇排水；IAT 污泥回流 DAT；中国天津市政工程设计研究院提出
- 流程: 进水（连续）〔水〕 → DAT 需氧池（连续曝气）〔水〕 → IAT 间歇池（曝气/沉淀/滗水循环）〔水〕 → 出水〔水〕 → IAT 污泥回流至 DAT〔回流〕 → WAS 排放〔泥〕
- 设计参数: 总 HRT=12–20 h; SRT=15–20 d; MLSS=3000–4500 mg/L; IAT 周期 3–4 h
- 适用: 中小规模、高排放标准（脱氮除磷）项目
- 优点: 抗冲击负荷强（DAT 缓冲）；可连续进水；脱氮除磷
- 缺点: 两池构造与自控较复杂；回流泵增加能耗

### 变种: 一体化三池交替系统 UNITANK | UNITANK

- 年份: 1987
- 差异点: 三个矩形池连通，边池交替作曝气池与沉淀池，中池恒为曝气；整体连续进出水、恒定水位；比利时 SEGHERS 公司提出，全球约 200 座
- 流程: 进水（连续，可进入任一边池）〔水〕 → 边池 A（曝气）〔水〕 → 中池（曝气）〔水〕 → 边池 C（沉淀出水）〔水〕 → 半周期后换向〔回流〕 → 剩余污泥自沉淀边池排放〔泥〕
- 设计参数: 周期约 7 h（主阶段 2×3 h+过渡 2×0.5 h）; SRT=15–25 d; MLSS=3000–5000 mg/L; 可不设初沉池
- 适用: 中小市政厂（新加坡、澳门、石家庄高新区等有案例）
- 优点: 无独立二沉池、占地省；恒水位运行；时间/空间双调控脱氮除磷
- 缺点: 闸门与自控系统复杂；大规模应用时配水均匀性难保证

### 变种: 改良式序批反应器 MSBR | Modified Sequencing Batch Reactor (MSBR)

- 年份: 约1980s 初
- 差异点: 单池多格（厌氧 A、厌氧 B、缺氧、主曝气、两个交替序批格、泥水分离格），恒定水位连续运行，实质为 A²/O 与 SBR 的串联集成；C.Y. Yang 等开发，专利归美国 Aqua-Aerobic Systems
- 流程: 进水〔水〕 → 厌氧格 A/B（释磷）〔水〕 → 缺氧格〔水〕 → 主曝气格〔水〕 → 序批格 1 或 2（交替沉淀-出水）〔水〕 → 污泥回流：序批格经泥水分离至缺氧格；WAS 排放〔回流〕
- 设计参数: 周期分 6 时段; 总 HRT=12–18 h; SRT=15–25 d; MLSS=3000–5000 mg/L
- 适用: 脱氮除磷要求高的中型市政厂
- 优点: 集约化程度最高；恒水位；脱氮除磷强
- 缺点: 格间连通与自控复杂；国内工程经验相对少

### 变种: 间歇排水延时曝气 IDEA | Intermittently Decanted Extended Aeration (IDEA)

- 年份: 约1980s
- 差异点: 连续进水、间歇曝气与间歇滗水的单池系统，前端加厌氧选择区强化除磷；澳大利亚新南威尔士州乡村污水体系
- 流程: 进水（连续）〔水〕 → 厌氧选择区〔水〕 → 主池（曝气/沉降/滗水时序运行）〔水〕 → 滗水排放〔水〕 → WAS 定期排放〔泥〕
- 设计参数: SRT=15–30 d; HRT=18–36 h; MLSS=3000–5000 mg/L
- 适用: 小型乡村与社区污水（澳新广泛应用）
- 优点: 极简单、运行费用低；出水 TN<5、TP<1 mg/L 可达
- 缺点: 规模受限；滗水器依赖进口
