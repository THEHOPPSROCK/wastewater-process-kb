# 12. 污泥处置与资源化 | Sludge Disposal & Beneficial Use

- 诞生: 1924（Indore 堆肥）；污泥土地利用 1840s 起
- 成熟度: 成熟主流
- 族/周期: 污泥处理处置 / 1910s-1940s
- 定位: 污泥的最终出路——减容、稳定与养分/能源回收
- 简介: 脱水泥饼的出路包括：土地利用（农肥/园林绿化，受重金属与病原体标准约束，1840s 污水农场即为其前身）、好氧堆肥（1924–1931 年 Indore 法创立，55–65 ℃ 高温杀菌制肥）、热干化（1930s 芝加哥首批烘干工程，制颗粒肥或燃料）、焚烧（多膛炉 1930s 起、流化床 1960s 起，850 ℃ 以上彻底减容并可发电）、卫生填埋（日趋受限，欧盟多国 2020s 起禁止有机质填埋）。路线选择取决于法规，且须与前端稳定化匹配。
- 来源:
  - https://pmc.ncbi.nlm.nih.gov/articles/PMC7617516/
  - https://civil.colorado.edu/~silverst/cven5534/History%20of%20Wastewater%20Treatment%20in%20the%20US.pdf
  - https://rke.abertay.ac.uk/ws/portalfiles/portal/15228568/Irvine_2002_Temperature_and_physical_modelling_studies_PhD.pdf

共 5 个变种。

### 变种: 好氧堆肥 | Composting (Windrow / In-vessel)

- 年份: 1924–1931（Indore 法）
- 差异点: 污泥与调理剂（秸秆/木屑）混合，好氧发酵升温至 55–65 ℃ 灭活病原体，4–8 周腐熟；1950s–70s 工业化
- 流程: 脱水污泥（含固 20%+）〔泥〕 → 混合调理剂（C/N 25–35）〔辅助〕 → 条垛/发酵仓（翻堆或强制通风）〔泥〕 → 高温期（55–65 ℃）〔泥〕 → 腐熟陈化、筛分〔泥〕 → 有机肥〔泥〕
- 设计参数: C/N=25–35; 含水率 55–65%; 55–65 ℃ 维持 ≥3 d（仓式）/15 d（条垛）; 周期 4–8 周
- 适用: 中小厂、农业区就近消纳
- 优点: 产品可销售；病原体灭活彻底
- 缺点: 占地与臭味管理；重金属制约农用

### 变种: 热干化 | Thermal Drying

- 年份: 1930s（首批工程）/1970s–90s（成套化）
- 差异点: 直接/间接加热把泥饼含水率降至 5–15%，制颗粒，体积缩减至 1/4–1/5
- 流程: 脱水污泥〔泥〕 → 干化机（流化床/带式/桨叶，200–300 ℃）〔泥〕 → 颗粒产品（含固 90–95%）〔泥〕 → 肥料/燃料〔泥〕 → 尾气冷凝除臭回污水线〔回流〕
- 设计参数: 蒸发能耗 ≈700–900 kWh/t 水; 产品含固 90–95%; 颗粒粒径 2–6 mm
- 适用: 长距离运输、土地利用或焚烧前预处理
- 优点: 产品卫生化、易储运；减容最大
- 缺点: 能耗高；粉尘爆炸风险管控

### 变种: 焚烧 | Incineration (Multiple-Hearth / Fluidized Bed)

- 年份: 1930s 初
- 差异点: 多膛炉层落式焚烧 vs 流化床剧烈混合焚烧；彻底矿化有机物，灰烬减量 90%
- 流程: 脱水污泥（含固 20–30%）〔泥〕 → 焚烧炉（850–950 ℃）〔泥〕 → 灰烬填埋/磷回收〔泥〕 → 烟气余热锅炉-除尘-脱酸脱硝〔辅助〕 → 排放〔辅助〕
- 设计参数: 炉温 850–950 ℃; 灰分为绝干污泥 25–45%; 消化污泥需辅助燃料
- 适用: 大城市污泥、重金属超标不可农用污泥
- 优点: 减容最彻底；可发电供热；灰中可回收磷
- 缺点: 烟气治理投资大；公众接受度低

### 变种: 卫生填埋 | Sanitary Landfill

- 年份: 20 世纪上半叶沿用至今
- 差异点: 泥饼与垃圾混填或专区填埋，需防渗与渗滤液收集；欧盟 2020s 起多国禁止有机质填埋
- 流程: 脱水/石灰稳定污泥〔泥〕 → 运输至填埋场〔泥〕 → 摊铺压实、日覆盖〔泥〕 → 渗滤液收集回污水厂〔回流〕 → 填埋气收集〔辅助〕
- 设计参数: 入场含固率要求 ≥30–40%（多数法规）
- 适用: 应急与兜底处置
- 优点: 简单、兜底可靠
- 缺点: 占地、渗滤液风险；法规日趋禁止

### 变种: 土地利用 | Land Application (Biosolids)

- 年份: 1840s 起 / 1970s 起规范化
- 差异点: 消化/堆肥稳定后的生物泥作为土壤改良剂与缓释肥；分 A 级（可接触）/B 级（限用）；美国 40 CFR Part 503 规范
- 流程: 消化/堆肥污泥〔泥〕 → 检测（重金属、病原体）〔泥〕 → 撒施/注入农田林地〔泥〕 → 土壤-作物利用〔泥〕
- 设计参数: 年施用率 2–70 tDS/(ha·a)（按氮磷负荷与土壤）; 重金属限值执行国标（如 GB 4284）
- 适用: 农业区、矿山修复、园林绿化
- 优点: 养分循环、成本最低；碳足迹小
- 缺点: 重金属/微污染物长期累积争议；公众与法规敏感
