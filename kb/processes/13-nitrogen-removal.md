# 13. 生物脱氮工艺（A/O 系） | Biological Nitrogen Removal Processes

- 诞生: 1932（Wuhrmann 后置反硝化）
- 成熟度: 成熟主流
- 族/周期: 悬浮生长生物 / 1910s-1940s
- 定位: 以硝化-反硝化生物途径去除总氮的经典工艺族
- 简介: 好氧区硝化菌将 NH₄⁺ 氧化为 NO₃⁻，缺氧区反硝化菌以原水有机物为碳源将 NO₃⁻ 还原为 N₂ 逸出。1932 年 Wuhrmann 提出后置反硝化，1962 年 Ludzack & Ettinger 提出前置反硝化（利用进水碳源、节省曝气），1973 年 Barnard 改良为 MLE/A/O（受控内回流）并创立 Bardenpho。内回流比决定脱氮率上限；需同步除磷时见大类「同步脱氮除磷工艺（BNR/EBPR）」。
- 来源:
  - https://sthj.ln.gov.cn/sthj/hjgl/swrfz/czws/F6B4CECEB15743ECB21658765FEDF235/index.shtml
  - https://www.wrc.org.za/wp-content/uploads/mdocs/TT-83-97.pdf

共 4 个变种。

### 变种: 后置反硝化 Wuhrmann 工艺 | Wuhrmann Process (Post-denitrification)

- 年份: 1932
- 差异点: 好氧硝化在前、缺氧反硝化在后，反硝化靠内源碳，速率低、池容大
- 流程: 进水经初沉〔水〕 → 好氧池（碳化+硝化）〔水〕 → 缺氧池（内源反硝化）〔水〕 → 二沉池〔水〕 → 出水〔水〕 → RAS 回流 / WAS 排放〔回流〕
- 设计参数: 总 HRT=10–16 h; SRT=15–25 d; 缺氧段 HRT 长（内源反硝化慢）
- 适用: 历史意义为主；低碳氮比研究场景
- 优点: 流程直观；理论奠基
- 缺点: 反硝化速率极低、占地大；工程上基本被淘汰

### 变种: 前置反硝化 Ludzack-Ettinger | Ludzack-Ettinger Process

- 年份: 1962
- 差异点: 缺氧池前置，利用进水碳源反硝化；但回流路径未受控，脱氮率有限
- 流程: 进水〔水〕 → 缺氧池（反硝化）〔水〕 → 好氧池（碳化+硝化）〔水〕 → 二沉池〔水〕 → 出水〔水〕 → RAS 回流至缺氧池〔回流〕
- 设计参数: 总 HRT=8–12 h; SRT=10–20 d; R=50–100%
- 适用: 历史过渡工艺
- 优点: 首次利用原水碳源
- 缺点: 好氧池硝酸盐无法受控回流；脱氮不彻底

### 变种: 改良 Ludzack-Ettinger（MLE/A/O 脱氮型） | Modified Ludzack-Ettinger (MLE)

- 年份: 1973
- 差异点: 在好氧池末端增设混合液内回流至缺氧池，硝酸盐受控回流，脱氮率显著提高；现代前置反硝化标准构型（Barnard）
- 流程: 进水经初沉〔水〕 → 缺氧池〔水〕 → 好氧池（硝化）〔水〕 → 二沉池〔水〕 → 出水〔水〕 → 内回流（硝化液）好氧末端至缺氧首端 100–400%〔回流〕 → RAS 回流 / WAS 排放〔回流〕
- 设计参数: 总 HRT=8–14 h（缺氧 2–4 h）; SRT=10–20 d; MLSS=2500–4000 mg/L; 内回流 100–400%; R=50–100%; TN 去除 60–80%
- 适用: 以脱氮为主、出水 TN≤15 mg/L 的市政厂
- 优点: 结构简单、脱氮稳定；利用原水碳源
- 缺点: 内回流受出水硝酸盐下限约束，不能彻底脱氮；无生物除磷功能

### 变种: 四段 Bardenpho | Four-Stage Bardenpho

- 年份: 1973（1975 年工程验证）
- 差异点: 在 MLE 后再加二级缺氧（后反硝化）+ 快速再曝气段，理论上可完全脱氮
- 流程: 进水〔水〕 → 一级缺氧池〔水〕 → 一级好氧池（硝化）〔水〕 → 二级缺氧池（后反硝化，必要时外加碳源）〔水〕 → 再曝气池〔水〕 → 二沉池、出水〔水〕 → 内回流：一级好氧至一级缺氧；RAS/WAS〔回流〕
- 设计参数: 总 HRT=12–18 h; SRT=15–25 d; 内回流 200–400%; TN 去除 85–95%
- 适用: 出水 TN≤10 mg/L 的严格脱氮场景
- 优点: 脱氮率最高的传统构型之一；无需化学除氮
- 缺点: 池容大；二级缺氧碳源不足时脱氮受限
