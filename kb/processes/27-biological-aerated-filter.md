# 27. 曝气生物滤池 | Biological Aerated Filter (BAF)

- 诞生: 约1980s 初（1982 BIOFOR 工程化）
- 成熟度: 成熟主流
- 族/周期: 固着生长生物 / 1980s
- 定位: 集生物降解与过滤截流于同一池体的紧凑型固定膜工艺
- 简介: 污水上流或下流通过淹没的颗粒滤料层（陶粒/浮石/聚苯乙烯小球），滤料表面生物膜降解碳氮污染物，滤层同时截留悬浮物；定期气水联合反冲洗排出截留物与老化生物膜，可取消二沉池。源头可追溯 1913 年板岩层曝气池与 1939 年首个淹没式接触曝气；约 1980s 初欧洲工程化（1982 年 Degrémont BIOFOR），全球已建 500+ 座，尤适合用地紧张的提标与深度处理。
- 来源:
  - https://politesi.polimi.it/retrieve/a81cb05c-2d31-616b-e053-1605fe0a889a/2016_12_Tastekin.pdf
  - https://vtechworks.lib.vt.edu/bitstream/handle/10919/76663/Thomas_A_T_2015.pdf
  - https://www.veoliawatertechnologies.com/en/solution/technologies/biostyr

共 3 个变种。

### 变种: 上向流沉水滤料 BIOFOR | BIOFOR (Upflow, Sunken Media)

- 年份: 约1982
- 差异点: 上向流+重于水的陶粒滤料，曝气管置于滤层中部，可分区实现碳化/硝化；法国 Degrémont 工程化
- 流程: 进水经初沉/CEPT〔水〕 → BIOFOR 滤池（底部进水、中部曝气、顶部出水）〔水〕 → 出水（或消毒）〔水〕 → 反冲洗：气洗-气水联合-水洗〔辅助〕 → 反洗废水回流至初沉/污泥线〔回流〕
- 设计参数: 滤速 2–6 m/h; 有机负荷 2–6 kgBOD/(m³滤料·d); 硝化负荷 0.4–1.0 kgNH₄-N/(m³·d); 反洗周期 24–48 h
- 适用: 大型市政厂二级+深度处理（多格并联）
- 优点: 占地为活性污泥法 1/4–1/6；出水 SS 极低；可模块化扩容
- 缺点: 反洗系统复杂；滤料与专用滤头投资高

### 变种: 上向流漂浮滤料 BIOSTYR | BIOSTYR (Upflow, Floating Media)

- 年份: 约1980s 末
- 差异点: 轻质聚苯乙烯滤珠漂浮于水面被出水顶板压持，滤床膨胀截污；曝气位置可调实现好氧/缺氧分区；法国 Krüger（现 Veolia）开发
- 流程: 进水经预处理〔水〕 → BIOSTYR（底部进水，上浮滤珠层，中部曝气）〔水〕 → 顶部清水区出水〔水〕 → 向下脉冲式反洗〔辅助〕 → 反洗水至污泥线〔泥〕
- 设计参数: 滤速 3–8 m/h; 负荷同 BIOFOR; 反洗周期 24–72 h
- 适用: 用地紧张的新建与提标项目、回用水前处理
- 优点: 滤速高；可同步硝化反硝化（分区）
- 缺点: 滤珠磨损需补充；专利设备

### 变种: 下向流反硝化滤池 | Downflow Denitrification Filter

- 年份: 约1970s
- 差异点: 下向流粗粒滤料，外加甲醇/乙酸碳源，缺氧运行专作反硝化；兼具过滤；美国三级深度脱氮
- 流程: 二级出水〔水〕 → 反硝化滤池（投加甲醇，缺氧）〔辅助〕 → 出水（短暂曝气脱氮气）〔水〕 → 消毒〔水〕 → 反洗回流〔回流〕
- 设计参数: 滤速 4–10 m/h; 硝酸盐负荷 0.5–2 kgNO₃-N/(m³·d); 碳氮比（甲醇/NO₃-N）≈3:1
- 适用: 出水 TN≤3–5 mg/L 的深度脱氮
- 优点: TN 可达极低；兼有 SS 过滤
- 缺点: 外加碳源成本与安全（甲醇）问题；微气泡氮气上浮需控制
