# 18. 藻类处理与菌藻共生 | Algae-Based Treatment

- 诞生: 约1950s–1960s
- 成熟度: 商业化初期
- 族/周期: 自然生态 / 1950s-1960s
- 定位: 用微藻光合供氧替代机械曝气，同步收获生物质（饲料/肥料/沼气）的「负碳」路线
- 简介: 微藻吸收 N、P 并光合放氧，供异养菌降解有机物，形成菌藻互利系统：省去鼓风机、固碳减排，收获藻泥可厌氧消化或作肥料。HRAP 高速率藻塘（1950s–60s，Oswald；浅水搅拌跑道池）是最成熟形态，与传统稳定塘好氧塘同源（见「稳定塘」大类）；光生物反应器 PBR 占地小但造价高；旋转藻生物膜 RAB（约 2013，Iowa State）让藻附着于旋转带/载体上，收获只需刮膜，破解藻水分离这一最大痛点；菌藻共生颗粒污泥 MBGS 把 AGS 颗粒与微藻复合，2010s 中起为研究热点。
- 来源:

共 4 个变种。

### 变种: 高效藻塘 | HRAP (High-Rate Algal Pond)

- 年份: 约1950s–1960s
- 差异点: 浅水（0.2–0.6 m）跑道池+桨轮搅拌，藻菌共生；新西兰/美国有大规模市政业绩；出水需藻分离
- 流程: 预处理〔水〕 → HRAP 跑道池（桨轮混合，光合供氧）〔水〕 → 藻水分离（混凝气浮/沉淀）〔泥〕 → 出水〔水〕 → 藻泥去消化/堆肥，部分藻回流接种〔回流〕
- 设计参数: HRT=4–10 d; 水深 0.2–0.6 m; BOD 去除 80–95%; N/P 去除 50–90%（季节波动大）; 搅拌约 0.01–0.05 kWh/m³
- 适用: 日照充足、土地宽裕地区；水产养殖尾水
- 优点: 能耗极低、固碳；运行简单
- 缺点: 占地巨大；冬季效率骤降；藻水分离难

### 变种: 光生物反应器 | Photobioreactor (PBR)

- 年份: 约1990s–2000s
- 差异点: 封闭管式/板式/柱式系统，光照比表面积大、污染可控；可培养高值藻种；造价与能耗（泵送/冷却）高
- 流程: 废水+藻种〔水〕 → PBR（光照循环）〔水〕 → 藻液〔水〕 → 离心/膜分离〔泥〕 → 出水〔水〕 → 藻生物质收集加工；CO₂ 补充线〔辅助〕
- 设计参数: HRT=2–6 d; 藻浓度 1–5 g/L; N/P 去除 >90%（可控工况）
- 适用: 高值藻产品联产、土地受限场景
- 优点: 占地小、可控性强；生物质品质高
- 缺点: 投资与运维成本高；放大后光穿透与传热瓶颈

### 变种: 旋转藻生物膜 | Revolving Algal Biofilm (RAB)

- 年份: 约2013
- 差异点: 藻附着于半浸没旋转带/载体上，气水交替接触；收获用刮板机械剥离，含水率远低于悬浮藻，破解收获能耗痛点（Iowa State，Gross/Wen 团队）
- 流程: 废水〔水〕 → RAB 反应槽（旋转带半浸没）〔水〕 → 藻膜吸收 N/P、光合放氧〔水〕 → 出水〔水〕 → 定期刮收藻膜（含固 5–15%）至消化/肥料〔泥〕
- 设计参数: 藻产率 5–30 g/(m²·d); 收获能耗较离心降 80–90%; N/P 去除 70–95%（中试）
- 适用: 中小型深度脱氮除磷+生物质回收
- 优点: 收获成本革命性下降；模块化
- 缺点: 户外季节波动；传动部件维护；规模化业绩少

### 变种: 菌藻共生颗粒污泥 | Microalgal-Bacterial Granular Sludge (MBGS)

- 年份: 约2010s 中起
- 差异点: 微藻与细菌共凝聚成好氧颗粒，光照下藻供氧、暗期菌供 CO₂，沉降性能等同 AGS、无需藻水分离
- 流程: 废水〔水〕 → 光照反应池（SBR 或连续流，菌藻颗粒悬浮）〔水〕 → 快速沉降〔水〕 → 出水〔水〕 → 颗粒自持留，剩余颗粒去污泥线〔泥〕
- 设计参数: 颗粒粒径 0.5–3 mm; 曝气节省 30–60%（补光条件下）; TN/TP 去除 70–90%（小中试）
- 适用: 日光充足地区低碳脱氮除磷的探索性应用
- 优点: 免/少曝气+免分离；碳中和卖点强
- 缺点: 光衰减与暗期缺氧矛盾；颗粒长期稳定性未证实
