# 03. 厌氧处理大家族 | Anaerobic Treatment Family

- 诞生: 1881
- 成熟度: 成熟主流
- 族/周期: 厌氧生物 / 1880-1909
- 定位: 无氧条件下有机物经水解-酸化-产乙酸-产甲烷四阶段降解产沼气的工艺族
- 简介: 厌氧工艺把 SRT 与 HRT 解耦，使慢生长的产甲烷菌得以持留：消化池靠长 HRT（1927 年德国 Essen-Rellinghausen 首座加热消化池），厌氧接触（1955 Schroepfer）靠污泥回流，AF（1969 Young & McCarty）靠填料挂膜，UASB/EGSB/IC 靠颗粒污泥自固定化，ABR 靠隔室折流。容积负荷从消化池的 1–2 kgCOD/(m³·d) 提高到 IC 的 20–30 kgCOD/(m³·d)。是工业高浓度废水的主流前段工艺与市政污泥消化的标配；污泥热水解等高级消化见大类「热水解与高级厌氧消化」。
- 来源:

共 8 个变种。

### 变种: 标准（低速）厌氧消化 | Standard-Rate (Low-Rate) Digestion

- 年份: 1927
- 差异点: 不搅拌或间歇搅拌，分层（浮渣-清液-消化层），HRT 30–60 d
- 流程: 初沉+剩余污泥〔泥〕 → 消化池（加热 33–35 ℃，不搅拌）〔泥〕 → 消化污泥至贮泥/脱水〔泥〕 → 上清液回流污水线〔回流〕 → 沼气利用〔辅助〕
- 设计参数: HRT=30–60 d; 负荷 0.5–1.6 kgVS/(m³·d); 温度 33–35 ℃
- 适用: 小型污水厂污泥稳定（历史主流）
- 优点: 简单、运行费低
- 缺点: 池容大；易分层短路、效率低

### 变种: 高速完全混合消化 | High-Rate Completely Mixed Digestion (CSTR Digester)

- 年份: 约1930s–1950s
- 差异点: 连续搅拌、全混合、恒定温度，负荷提高 3–5 倍；常两级串联
- 流程: 污泥〔泥〕 → 一级消化池（35 ℃ 中温或 55 ℃ 高温，搅拌）〔泥〕 → 二级消化/储泥池〔泥〕 → 脱水〔泥〕 → 沼气至锅炉/发电〔辅助〕 → 上清液回流〔回流〕
- 设计参数: HRT=15–20 d（中温）/10–15 d（高温）; 负荷 1.6–4.8 kgVS/(m³·d); VS 破坏率 45–60%; 产气 0.8–1.1 m³/kgVS
- 适用: 大中型市政厂污泥稳定（当今主流）
- 优点: 稳定高效；产沼气能源化
- 缺点: 投资与温控能耗；浮渣泡沫管理

### 变种: 厌氧接触法 | Anaerobic Contact Process

- 年份: 1955
- 差异点: 消化池后加沉淀池与污泥回流，SRT 与 HRT 解耦，可处理溶解性有机废水
- 流程: 废水〔水〕 → 厌氧接触池（35 ℃，搅拌）〔水〕 → 脱气器〔辅助〕 → 沉淀池〔水〕 → 出水〔水〕 → 厌氧污泥回流〔回流〕 → 剩余污泥排放〔泥〕
- 设计参数: HRT=12–24 h; SRT=20–50 d; 负荷 1–5 kgCOD/(m³·d); MLSS=5000–10000 mg/L
- 适用: 高浓度溶解性工业废水（屠宰、酿酒）
- 优点: 比消化池负荷高；出水稳定
- 缺点: 厌氧污泥难沉降（气泡夹带）；脱气器增加复杂度

### 变种: 厌氧滤池 AF | Anaerobic Filter (AF)

- 年份: 1969
- 差异点: 上向流填料挂膜持留生物量，无污泥回流；微生物以生物膜+截留絮体存在
- 流程: 废水〔水〕 → 厌氧滤池（填料层，上流）〔水〕 → 出水〔水〕 → 顶部集气〔辅助〕 → 定期反冲/排泥〔泥〕
- 设计参数: HRT=1–3 d; 容积负荷 2–10 kgCOD/(m³·d); 填料比表面积 90–300 m²/m³
- 适用: 低到中等浓度溶解性废水、制药/化工废水
- 优点: 无需三相分离器；耐冲击与毒物
- 缺点: 填料堵塞风险；不适合高 SS 废水

### 变种: 升流式厌氧污泥床 UASB | Upflow Anaerobic Sludge Blanket (UASB)

- 年份: 1974（开发）/1977（工程应用）
- 差异点: 无填料，靠颗粒污泥与顶部三相分离器持留生物量；结构最简的高速厌氧工艺
- 流程: 废水至底部布水系统〔水〕 → 颗粒污泥床层（上流 0.5–1.5 m/h）〔水〕 → 三相分离器（气/固/液分离）〔水〕 → 出水〔水〕 → 沼气收集利用〔辅助〕 → 剩余颗粒污泥排放（可作种泥）〔泥〕
- 设计参数: HRT=4–12 h; SRT=30–100+ d; 容积负荷 4–15 kgCOD/(m³·d)（颗粒污泥可达 25）; 上流速度 0.5–1.5 m/h
- 适用: 食品、酿造、造纸等高浓度工业废水；热带/亚热带市政污水（巴西、印度大量应用）
- 优点: 无填料、能耗近零、产沼气；占地小、全球装机最多的高速厌氧工艺
- 缺点: 颗粒污泥培养启动慢（2–6 个月）；不耐高 SS；出水需后处理（无脱氮除磷）

### 变种: 膨胀颗粒污泥床 EGSB | Expanded Granular Sludge Bed (EGSB)

- 年份: 约1991–1992
- 差异点: 高径比加大+出水回流，上流速度 2.5–6 m/h 使颗粒床膨胀，传质显著改善；适于低浓度与低温废水。年份以 van der Last & Lettinga 1991 内部报告/1992 正式发表为准；部分中文文献记 1981，未获佐证不予采信
- 流程: 废水+回流出水〔回流〕 → 底部布水〔水〕 → 膨胀颗粒床〔水〕 → 三相分离器〔水〕 → 出水（部分回流稀释）〔回流〕 → 沼气收集〔辅助〕
- 设计参数: 上流速度 2.5–6 m/h; 高径比 >5; 容积负荷 10–30 kgCOD/(m³·d); HRT=2–8 h
- 适用: 低浓度、低温废水；含微量毒物废水（稀释效应）
- 优点: 负荷高于 UASB；低温适应好
- 缺点: 回流泵能耗；对颗粒沉降性能要求更高

### 变种: 内循环厌氧反应器 IC | Internal Circulation Reactor (IC)

- 年份: 1986（概念）/约1990s 中（Paques BIOPAQ IC 商业化）
- 差异点: 相当于上下两级 UASB 叠置，利用下层沼气气提实现内循环稀释进水；两级三相分离。1986 年 Vellinga 等描述 IC 构型，Paques 官方口径为 1990s 与高校客户共同开发商业化
- 流程: 废水至底部混合区〔水〕 → 下层高负荷反应区（膨胀床）〔水〕 → 下层三相分离（沼气经上升管气提内循环）〔回流〕 → 上层精制区〔水〕 → 上层三相分离与出水〔水〕 → 沼气经气液分离器收集〔辅助〕 → 泥水经下降管回流底部〔回流〕
- 设计参数: 上流速度 10–30 m/h; 容积负荷 15–30 kgCOD/(m³·d); 高度 16–25 m
- 适用: 超高浓度工业废水（啤酒、淀粉、造纸）
- 优点: 负荷族内最高；占地最小；抗冲击（内循环稀释）
- 缺点: 结构复杂、投资高；需专业调试

### 变种: 厌氧折流板反应器 ABR | Anaerobic Baffled Reactor (ABR)

- 年份: 1981–1982
- 差异点: 竖向折流板分隔成 4–8 个串联隔室，各室为独立上流污泥床，实现产酸/产甲烷相沿程分离（SMPA 思想）
- 流程: 废水〔水〕 → 隔室 1（折流，酸化为主）〔水〕 → 隔室 2–4（渐次产甲烷）〔水〕 → 末隔室至出水（可设沉淀室）〔水〕 → 各室沼气汇总收集〔辅助〕 → 定期排泥〔泥〕
- 设计参数: HRT=6–20 h; SRT 可达 100 d; 容积负荷 5–30 kgCOD/(m³·d); 隔室上流速度约 1–2 m/h
- 适用: 高浓度难降解、有毒工业废水；热带分散式市政污水前段
- 优点: 无运动部件与三相分离器、结构简单；相分离提高稳定性与抗毒性
- 缺点: 首格负荷过高易酸化；布水均匀性随规模放大变差
