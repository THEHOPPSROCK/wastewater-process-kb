# 32. 热水解与高级厌氧消化 | Thermal Hydrolysis & Advanced Anaerobic Digestion

- 诞生: 1995（Cambi Hamar 首座全规模 THP）
- 成熟度: 成熟主流
- 族/周期: 污泥处理处置 / 1990s
- 定位: 用 160–180 ℃ 蒸汽「压煮」破壁，让消化池产能翻倍、泥饼更干、病原菌归零的污泥预处理革命
- 简介: 热水解 THP 把脱水污泥（16–20% 含固）在 6–9 bar、160–180 ℃ 下保持 20–60 min 后闪蒸泄压，细胞破壁、粘度骤降，消化池进泥含固可从 4% 提至 10–12%，池容需求减半，沼气产量增 20–50%，泥饼含固提升 3–6 个百分点，并达 A 级生物固废标准。批式代表 Cambi（1995 Hamar）与 Veolia BioThelys（2006 Saumur），连续式代表 Veolia Exelys；衍生路线包括消化后热水解、温度分相 TPAD、两相消化与高含固消化。THP 滤液高氨氮（2000+ mg/L）催生与侧流 Anammox 的标配组合。与「厌氧处理大家族」的边界：本类面向污泥消化的强化预处理与高级构型，厌氧大家族面向废水厌氧反应器与常规消化。全球 80+ 座热水解厂。

共 6 个变种。

### 变种: Cambi 批式热水解 | CambiTHP™

- 年份: 1995
- 差异点: 批式反应器阵列（浆化罐→反应器蒸汽注入 160–180 ℃→闪蒸罐），蒸汽回用预热；首座挪威 Hamar HIAS 厂（9 万当量），2011 华盛顿 Blue Plains 为世界最大之一
- 流程: 脱水污泥（16–20%DS）〔泥〕 → 浆化预热罐（回收闪蒸蒸汽）〔泥〕 → 批式反应器（165 ℃、6 bar、30 min）〔泥〕 → 闪蒸泄压破壁、换热稀释〔泥〕 → 高温/中温消化池〔泥〕 → 沼气发电/提纯〔辅助〕 → 消化泥脱水（滤液去侧流脱氨）、A 级泥饼土地利用〔泥〕
- 设计参数: 165 ℃/6 bar/30 min; 消化池负荷 5–6 kgVS/(m³·d)（传统 2–3）; VS 去除率 ~60%; 沼气增产 20–50%; 泥饼含固 28–35%
- 适用: 大中型厂污泥集中处置中心、餐厨协同消化
- 优点: 全球 55–60+ 座业绩、可用率 98%+；病原菌全灭
- 缺点: 蒸汽系统投资高；THP 滤液高氨氮需配套脱氨

### 变种: Veolia 批式与连续式热水解 | BioThelys™ / Exelys™

- 年份: 2006（BioThelys 首座 Saumur）/2010s（Exelys 连续式）
- 差异点: BioThelys 为批式（165 ℃/9 bar/30 min）；Exelys 为连续管式反应器 24 h 连续运行，PLC 按进泥量调制蒸汽（2015 年发布标准化 Package Exelys）
- 流程: 脱水污泥〔泥〕 → 换热预热〔泥〕 → 批式罐组或连续管式反应器热水解〔泥〕 → 热回收〔回流〕 → 消化池、沼气利用、脱水、泥饼〔泥〕 → 滤液去侧流脱氨〔回流〕
- 设计参数: 165 ℃/9 bar/约 30 min; 污泥减量 25–35%; 沼气增产 30–50%; Package Exelys 单线 ≤30 tDS/d
- 适用: 中大型厂；连续式适合负荷波动小的集中处置中心
- 优点: 连续式占地与热损失更小；模块化撬装交付
- 缺点: 连续式业绩少于 Cambi 批式；高温高压设备维护门槛高

### 变种: 低温碱热水解 | Lystek 类 (Low-Temperature Alkaline THP)

- 年份: 约2000s
- 差异点: 70–90 ℃+碱（KOH/NaOH）+剪切均质，低温低压即可液化污泥，产物为液态有机肥原料；设备造价远低于高温 THP
- 流程: 脱水污泥〔泥〕 → 均质剪切〔泥〕 → 低温碱热反应（70–90 ℃+碱）〔辅助〕 → 液态产物〔泥〕 → 土地利用/肥料调配〔泥〕
- 设计参数: 70–90 ℃; pH 9.5–10; 停留 30–60 min; 产物含固 12–15%
- 适用: 中小厂、无消化设施的污泥出路
- 优点: 投资低；常压附近运行安全
- 缺点: 不产沼气；碱耗成本高；产物出路依赖农肥市场

### 变种: 两相厌氧消化 | Two-Phase AD

- 年份: 约1970s 提出 / 1990s 工程化
- 差异点: 水解酸化相与产甲烷相分池运行，各自优化 pH/温度/停留时间；酸相产 VFA 可兼作碳源或 PHA 原料
- 流程: 浓缩污泥〔泥〕 → 酸相罐（pH 5–6，HRT 1–3 d，产 VFA）〔泥〕 → 甲烷相罐（pH 7–8，HRT 10–15 d）〔泥〕 → 沼气收集〔辅助〕 → 脱水、泥饼〔泥〕 → 酸相上清可分流出碳源线〔回流〕
- 设计参数: 酸相 HRT 1–3 d; 甲烷相负荷 3–6 kgVS/(m³·d); 总 VS 去除率较单相高 5–15%
- 适用: 高含固污泥、协同消化、VFA 平台型资源回收
- 优点: 抗冲击、产气稳；可分取 VFA
- 缺点: 两池投资与自控复杂；酸相跑高会抑制甲烷相

### 变种: 温度分相消化 | TPAD (Temperature-Phased AD)

- 年份: 约1990s 工程化
- 差异点: 第一相高温（50–60 ℃，短时 2–5 d）杀菌+快速水解，第二相中温（35 ℃）完成甲烷化；病原菌杀灭与产气效率兼顾
- 流程: 浓缩污泥〔泥〕 → 高温相罐（55 ℃，2–5 d）〔泥〕 → 中温相罐（35 ℃，10–15 d）〔泥〕 → 沼气〔辅助〕 → 脱水、泥饼（A 级）〔泥〕
- 设计参数: 高温相 50–60 ℃/HRT 2–5 d; 中温相 35 ℃/HRT 10–15 d; 粪大肠菌群杀灭 >99.9%
- 适用: 需 A 级泥饼但不愿上 THP 的厂
- 优点: 杀菌达标；投资低于 THP
- 缺点: 能耗高于单相；高温相泡沫与腐蚀管理

### 变种: 高含固厌氧消化 | High-Solids AD

- 年份: 约2000s–2010s
- 差异点: 进泥含固 8–15%（传统 3–5%），消化池体积减半；依赖 THP 降粘或专用搅拌（干式消化）；常与餐厨协同消化组合
- 流程: 高含固进泥（THP 预处理或直接浓缩）〔泥〕 → 高含固消化池（强力搅拌/干式推流）〔泥〕 → 沼气〔辅助〕 → 脱水、泥饼〔泥〕
- 设计参数: 进泥 8–15% DS; 负荷 4–8 kgVS/(m³·d); HRT 15–20 d
- 适用: 用地紧张的消化扩容、餐厨协同
- 优点: 池容省 50%；单位产气率高
- 缺点: 搅拌传质难度大；氨抑制风险高
