# 28. 污泥磷回收（鸟粪石等结晶法） | Phosphorus Recovery (Struvite Crystallization)

- 诞生: 1987（Phosnix 起运行）
- 成熟度: 成熟主流
- 族/周期: 资源能源回收 / 1980s
- 定位: 把消化液/污泥中的磷结晶成缓释肥料鸟粪石，变「管道结石烦恼」为资源收入
- 简介: 鸟粪石（MgNH₄PO₄·6H₂O）结晶回收通过投加镁源并提升 pH（曝气吹脱 CO₂ 或加碱），使消化液中的 PO₄³⁻-P 与 NH₄⁺ 可控结晶析出，回收率 80–95%，同时解除管道结垢、降低回流磷负荷 20–40%。1987 年日本 Unitika 的 Phosnix 工艺起运行、1998 年建成首座全规模（岛根县 Lake Shinji）；2007–2009 年北美 Ostara Pearl 商业化，产品 Crystal Green 为 99.9% 纯度缓释肥。技术分消化液路线（Pearl、Phosnix、NuReSys、Crystalactor）与消化污泥直接结晶路线（AirPrex，兼改善脱水）；上游 WASSTRIP 等释磷预处理可把回收率再提一倍。全球逾百套装置；欧盟肥料法规与磷危机清单（2014 起）持续驱动市场。

### 变种: Ostara Pearl 流化床结晶 | Ostara Pearl®

- 年份: 2007（首个示范 Edmonton）/2009（首个全商业装置 Durham）
- 差异点: 变径多级流化床，MgCl₂+NaOH 投加，晶体逐层生长至 1–3.5 mm 珍珠状颗粒后收获；技术源自 UBC（公司 2005 年成立）。口径说明：2007 Edmonton Gold Bar 为首个示范/首个商业规模反应器，2009-06 美国俄勒冈 Durham 为首个全商业设施，两说按语境区分
- 流程: 消化液（+WASSTRIP 释磷滤液）〔水〕 → Pearl 流化床反应器（底部进料+MgCl₂/NaOH）〔辅助〕 → 顶部出水回主流前端〔回流〕 → 底部定期收获颗粒〔泥〕 → 水力旋流脱水、热风干、包装外售〔泥〕
- 设计参数: P 回收率 80–90%; N 回收 10–25%; 颗粒 1.0–3.5 mm; 单线 0.5–10 t 鸟粪石/d; Mg:P 摩尔比约 1–1.3
- 适用: 大中型 EBPR 厂消化液；化肥长协消纳模式
- 优点: 产品商品化最成功（14+ 座）；收益分成模式成熟
- 缺点: 需镁源与碱药耗；小颗粒「细晶」逃逸会回负荷

### 变种: AirPrex 消化污泥直接结晶 | AirPrex® (CNP)

- 年份: 2009（首座全规模 MG-Neuwerk；柏林 Wassmannsdorf 2010-03 投运、2011 全规模扩建）
- 差异点: 结晶反应器直接插在消化池与脱水机之间处理「消化污泥」本身：曝气吹 CO₂ 升 pH 至约 8，投 MgCl₂ 结晶，鸟粪石沉入锥底排出洗涤；同时改善脱水（泥饼含固 +4–5 个百分点、聚合物省 20–30%）。柏林水务 BWB 多年试验开发（2006 成型）、CNP 商业化；首厂口径双注——CNP 官网以 2011 Wassmannsdorf 为「全规模」，安装清单与多份报告记 2009 门兴格拉德巴赫 MG-Neuwerk（63 万当量）先投运，本轮核实采信 2009 为首座
- 流程: 消化污泥〔泥〕 → AirPrex 气升结晶反应器（粗气泡曝气吹 CO₂，HRT 约 10 h）〔辅助〕 → 锥底排晶（每日数次）〔泥〕 → 砂洗分离（有机物洗回主流，晶体外运）〔回流〕 → 污泥去脱水机；上清回主流〔泥〕
- 设计参数: HRT 约 10 h; pH 7→8; P 去除 90–95%（对污泥液相）; Wassmannsdorf 产 2500–3000 kg 鸟粪石/d
- 适用: EBPR 厂消化段防垢+脱水改善；柏林、阿姆斯特丹、天津等业绩
- 优点: 脱水与药剂节省占总收益约 70–90%；防垢立竿见影
- 缺点: 结晶在污泥中进行，产品纯度低于流化床路线；曝气能耗附加

### 变种: Phosnix 曝气流化结晶 | Phosnix® (Unitika)

- 年份: 1987 起运行 / 1998 首座全规模
- 差异点: 圆柱+锥底反应器，Mg(OH)₂+NaOH 投加，曝气吹 CO₂ 并流化晶体；产品 0.5–1 mm 晶体；1998 年首座全规模建于日本岛根县 Lake Shinji 东部净水中心
- 流程: 消化上清液/脱水滤液〔水〕 → Phosnix 反应器（底部进料，曝气流化，pH 8.2–8.8）〔辅助〕 → 晶体锥底排出、收集外售〔泥〕 → 出水回主流〔回流〕
- 设计参数: pH 8.2–8.8; P 回收率 80–90%; 单线 ≤1000 m³/d; 产量 500–550 kg/d（500 m³/d 规模）
- 适用: 消化液磷回收（日本市场最早商业化范例）
- 优点: 运行记录最长；设备简单
- 缺点: 产品粒径小需再加工；市场主要在日本

### 变种: Crystalactor 粒丸结晶 | DHV Crystalactor®

- 年份: 约1990s
- 差异点: 流化床内以石英砂为晶种，可产鸟粪石、磷酸钙或碳酸钙粒丸；粒丸沉降性好、纯度可调；兼用于饮用水软化
- 流程: 进水（含 P 或硬度）〔水〕 → Crystalactor 流化床（晶种砂+投药调 pH）〔辅助〕 → 晶体在砂面生长〔水〕 → 底部排粒丸、收集〔泥〕 → 出水回用/排放〔水〕
- 设计参数: P 回收 80–90%; 粒丸 1–2 mm; 表面负荷 30–60 m/h
- 适用: 磷回收、水软化、氟/重金属结晶去除
- 优点: 多产物灵活；粒丸易分离
- 缺点: 晶种砂消耗与补充；操作窗口窄

### 变种: NuReSys / PHOSPAQ 等搅拌结晶变体 | NuReSys® 等

- 年份: 约2000s
- 差异点: 搅拌结晶罐（非流化床），曝气吹 CO₂+MgCl₂/MgO 投加；PHOSPAQ 用 MgO 兼作镁源与碱源，气升混合
- 流程: 消化液〔水〕 → 吹脱/结晶搅拌罐（投镁源+碱）〔辅助〕 → 晶体沉降分离〔泥〕 → 洗涤干燥、产品〔泥〕 → 出水回主流〔回流〕
- 设计参数: pH 8.1–8.3; P 回收 80–90%; 搅拌强度控制粒径
- 适用: 中小型厂、工业高磷废水（食品加工）
- 优点: 设备简单、造价低
- 缺点: 晶体细小、分离效率低；业绩少于 Pearl/AirPrex

### 变种: WASSTRIP 释磷预处理 | WASSTRIP™ (Ostara)

- 年份: 约2011–2015
- 差异点: 不是结晶器而是「前置释磷」：初沉污泥+剩余污泥在厌氧释磷罐（HRT 3–6 h）中把污泥内磷释入液相，浓缩滤液富磷富镁后送 Pearl 结晶，把回收量翻倍并缓解全厂结垢；美国第三套 2015-07 Gwinnett County 投运
- 流程: 初沉污泥+WAS〔泥〕 → 释磷罐（厌氧 3–6 h）〔泥〕 → 转鼓浓缩〔泥〕 → 富磷滤液至 Pearl 结晶器〔水〕 → 浓缩污泥去消化〔泥〕 → 晶体收获线同 Pearl〔泥〕
- 设计参数: HRT 3–6 h; 滤液 PO₄-P 可达 200–500 mg/L; 全厂 P 回收率提至 40–60%（相对进水磷）
- 适用: EBPR 厂追求高回收率；与 Pearl 捆绑
- 优点: 回收率倍增；减少消化与脱水段结垢
- 缺点: 增加构筑物与控制系统；释磷罐臭气管理
