# 06. 高级氧化与深度物化处理 | Advanced Oxidation & Polishing (AOP/吸附/离子交换)

- 诞生: 1894（Fenton 试剂）；污水深度应用 2000s 起
- 成熟度: 成熟主流
- 族/周期: 高级氧化与深度 / 1880-1909
- 定位: 针对微污染物、难降解 COD、色度与消毒副产物前体的「最后一公里」深度处理家族
- 简介: 高级氧化以羟基自由基 ·OH（E⁰=2.8 V）无差别矿化有机物为核心：臭氧直接氧化+分解产 ·OH；Fenton（1894 年发现）以 Fe²⁺/H₂O₂ 链式产 ·OH；UV/H₂O₂、UV/Cl₂ 光解产自由基；光催化（1972 Fujishima-Honda 效应）以 TiO₂ 受光激发产 ·OH；电化学氧化在阳极表面直接/间接氧化。瑞士 2014 年起立法要求污水厂去除微污染物，臭氧与活性炭成为标配；臭氧-BAC 把氧化后的可生化中间体再接生物滤池。吸附路线（PAC/GAC）不降解污染物但转移富集；离子交换面向硝酸盐、氟、全氟化合物等特异性离子。
- 来源:
  - https://www2.mst.dk/Udgiv/publikationer/2021/03/978-87-7038-291-5.pdf
  - https://link.springer.com/chapter/10.1007/978-3-642-01999-9_1

共 8 个变种。

### 变种: 臭氧氧化 | Ozonation

- 年份: 1906（饮用水首用）/约2000s（污水微污染物规模化）
- 差异点: O₃ 直接氧化（选择性）+ 分解产 ·OH（非选择性）双路径；兼具消毒脱色；尾气需破坏
- 流程: 二级出水〔水〕 → 臭氧接触池（扩散器/文丘里投加）〔辅助〕 → 余臭氧淬灭〔辅助〕 → （可选）BAC〔水〕 → 出水〔水〕 → 尾气破坏器〔辅助〕
- 设计参数: O₃ 投加 0.4–1.0 gO₃/gDOC（微污染物约 5–15 mg/L）; 接触 10–20 min; 能耗约 0.05–0.15 kWh/m³; 微污染物去除率 >80%
- 适用: 微污染物（药品、内分泌干扰物）去除、脱色、再生水消毒
- 优点: 无化学残留、氧化力强；兼消毒
- 缺点: 可能生成溴酸盐/亚硝基副产物；制氧能耗高

### 变种: 臭氧-生物活性炭 | O₃-BAC

- 年份: 约1970s（饮用水）/1990s–2000s（污水推广）
- 差异点: 臭氧把难降解大分子剪碎为可生化小分子，BAC 滤池生物降解+活性炭吸附双效，降低臭氧量并稳定出水 COD
- 流程: 二级出水〔水〕 → 臭氧接触〔辅助〕 → BAC 滤池（下向流，颗粒活性炭+生物膜）〔水〕 → 出水〔水〕 → 反冲水回流前端〔回流〕 → 饱和炭更换/再生〔泥〕
- 设计参数: O₃ 投加 3–8 mg/L; BAC 空床接触时间 EBCT 10–30 min; 滤速 5–10 m/h; COD 去除率较单独臭氧提升 10–30%
- 适用: 再生水、准四类/地表 Ⅳ 类提标、水源水预处理
- 优点: 出水稳定性好；炭寿命因生物再生延长
- 缺点: 占地大；反冲管理复杂；炭更换成本高

### 变种: Fenton 与类 Fenton | Fenton & Fenton-like

- 年份: 1894（发现）/约1960s 起废水应用
- 差异点: Fe²⁺+H₂O₂ 在 pH 2.5–4 产 ·OH；类 Fenton 用铁碳、铁泥、光/电/超声协同扩 pH 窗口并减泥；工业难降解废水深度处理的重炮
- 流程: 废水调 pH 至 3–4（加酸）〔辅助〕 → 投加 Fe²⁺ 与 H₂O₂〔辅助〕 → 氧化反应池（HRT 0.5–2 h）〔水〕 → 调碱中和沉淀〔辅助〕 → 铁泥分离至污泥线〔泥〕 → 出水〔水〕
- 设计参数: H₂O₂/Fe²⁺ 摩尔比约 1–10:1; H₂O₂ 投加 0.1–2 g/L; pH 2.8–3.5 最优; 铁泥产量 0.5–2 kg/kgH₂O₂
- 适用: 制药、化工、印染、渗滤液浓液等难降解 COD 削减
- 优点: 氧化力最强档、反应快；设备简单
- 缺点: 酸碱来回调节、铁泥量大；pH 窗口窄（类 Fenton 缓解中）

### 变种: UV 高级氧化 | UV-AOP (UV/H₂O₂、UV/Cl₂)

- 年份: 约1990s–2000s
- 差异点: 紫外光解氧化剂产自由基；UV/Cl₂ 因氯自由基选择性降解受关注；常与双膜法串联作第三屏障
- 流程: RO 产水/二级出水〔水〕 → 投加 H₂O₂ 或 NaClO〔辅助〕 → 中压 UV 反应器〔辅助〕 → 自由基氧化微污染物〔水〕 → 余氧化剂淬灭〔辅助〕 → 出水〔水〕
- 设计参数: UV 剂量 500–1000 mJ/cm²; H₂O₂ 3–10 mg/L; 对 NDMA、1,4-二噁烷去除 >99%（log 级）; 能耗 0.1–0.3 kWh/m³
- 适用: 间接饮用回用（IPR）、微污染物达标、消毒副产物控制
- 优点: 无污泥无残留；对 RO 难截留小分子（NDMA）有效
- 缺点: 灯管老化与套管结垢；能耗高于单独臭氧（视水质）

### 变种: 光催化氧化 | Photocatalysis (TiO₂ 等)

- 年份: 1972（原理）/2000s 起废水示范
- 差异点: TiO₂ 等半导体受 UV/可见光激发产生电子-空穴对与 ·OH；可见光响应改性（掺杂、异质结）为研究热点
- 流程: 废水〔水〕 → 光催化反应器（固定化膜/悬浮浆态+光照）〔辅助〕 → 氧化降解〔水〕 → 催化剂分离回用（膜/沉淀）〔回流〕 → 出水〔水〕
- 设计参数: 催化剂负载 0.1–2 g/L（浆态）; HRT 0.5–4 h; 难降解有机物去除 60–95%（中试范围）
- 适用: 低浓度难降解废水、室内空气/自洁净表面延伸场景
- 优点: 可利用太阳光；无药剂消耗
- 缺点: 光利用率低、催化剂回收难；工程化业绩少

### 变种: 电化学氧化 | Electrochemical Oxidation (EO)

- 年份: 约1990s 起探索 / 2010s（BDD 阳极推动示范）
- 差异点: 阳极直接电子转移 + 间接产生活性氯/·OH/过硫酸盐；BDD 阳极氧化能力最强但造价高；模块化成撬装
- 流程: 废水（调盐度/pH）〔辅助〕 → 电化学反应器（BDD/Pt/DSA 阳极，恒流）〔辅助〕 → 氧化降解〔水〕 → 脱气（除 H₂/Cl₂）〔辅助〕 → 出水〔水〕
- 设计参数: 电流密度 10–50 mA/cm²; 能耗 5–50 kWh/kgCOD; 氨氮、渗滤液浓液 COD 去除 80–99%
- 适用: 渗滤液浓液、高盐难降解废水、小型撬装应急
- 优点: 无需加药、占地小；即开即停
- 缺点: 能耗与电极成本高；析氯副产物需控

### 变种: 活性炭吸附 | PAC/GAC Adsorption

- 年份: 约1960s（GAC 滤池）/2000s（PAC 微污染物）
- 差异点: PAC 粉末炭随流投加+沉淀/超滤截留；GAC 固定床滤池定期更换再生；瑞士微污染物路线两大支柱之一
- 流程: 二级出水〔水〕 → PAC 接触池（10–20 mg/L 投加）〔辅助〕 → 絮凝沉淀/超滤截留炭粉〔水〕 → 出水〔水〕 → 废炭去污泥线焚烧 / GAC 饱和炭热再生〔泥〕
- 设计参数: PAC 投加 10–30 mg/L; GAC EBCT 10–30 min、滤速 5–15 m/h; 微污染物去除 >80%; 炭耗成本约 0.05–0.15 €/m³（欧洲量级）
- 适用: 微污染物、色度、嗅味；与臭氧互补或竞争路线
- 优点: 无氧化副产物；对 PFAS 等臭氧难降解物有效
- 缺点: 污染物只转移不矿化；废炭处置/再生成本

### 变种: 离子交换 | Ion Exchange (IX)

- 年份: 约1950s（软化）/2000s 起（选择性树脂）
- 差异点: 选择性树脂靶向吸附 NO₃⁻、ClO₄⁻、PFAS、氟等；新兴方向为氨氮选择性交换+再生液资源回收
- 流程: 进水〔水〕 → 保安过滤〔水〕 → 离子交换柱（选择性树脂）〔辅助〕 → 出水〔水〕 → 盐水再生，再生废液去浓缩/处置〔泥〕
- 设计参数: 床体积流速 BV 5–20 h⁻¹; NO₃⁻ 去除 >90%; 再生周期数百至数千 BV
- 适用: 地下水硝酸盐、特种离子达标、PFAS 应急
- 优点: 选择性极高；出水稳定
- 缺点: 再生废液处置难；悬浮物预处理要求高
