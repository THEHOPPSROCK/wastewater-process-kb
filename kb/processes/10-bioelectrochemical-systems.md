# 10. 生物电化学系统 | Bioelectrochemical Systems (MFC/MEC/MES)

- 诞生: 1911（现象发现）；现代 MFC 约1999 复兴
- 成熟度: 前沿研发
- 族/周期: 资源能源回收 / 1910s-1940s
- 定位: 让微生物在电极上「呼吸」，把污水中的化学能直接变成电或氢气的理想型技术
- 简介: 1911 年英国 Potter 发现微生物产电现象；1990s 末现代 MFC 复兴。MFC 中产电菌（Geobacter 等）在阳极氧化有机物并把电子交给电极，阴极还原氧气产电；MEC（约 2005，Penn State）外加小电压（>0.2 V）即可在阴极产氢，理论能耗远低于电解水；MES 反向用电流驱动微生物合成乙酸/甲烷等化学品。功率密度与放大是世纪难题：实验室功率密度已从 mW/m² 级升至数 W/m²，但立方米级堆体的欧姆损耗与膜成本使工程化停滞。现实切入点为小型分散电源、BOD 在线传感器与阴极回收金属/氨等产物导向变体。
- 来源:
  - https://www.mdpi.com/1996-1073/11/7/1675

共 3 个变种。

### 变种: 微生物燃料电池 | Microbial Fuel Cell (MFC)

- 年份: 1911（发现）/约1999（复兴）
- 差异点: 双室（质子交换膜分隔）或单室（空气阴极）构型；直接产电但功率密度低（实用化 <1–2 W/m³）
- 流程: 废水入阳极室〔水〕 → 产电菌氧化 COD、电子经外电路至阴极〔辅助〕 → 阴极氧还原〔辅助〕 → 出水〔水〕 → 定期换电极/膜〔辅助〕
- 设计参数: COD 去除 60–90%; 库仑效率 10–40%; 功率密度 0.1–2 W/m³（中试）; HRT 6–24 h
- 适用: 分散式微电源、BOD 生物传感器、生态修复原位供电
- 优点: 污泥极少；理论能量直收
- 缺点: 功率密度与成本远不达标；膜与电极放大衰减严重

### 变种: 微生物电解池 | Microbial Electrolysis Cell (MEC)

- 年份: 约2005
- 差异点: 外加 0.2–0.8 V 小电压，阴极产 H₂（或 CH₄）；理论电耗仅为电解水的 1/3–1/2；与厌氧消化/发酵耦合可提级沼液
- 流程: 废水/发酵液入 MEC 阳极〔水〕 → 生物氧化产电子质子+外加电源〔辅助〕 → 阴极析氢〔辅助〕 → 气体收集净化〔辅助〕 → 出水回生化线〔回流〕
- 设计参数: 外加电压 0.2–0.8 V; 氢产率 0.5–3 m³H₂/(m³·d)（中试）; 能量效率可达 200–400%（含基质能）
- 适用: 沼液提氢、难降解残余 COD 深度利用
- 优点: 产氢门槛电压远低于水电解；兼降解有机物
- 缺点: 氢气收集与膜污染；放大堆体电流分布不均

### 变种: 微生物电合成与资源回收变体 | MES / 电化学回收

- 年份: 约2010s
- 差异点: 反向供电驱动阴极微生物固定 CO₂ 合成乙酸/乙醇/甲烷；或阴极电沉积回收氨（鸟粪石）、铜等
- 流程: CO₂/发酵尾气入阴极室〔辅助〕 → 电活性菌+供电合成产物〔辅助〕 → 产物分离〔辅助〕 → 或含氨废水阴极析鸟粪石回收〔泥〕
- 设计参数: 电流密度 1–10 A/m²; 产物选择性 50–90%（中试）
- 适用: 碳捕集利用、氨回收的前沿探索
- 优点: 电-化学品转化路径短
- 缺点: 速率低、产物分离难；无量产前景证据
