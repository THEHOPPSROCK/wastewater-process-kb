# 25. 厌氧膜生物反应器 | Anaerobic MBR (AnMBR)

- 诞生: 1978（概念）；1980 首个商业系统 MARS
- 成熟度: 商业化初期
- 族/周期: 厌氧生物 / 1970s
- 定位: 无曝气、产沼气、出水无菌的能源回收型主流处理候选工艺
- 简介: AnMBR 将厌氧消化与膜分离耦合，SRT 与 HRT 完全解耦，可在 20–40 ℃ 甚至常温下处理市政污水，把进水 COD 直接转化为沼气而非曝气掉，理论上是「产能型」主流工艺，污泥产率仅为好氧工艺的 1/5–1/10。1978 年 Grethlein 提出概念（化粪池出水+外置错流膜），1980 年 Dorr-Oliver 推出首个商业化系统 MARS（乳清废水），1987 年南非建成 ADUF。瓶颈在于膜污染控制能耗（沼气擦洗）、出水溶解甲烷逸散以及低温下厌氧动力学慢；目前在食品饮料等高浓度废水领域已有数百套业绩。
- 来源:

共 4 个变种。

### 变种: 外置式厌氧膜系统 | MARS / ADUF (Side-stream AnMBR)

- 年份: 1980（MARS）/1987（ADUF）
- 差异点: 厌氧 CSTR+外置管式膜错流过滤；能耗高但膜可控性好，开创了厌氧+膜的工程先例
- 流程: 高浓度废水调节〔水〕 → 厌氧 CSTR（中温 35 ℃）〔水〕 → 沼气收集（脱硫后利用）〔辅助〕 → 混合液泵入外置管式膜、产水〔辅助〕 → 膜浓水回流 CSTR〔回流〕 → 剩余厌氧污泥少量外排〔泥〕
- 设计参数: HRT 2–10 d; SRT 30–100+ d; 容积负荷 5–15 kgCOD/(m³·d); 膜通量 10–30 LMH; 污泥产率 0.05–0.15 kgVSS/kgCOD
- 适用: 乳品、酿酒等高浓度有机工业废水
- 优点: 无需曝气、净产能；出水 SS 为零
- 缺点: 错流循环能耗高；早期膜成本高限制推广

### 变种: 浸没式厌氧 MBR | Submerged AnMBR / KSAMBR

- 年份: 约1990s 末
- 差异点: 平板膜浸没于厌氧池（日本 Kubota，后称 KSAMBR），用自产沼气循环擦洗膜面控污，省去循环泵，能耗大幅下降
- 流程: 废水〔水〕 → 厌氧膜池（平板膜浸没、沼气鼓泡擦洗）〔辅助〕 → 抽吸产水〔辅助〕 → 后续好氧抛光（如需脱氮）、排放〔水〕 → 池顶沼气经脱硫进储柜/锅炉〔辅助〕 → 剩余污泥少量外排〔泥〕
- 设计参数: HRT 0.5–5 d; SRT 50–200 d; 膜通量 3–10 LMH; 沼气产量 0.3–0.45 Nm³CH₄/kgCOD; 膜侧能耗约 0.1–0.3 kWh/m³
- 适用: 食品、饮料、酿造废水；市政主流试验中
- 优点: 沼气擦洗免外加能耗；占地小、产泥极少
- 缺点: 溶解甲烷回收难；低温市政场景通量衰减明显

### 变种: ADI-AnMBR（大型工程化） | ADI-AnMBR

- 年份: 2008
- 差异点: CSTR+浸没膜箱的模块化大型工程方案；首创 AnMBR+好氧 MBR 串联路线；加拿大 ADI Systems（后并入 Evoqua）业绩最多；北美首套 Ken's Foods（475 m³/d、进水 COD 39 g/L）
- 流程: 废水调节/换热〔水〕 → 厌氧 CSTR（36 ℃ 中温）〔水〕 → 浸没膜箱（沼气擦洗）〔辅助〕 → 产水（COD 去除 >99%）〔水〕 → （可选）好氧 MBR 抛光、达标排放〔水〕 → 沼气利用；污泥回流 CSTR〔回流〕 → 剩余污泥去污泥线〔泥〕
- 设计参数: 容积负荷 8–15 kgCOD/(m³·d); HRT 1–5 d; 出水 COD <500 mg/L; SRT >100 d
- 适用: 食品饮料、油脂加工等高浓度工业废水
- 优点: 工程业绩成熟、去除率 >99%；副产沼气收益明确
- 缺点: 仅适合高浓度废水；脱氮除磷需后端工艺

### 变种: 厌氧动态膜生物反应器 | Anaerobic Dynamic MBR (AnDMBR)

- 年份: 2008
- 差异点: 用无纺布/筛网等廉价粗孔基材替代微滤膜，靠泥饼层（动态膜）实现过滤；造价与阻力低，但出水水质波动大；智利 David Jeison 等提出
- 流程: 废水〔水〕 → 厌氧反应器（含粗孔基材组件）〔水〕 → 动态膜层形成后抽吸产水〔辅助〕 → 出水〔水〕 → 沼气收集；动态膜失效后水力冲洗再生〔辅助〕
- 设计参数: 通量 5–20 LMH（波动）; 基材孔径 10–100 μm; 出水浊度高于常规膜
- 适用: 低成本分散处理、发展中国家市政试点
- 优点: 膜材料成本降 90% 以上；抗污染层可原位再生
- 缺点: 出水水质不稳定；尚无规模化商业业绩
