# 11. 传统活性污泥法及其负荷/流态变型 | Conventional Activated Sludge & Loading/Flow Variants

- 诞生: 1914
- 成熟度: 成熟主流
- 族/周期: 悬浮生长生物 / 1910s-1940s
- 定位: 悬浮生长好氧生物处理的母工艺，一切活性污泥变型的基础
- 简介: 1914 年 4 月 3 日 Ardern 与 Lockett 在曼彻斯特宣读经典论文，1916 年美国德州 San Marcos 建成首座活性污泥厂。污水与回流活性污泥在曝气池中混合曝气，好氧微生物将有机物氧化为 CO₂ 与细胞物质，硝化菌将氨氮氧化为硝酸盐；混合液在二沉池泥水分离，污泥大部分回流、少量作为剩余污泥排出。核心参数为 SRT（泥龄）、F/M（食微比）与回流比。发明后迅速扩散，衍生出推流、完全混合、阶段曝气、接触稳定、延时曝气等一系列负荷与流态变型。
- 来源:

共 6 个变种。

### 变种: 传统推流式活性污泥法 | Conventional Plug-Flow Activated Sludge

- 年份: 1917
- 差异点: 狭长廊道池、水流推流前进，沿程污染物浓度递减、需氧前高后低
- 流程: 进水经格栅、沉砂、初沉〔水〕 → 曝气池（推流廊道，鼓风曝气）〔水〕 → 二沉池〔水〕 → 消毒、出水〔水〕 → RAS 回流至曝气池首端〔回流〕 → WAS 至浓缩-消化-脱水〔泥〕
- 设计参数: HRT=4–8 h; SRT=5–15 d; F/M=0.2–0.4 kgBOD/(kgMLVSS·d); MLSS=1500–3000 mg/L; 回流比 R=25–75%; 二沉池表面负荷 1.0–1.5 m³/(m²·h)
- 适用: 大中型市政污水厂、水质水量较稳定场景
- 优点: 出水水质好（可硝化）；处理效率高；运行经验丰富
- 缺点: 首端需氧集中易缺氧；抗冲击负荷差；占地大

### 变种: 完全混合式活性污泥法 | Completely Mixed Activated Sludge (CMAS)

- 年份: 约1927
- 差异点: 入流迅速与全池混合液均匀混合，池内各点浓度一致，抗冲击负荷强；1960 年 McKinney 系统化理论
- 流程: 进水经预处理〔水〕 → 完全混合曝气池（机械表曝或鼓风曝气）〔水〕 → 二沉池〔水〕 → 消毒、出水〔水〕 → RAS 回流 / WAS 排放至污泥线〔回流〕
- 设计参数: HRT=3–6 h; SRT=5–15 d; F/M=0.2–0.6 kgBOD/(kgMLVSS·d); MLSS=2000–4000 mg/L; R=50–100%
- 适用: 工业废水、有毒/冲击负荷废水、小型市政厂
- 优点: 抗冲击强；进水稀释快；运行稳定
- 缺点: 出水水质略逊于推流；低 F/M 易污泥膨胀

### 变种: 阶段曝气/分步进水 | Step Aeration / Step-Feed

- 年份: 1939–1942
- 差异点: 进水沿曝气池 3–4 个点位分段进入，均衡全池需氧量，提高容积利用率；纽约 Tallman Island 厂 Gould 首创
- 流程: 进水经预处理、初沉〔水〕 → 曝气池（4 廊道，进水分点注入）〔水〕 → 二沉池〔水〕 → 消毒、出水〔水〕 → RAS 至首端 / WAS 至污泥线〔回流〕
- 设计参数: HRT=3–5 h; SRT=5–10 d; F/M=0.2–0.4; MLSS=2000–3500 mg/L; R=25–75%
- 适用: 大中型厂扩容改造；峰值流量调节；兼作 BNR 分步进水脱氮
- 优点: 池容省约 1/3；需氧均衡；可灵活切换运行模式
- 缺点: 自控阀门多；运行管理较复杂

### 变种: 接触稳定法 | Contact Stabilization (Biosorption)

- 年份: 1951
- 差异点: 有机物先在接触池（0.5–1 h）被污泥快速吸附，污泥单独在稳定池（3–6 h）再曝气氧化，曝气总池容大幅减少；美国 Austin，Ullrich & Smith
- 流程: 进水经预处理〔水〕 → 接触池（与回流污泥混合短曝气）〔水〕 → 二沉池〔水〕 → 出水〔水〕 → 沉淀污泥至稳定池再曝气后回流〔回流〕 → WAS 排放〔泥〕
- 设计参数: 接触 HRT=0.5–1.0 h; 稳定 HRT=3–6 h（全系统 SRT 5–10 d）; MLSS（接触池）=1000–3000 mg/L; R=50–150%; 总池容约为传统法 50–60%
- 适用: 中小规模市政污水、可生化性好且含较多悬浮/胶体有机物的废水
- 优点: 池容小、基建省；抗冲击好
- 缺点: 对溶解性有机物为主的废水不适用；硝化能力弱；出水水质一般

### 变种: 延时曝气 | Extended Aeration

- 年份: 约1940s
- 差异点: 极低负荷、长泥龄运行，污泥自身氧化（内源呼吸）比例高，剩余污泥少且基本稳定，常不设初沉池；1950s 成套设备化
- 流程: 进水经格栅/沉砂〔水〕 → 曝气池（HRT 16–24 h）〔水〕 → 二沉池〔水〕 → 消毒、出水〔水〕 → RAS 回流 / WAS 少量排放〔回流〕
- 设计参数: HRT=16–24 h; SRT=18–30 d; F/M=0.05–0.15 kgBOD/(kgMLVSS·d); MLSS=2000–4000 mg/L; R=50–200%
- 适用: 小型社区、乡镇、度假村、学校等分散式污水
- 优点: 污泥量少且稳定（可不设消化系统）；硝化彻底；管理简单
- 缺点: 占地与曝气能耗大；低温下氨氮波动；成套设备规模受限

### 变种: 高负荷/改良曝气 | High-Rate & Modified Aeration

- 年份: 约1940s
- 差异点: 短 HRT、低 MLSS、高 F/M，只作部分处理（BOD 去除 60–70%），作粗处理或前段
- 流程: 进水经预处理〔水〕 → 短曝气池（1.5–3 h）〔水〕 → 二沉池〔水〕 → 出水（或接二级单元）〔水〕 → RAS 回流〔回流〕
- 设计参数: HRT=1.5–3 h; SRT=1–3 d; F/M=0.5–1.5; MLSS=300–1000 mg/L
- 适用: 工业废水预处理、负荷削减前段、排放标准不高的过渡性工程
- 优点: 池容极小；投资省
- 缺点: 出水水质差；污泥产率高、沉降性差
