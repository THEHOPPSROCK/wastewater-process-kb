# 07. 稳定塘（氧化塘） | Waste Stabilization Ponds

- 诞生: 1901
- 成熟度: 成熟经典
- 族/周期: 自然生态 / 1880-1909
- 定位: 利用自然生态过程（菌藻共生）处理污水的最经济土地密集型工艺
- 简介: 稳定塘依靠藻类光合作用供氧、细菌降解有机物、长停留时间沉淀与灭活病原体。天然塘利用已有 3000 年历史，1901 年 San Antonio 塘为首座有记录工程，1924 年加州 Santa Rosa 塘运行数据推动工程化认知，1950s 起成为小城镇经济选择（美国 8000+ 座）。按溶解氧分层分为厌氧塘、兼性塘、好氧塘与熟化塘，常串联使用；曝气塘以机械曝气强化。以收获藻类为导向的高速率藻塘（HRAP）见大类「藻类处理与菌藻共生」。
- 来源:
  - https://www.epa.gov/sites/default/files/2014-09/documents/lagoon-pond-treatment-2011.pdf
  - https://www.sciencedirect.com/science/article/pii/S0959652618302270

共 5 个变种。

### 变种: 好氧塘 | Aerobic (High-Rate) Pond

- 年份: 约1950s
- 差异点: 全塘好氧、水深最浅（0.3–0.5 m），藻类高产；资源化导向的搅拌跑道池形态即 HRAP，见「藻类处理」大类
- 流程: 进水（经前处理）〔水〕 → 好氧塘（浅层、可搅拌）〔水〕 → 藻类分离（沉淀/气浮）〔泥〕 → 出水〔水〕
- 设计参数: 水深 0.3–0.5 m; HRT=3–10 d; BOD 负荷 80–200 kg/(ha·d)
- 适用: 温暖日照充足地区、资源回收（藻蛋白）
- 优点: 处理效率高；产藻类资源
- 缺点: 藻水分离难；仅限温暖气候

### 变种: 兼性塘 | Facultative Pond

- 年份: 1901
- 差异点: 上层好氧（藻类供氧）、中层兼性、底层厌氧（污泥消化），三层协同；最常见的塘型
- 流程: 进水（格栅/沉砂）〔水〕 → 兼性塘（水深 1–2.5 m）〔水〕 → 熟化塘〔水〕 → 出水灌溉/排放〔水〕 → 塘底污泥数年清掏一次〔泥〕
- 设计参数: 水深 1–2.5 m; HRT=20–60 d; BOD 表面负荷 20–60 kg/(ha·d)（随纬度调整）
- 适用: 小城镇、土地充裕地区
- 优点: 几乎无能耗；耐冲击；BOD/病原体去除好
- 缺点: 占地巨大；受季节温度影响；底泥长期累积

### 变种: 厌氧塘 | Anaerobic Pond

- 年份: 约1920s–1950s
- 差异点: 水深 2–5 m、全塘厌氧，承接高负荷有机废水，BOD 去除 40–70%，后续必须接好氧/兼性塘
- 流程: 进水〔水〕 → 厌氧塘（深塘，HRT 1–7 d）〔水〕 → 兼性塘〔水〕 → 熟化塘〔水〕 → 出水〔水〕
- 设计参数: 水深 2–5 m; HRT=1–7 d; 容积负荷 100–400 gBOD/(m³·d)
- 适用: 高浓度有机废水（屠宰、食品）前处理、热带地区
- 优点: 负荷高；污泥产率低
- 缺点: 臭气（H₂S）；出水必须后处理

### 变种: 曝气塘 | Aerated Lagoon

- 年份: 约1950s–1960s
- 差异点: 表面曝气机或鼓风曝气供氧，水深 2–5 m；分完全混合好氧曝气塘与部分混合兼性曝气塘
- 流程: 进水〔水〕 → 曝气塘（曝气机）〔辅助〕 → 沉淀塘/二沉池〔水〕 → 出水〔水〕 → 污泥定期排放〔泥〕
- 设计参数: HRT=3–10 d; 水深 2–5 m; 功率输入 1–6 W/m³（部分混合）或 >10 W/m³（完全混合）
- 适用: 用地有限但不足以建活性污泥厂的小城镇
- 优点: 占地小于兼性塘；出水优于自然塘
- 缺点: 有电耗；藻类/SS 出水偏高

### 变种: 熟化塘（精制塘） | Maturation Pond

- 年份: 约1950s 起
- 差异点: 浅（0.5–1.5 m）、负荷极低，主要靠光照与 pH 升高灭活病原体
- 流程: 兼性塘出水〔水〕 → 熟化塘 1〔水〕 → 熟化塘 2（串联）〔水〕 → 出水〔水〕
- 设计参数: 水深 0.5–1.5 m; 单塘 HRT=5–10 d; 粪大肠菌群去除可达 99.99%
- 适用: 出水回用（灌溉）前的卫生学屏障
- 优点: 无动力去除病原体；脱氮（氨挥发/藻吸收）
- 缺点: 占地；藻类致出水 SS 偏高
