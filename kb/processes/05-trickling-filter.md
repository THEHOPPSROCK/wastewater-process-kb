# 05. 滴滤池（生物滤池） | Trickling Filter

- 诞生: 1890
- 成熟度: 成熟经典
- 族/周期: 固着生长生物 / 1880-1909
- 定位: 固定床生物膜法的鼻祖——污水喷淋通过填料床，生物膜氧化有机物
- 简介: 污水经旋转布水器均匀洒布于碎石或塑料填料表面，自上而下渗滤，填料表面生物膜降解有机物与氨氮；空气靠自然通风或强制通风自下而上供氧，脱落的生物膜（腐殖污泥）由后沉池分离。1890 年 Lawrence 实验站建成首个真正意义的滴滤池，1893 年英国 Salford 首座市政应用，1901 年美国 Madison 首座市政应用。20 世纪上半叶为二级处理主力，现多用于中小厂、工业废水与粗滤前段。
- 来源:

共 4 个变种。

### 变种: 低负荷（标准）滴滤池 | Low-Rate / Standard-Rate Trickling Filter

- 年份: 1893
- 差异点: 无回流或低回流，负荷低，可达到完全硝化；滤蝇问题突出
- 流程: 进水经格栅、沉砂、初沉〔水〕 → 滴滤池（碎石填料 1.5–2 m 深）〔水〕 → 后沉池〔水〕 → 出水〔水〕 → 腐殖污泥至污泥线〔泥〕
- 设计参数: 水力负荷 1–4 m³/(m²·d); 有机负荷 0.08–0.32 kgBOD/(m³·d); BOD 去除 80–90%（可硝化）
- 适用: 小型市镇、气候温和地区
- 优点: 能耗极低（靠自然通风）；管理简单
- 缺点: 占地大；滤蝇与孳生虫害；冬季效率下降

### 变种: 高负荷滴滤池 | High-Rate Trickling Filter

- 年份: 约1930s–1940s
- 差异点: 出水回流稀释进水、提高喷淋密度冲刷生物膜，负荷提高 5–10 倍；塑料填料允许塔式构型
- 流程: 进水经初沉〔水〕 → 高负荷滴滤池〔水〕 → 出水回流（比 0.5–2）〔回流〕 → 后沉池〔水〕 → 出水（或二级串联）〔水〕 → 污泥至污泥线〔泥〕
- 设计参数: 水力负荷 8–40 m³/(m²·d); 有机负荷 0.4–1.2 kgBOD/(m³·d); BOD 去除 65–85%（单级）
- 适用: 中型厂、工业废水粗处理
- 优点: 占地比低负荷小得多；不易堵塞
- 缺点: 出水一般不达标需二级串联；回流泵能耗

### 变种: 塔式生物滤池 | Biotower (Plastic Media Tower)

- 年份: 约1950s–1960s
- 差异点: 轻质塑料填料堆高 4–12 m，垂直塔式布置，占地极小
- 流程: 进水经初沉〔水〕 → 塔式滤池（顶部布水）〔水〕 → 后沉池〔水〕 → 出水〔水〕 → 常作活性污泥前粗滤（TF/AS 组合）〔水〕
- 设计参数: 有机负荷 0.8–2.0 kgBOD/(m³·d)（粗滤可更高）; 水力负荷 20–80 m³/(m²·d)
- 适用: 工业废水预处理、用地紧张改扩建
- 优点: 占地极小；抗冲击、能耗低
- 缺点: 出水水质有限；填料投资高

### 变种: 滴滤池-活性污泥组合 | Trickling Filter / Solids Contact (TF/SC) & TF/AS

- 年份: 约1970s–1980s
- 差异点: 滴滤池后接短曝气固体接触池，絮凝脱膜污泥、稳定出水水质
- 流程: 进水经初沉〔水〕 → 滴滤池〔水〕 → 固体接触曝气池（HRT 1–2 h）〔水〕 → 二沉池〔水〕 → 出水〔水〕 → RAS 回流 / WAS 排放〔回流〕
- 设计参数: 接触池 HRT=1–2 h; MLSS=1500–2500 mg/L; 组合出水 BOD/SS ≤20 mg/L
- 适用: 老滴滤池厂提标改造
- 优点: 旧设施利用；能耗低于全活性污泥
- 缺点: 流程单元多
