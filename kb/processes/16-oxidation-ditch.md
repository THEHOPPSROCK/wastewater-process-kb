# 16. 氧化沟家族 | Oxidation Ditch Family

- 诞生: 1954
- 成熟度: 成熟主流
- 族/周期: 悬浮生长生物 / 1950s-1960s
- 定位: 环形沟渠中的延时曝气活性污泥法，兼有推流与完全混合特征
- 简介: 氧化沟是首尾相连的环形曝气沟渠，混合液在沟内循环流动（流速 0.25–0.35 m/s），转刷/转盘/表曝机兼作充氧与推流。低负荷长泥龄（SRT 15–30 d）运行，污泥稳定、硝化彻底；沟内沿程形成好氧-缺氧分区，可同步硝化反硝化，一般不设初沉池。1920 年英国 Sheffield 桨板曝气沟渠被视为雏形（Kessener 1925 年起研制转刷），1954 年 Pasveer 设计首座氧化沟。全球数千座，是中小型市政厂经典选择。
- 来源:

共 6 个变种。

### 变种: 帕斯维尔氧化沟 | Pasveer Oxidation Ditch

- 年份: 1954
- 差异点: 单沟跑道型，Kessener 转刷曝气，早期间歇运行，后期加二沉池连续运行；水深一般 ≤1.5 m
- 流程: 进水经格栅/沉砂〔水〕 → 氧化沟（转刷曝气，循环流）〔水〕 → 二沉池〔水〕 → 消毒、出水〔水〕 → RAS 回流至沟首 / WAS 至污泥线〔回流〕
- 设计参数: HRT=16–24 h; SRT=15–30 d; F/M=0.05–0.10; MLSS=3000–5000 mg/L; R=50–100%
- 适用: 小城镇、农村地区市政污水
- 优点: 工艺极简、污泥稳定；出水水质好
- 缺点: 水深浅、占地大；转刷充氧效率一般

### 变种: 卡鲁塞尔氧化沟 | Carrousel

- 年份: 1967–1968
- 差异点: 多廊道串联、立式低速表曝机置于廊道端部，水深可达 4–5 m，占地小于 Pasveer。年份双注：1967 年 DHV（工程师 R.J. Klein）发明第一代系统，1968 年首座工程建于荷兰 Oosterwolde（本轮据 Royal HaskoningDHV 档案史料核实）
- 流程: 进水经格栅/沉砂〔水〕 → Carrousel 氧化沟（表曝机+廊道循环）〔水〕 → 二沉池〔水〕 → 消毒、出水〔水〕 → RAS/WAS 至污泥线〔回流〕
- 设计参数: HRT=18–24 h; SRT=15–30 d; MLSS=3000–4500 mg/L; 沟深 4–5 m
- 适用: 中型市政厂
- 优点: 水深大占地省；表曝机单机服务面积大、维护少
- 缺点: 脱氮除磷能力一般（基础型）

### 变种: 卡鲁塞尔 2000 / 3000 | Carrousel 2000 / 3000

- 年份: 约1990s
- 差异点: 沟前增设厌氧/缺氧选择区（2000 型）或前置反硝化区+内回流（3000 型），实现生物脱氮除磷；DHV 与美国 EIMCO 开发
- 流程: 进水〔水〕 → 厌氧选择区〔水〕 → 缺氧区〔水〕 → Carrousel 好氧沟〔水〕 → 二沉池、出水〔水〕 → 混合液内回流至缺氧区〔回流〕 → RAS 回流 / WAS 排放〔回流〕
- 设计参数: SRT=15–25 d; MLSS=3500–5000 mg/L; 内回流比 100–300%
- 适用: 有 TN/TP 排放标准的中型市政厂
- 优点: 保留氧化沟稳定优点同时脱氮除磷
- 缺点: 内回流能耗；池体改造受限

### 变种: 奥贝尔氧化沟 | Orbal

- 年份: 约1970
- 差异点: 三条同心椭圆沟，污水自外沟→中沟→内沟串联流动，溶解氧沿程 0→1→2 mg/L 梯度分布，外沟同步硝化反硝化；转盘曝气机充氧。单一中文行业来源记 1970 年 Envirex 推出，待补强（存疑）
- 流程: 进水经格栅/沉砂〔水〕 → Orbal 外沟（缺氧/厌氧，转盘）〔水〕 → 中沟〔水〕 → 内沟（好氧）〔水〕 → 二沉池、消毒、出水〔水〕 → RAS 回流至外沟 / WAS 排放〔回流〕
- 设计参数: HRT=16–24 h; SRT=15–30 d; MLSS=3000–5000 mg/L; 外沟容积约占 50–60%
- 适用: 中型市政厂、脱氮要求较高场景
- 优点: 外沟反硝化节能（利用原水碳源）；氧梯度高、传氧效率好
- 缺点: 同心圆布置占地形状受限；转盘设备维护量大

### 变种: 交替工作式氧化沟（D 型/T 型/三沟式） | Alternating (DE, T-type, Tri-ditch)

- 年份: 约1970s
- 差异点: 双沟（DE）或三沟串联，边沟交替承担曝气与沉淀功能，省掉二沉池；转刷曝气；丹麦 Krüger 开发
- 流程: 进水〔水〕 → 沟 A（曝气）〔水〕 → 沟 B（沉淀出水）〔水〕 → 出水〔水〕 → 半周期切换曝气/沉淀功能〔回流〕 → 剩余污泥自沉淀沟排出〔泥〕
- 设计参数: HRT=16–24 h; SRT=15–30 d; MLSS=3000–4500 mg/L; 周期 4–8 h
- 适用: 中小市政厂，无二沉池一体化需求
- 优点: 省二沉池与回流系统；可时序脱氮
- 缺点: 设备利用率低（转刷闲置时段）；自控阀门多

### 变种: 一体化氧化沟 | Integrated Oxidation Ditch (ICC)

- 年份: 约1980s
- 差异点: 沉淀区（船式/侧沟式/内置斜板）置于沟内，泥水在沟内分离回流，真正单构筑物
- 流程: 进水经格栅/沉砂〔水〕 → 一体化氧化沟（曝气循环+内置沉淀区）〔水〕 → 出水〔水〕 → 污泥自动回流，WAS 排放〔回流〕
- 设计参数: HRT=16–24 h; SRT=15–30 d; MLSS=3000–5000 mg/L
- 适用: 小型市政与工业点源
- 优点: 占地最省；流程最短
- 缺点: 内置沉淀区水力条件苛刻、出水 SS 波动；大型化困难
