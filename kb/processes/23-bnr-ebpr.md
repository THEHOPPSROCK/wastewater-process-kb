# 23. 同步脱氮除磷工艺（A²/O 系/BNR/EBPR） | Combined N & P Removal (BNR/EBPR) Processes

- 诞生: 1976（五段 Phoredox/改良 Bardenpho）
- 成熟度: 成熟主流
- 族/周期: 悬浮生长生物 / 1970s
- 定位: 单污泥系统内同步实现碳、氮、磷去除的工艺族，用聚磷菌「厌氧释磷-好氧超量吸磷」取代化学除磷
- 简介: 厌氧段聚磷菌（PAO）释磷并储存 VFA 为 PHA；缺氧段反硝化；好氧段完成碳化、硝化与过量吸磷，通过排放富磷剩余污泥除磷（污泥含磷量可达 3–7%）。1976 年 Barnard 在 Bardenpho 前加厌氧段形成五段 Phoredox/改良 Bardenpho（部分文献记 Barnard 1974 提出 Phoredox 概念），1980 年 Rabinowitz & Marais 三段化为传统 A²/O、同年开普敦大学提出 UCT，1987 年美国 CH2M Hill 推出 VIP。各变种的本质区别在于三条回流（污泥回流 S、好氧内回流 A、缺氧内回流 R）的落点安排，目标是让尽量少的硝酸盐进入厌氧段。近年的 Dephanox、BCFS、S2EBPR 等进一步引入反硝化聚磷菌（DPAO，「一碳两用」）与侧流发酵造碳源，破解低碳氮比难题。2015 年起出现的 AOA 工艺（缺氧段整体后置、取消硝化液内回流）是这一矛盾的另一种解法，已单列为独立大类。

### 变种: 传统 A²/O（三段 Phoredox） | Anaerobic-Anoxic-Oxic (A²/O)

- 年份: 1980
- 差异点: 五段 Bardenpho 简化为厌氧-缺氧-好氧三段，污泥回流直接进厌氧段；流程最短的总氮总磷同步去除工艺（Rabinowitz & Marais）
- 流程: 进水经初沉〔水〕 → 厌氧池（释磷）〔水〕 → 缺氧池（反硝化）〔水〕 → 好氧池（碳化+硝化+吸磷）〔水〕 → 二沉池、消毒、出水〔水〕 → 内回流：好氧至缺氧（100–300%）；RAS 至厌氧池〔回流〕 → WAS 富磷污泥至污泥线〔泥〕
- 设计参数: 总 HRT=7–14 h（厌氧 1–2 h、缺氧 2–3 h、好氧 4–8 h）; SRT=10–20 d; MLSS=2500–4000 mg/L; SVI<100 mL/g; 污泥含磷 2.5% 以上
- 适用: 出水 TN≤15 mg/L、TP≤1 mg/L 的市政污水厂（中国主流工艺）
- 优点: 流程最简、HRT 最短；不易污泥膨胀；剩余污泥富磷可作肥料
- 缺点: 回流污泥携带硝酸盐进入厌氧段抑制释磷；脱氮与除磷对泥龄需求矛盾

### 变种: 五段 Phoredox/改良 Bardenpho | Five-Stage Phoredox / Modified Bardenpho

- 年份: 1976（部分文献记 Barnard 1974 提出概念）
- 差异点: 在四段 Bardenpho 首端加厌氧池，脱氮与除磷能力均为族内最强
- 流程: 进水〔水〕 → 厌氧池〔水〕 → 一级缺氧池〔水〕 → 一级好氧池〔水〕 → 二级缺氧池〔水〕 → 再曝气池〔水〕 → 二沉池、出水〔水〕 → 内回流：一级好氧至一级缺氧；RAS 至厌氧池〔回流〕
- 设计参数: 总 HRT=14–20 h; SRT=15–25 d; 内回流 200–400%; TN 去除 >90%; TP 可达 <1 mg/L
- 适用: 出水要求极严（TN<10、TP<0.5 mg/L）的大型厂
- 优点: 氮磷去除深度最大；无需外加碳源即可深度脱氮
- 缺点: 池容与能耗最大；运行管理复杂

### 变种: UCT 工艺 | University of Cape Town Process (UCT)

- 年份: 1980
- 差异点: 污泥回流至缺氧段而非厌氧段，另设缺氧→厌氧混合液回流（R 回流），隔绝硝酸盐进入厌氧段，保护释磷。年份裁定：1980（Rabinowitz 硕士论文、Rabinowitz & Marais；Ekama et al. 1983 系统发表）；前沿草稿所记 1976 不采信
- 流程: 进水〔水〕 → 厌氧池〔水〕 → 缺氧池〔水〕 → 好氧池〔水〕 → 二沉池、出水〔水〕 → 回流 A：好氧至缺氧；回流 R：缺氧至厌氧；RAS：二沉池至缺氧池〔回流〕
- 设计参数: 总 HRT=10–16 h; SRT=15–25 d; A 回流 100–300%; R 回流 100–200%; S 回流 50–100%
- 适用: 进水 C/N 偏低、需强化除磷的市政厂
- 优点: 厌氧段几乎无硝酸盐干扰；除磷稳定
- 缺点: 三条回流管线、运行调控复杂；A 回流需精确控制避免缺氧段过载

### 变种: 改良 UCT（MUCT） | Modified UCT (MUCT)

- 年份: 约1980s 中
- 差异点: 缺氧段一分为二：第一缺氧段专受 RAS 并反硝化后再回流厌氧段；第二缺氧段接受好氧内回流，免除 UCT 对 A 回流的精细控制
- 流程: 进水〔水〕 → 厌氧池〔水〕 → 缺氧段 1（受 RAS，反硝化）〔水〕 → 缺氧段 2（受内回流）〔水〕 → 好氧池〔水〕 → 二沉池、出水〔水〕 → 回流：缺氧段 1 至厌氧；好氧至缺氧段 2〔回流〕
- 设计参数: 总 HRT=10–16 h; SRT=15–25 d; 缺氧段 1 约占缺氧总泥量 10%
- 适用: 低 C/N 污水、运行控制要求简化的除磷场景
- 优点: 运行控制简化；厌氧段保护可靠
- 缺点: 回流系统更多；整体脱氮能力略降

### 变种: VIP 工艺 | Virginia Initiative Plant Process (VIP)

- 年份: 1987
- 差异点: 类 UCT 构型但按高负荷（SRT≤10 d）运行，各区段用隔板分成 2 个以上完全混合小室串联，提高前端反应速率；美国 CH2M Hill（Daigger 等），弗吉尼亚 HRSD
- 流程: 进水〔水〕 → 厌氧段（2 格串联）〔水〕 → 缺氧段（2 格串联）〔水〕 → 好氧段〔水〕 → 二沉池、出水〔水〕 → 回流同 UCT（S 至缺氧、R 缺氧至厌氧、A 好氧至缺氧）〔回流〕
- 设计参数: 总 HRT=6–10 h; SRT=5–10 d; MLSS=2000–3000 mg/L; 污泥产率较高（短泥龄）
- 适用: 北美高负荷市政厂；用地紧张改造
- 优点: 池容小；短泥龄除磷效率高（净产泥率大则排磷多）
- 缺点: 短泥龄下低温硝化风险；污泥产量较大

### 变种: 约翰内斯堡工艺 JHB | Johannesburg Process (JHB)

- 年份: 约1980s
- 差异点: 回流污泥先经一个独立的小型缺氧池（内源反硝化脱除硝酸盐）再进入厌氧段，厌氧段保护最彻底；约翰内斯堡 Northern Works 厂改造中形成
- 流程: 进水〔水〕 → 厌氧池〔水〕 → 缺氧池〔水〕 → 好氧池〔水〕 → 二沉池、出水〔水〕 → RAS 先经回流污泥缺氧池脱硝再入厌氧池；内回流好氧至缺氧〔回流〕
- 设计参数: 总 HRT=10–16 h; 污泥脱硝池 HRT≈1 h; SRT=15–25 d
- 适用: 进水 C/N 低、出水 TP 要求严格的场景
- 优点: 厌氧段硝酸盐最少、释磷最充分
- 缺点: 多一座脱硝池；可反硝化的缺氧容积被分走，脱氮率略降

### 变种: 倒置 A²/O | Inverted A²/O (Anoxic-Anaerobic-Oxic)

- 年份: 1981–1990（试验）/1990s（中国推广）
- 差异点: 缺氧段置于厌氧段之前，取消混合液内回流，回流污泥与进水（部分）先入缺氧段耗尽硝酸盐，再进厌氧段释磷；美国德州大学阿灵顿分校 Qasim 等试验，1990s 中国同济大学高廷耀、张波等推广命名
- 流程: 进水（部分直入缺氧、部分直入厌氧）〔水〕 → 缺氧池（受 RAS，反硝化）〔水〕 → 厌氧池（释磷）〔水〕 → 好氧池〔水〕 → 二沉池、出水〔水〕 → 污泥回流 100–200%（合一回流）；无内回流〔回流〕
- 设计参数: 缺氧 HRT=1–3 h; 总 HRT=8–14 h; SRT=10–20 d; 污泥回流 100–200%
- 适用: 碳源紧张、以脱氮为主兼顾除磷的市政厂（中国多个改造案例）
- 优点: 碳源优先满足反硝化，脱氮能力强；取消内回流、流程简化
- 缺点: 厌氧段优质碳源少，除磷效率不如常规 A²/O；大回流加重二沉池负荷

### 变种: 反硝化除磷（双污泥）Dephanox | Dephanox

- 年份: 约1996
- 差异点: 硝化菌与反硝化聚磷菌分置两套污泥系统：硝化在固定膜/悬浮硝化池完成，DPAO 污泥在「厌氧-缺氧」两池间切换，缺氧池同时完成脱氮与吸磷；意大利 Bortone 等提出
- 流程: 厌氧池（释磷、吸收 VFA）〔水〕 → 快速沉淀池Ⅰ〔水〕 → 上清液去硝化池（固定膜硝化）〔水〕 → 硝化液与厌氧污泥在缺氧池混合（DPAO 吸磷+脱氮）〔水〕 → 沉淀池Ⅱ、出水〔水〕 → 两套污泥系统独立回流〔回流〕
- 设计参数: 缺氧吸磷速率约为好氧的 60–70%; 碳源需求较传统工艺省约 30–50%; SRT（硝化段）15–30 d
- 适用: 低 C/N 污水、碳源极度紧张且要求双低的场景
- 优点: 一碳两用，碳源与曝气双节省
- 缺点: 双污泥系统构筑物多、控制复杂；工程业绩少

### 变种: BCFS 生物化学联合除磷 | BCFS (Biological-Chemical P & N Removal)

- 年份: 约1998
- 差异点: UCT 的「分点回流」精细化版：厌氧-选择-缺氧-好氧-混合五段+化学辅助除磷沉淀池，最大化 DPAO 作用并留化学兜底；荷兰 TU Delft van Loosdrecht 等
- 流程: 进水〔水〕 → 厌氧池〔水〕 → 接触选择池〔水〕 → 缺氧池〔水〕 → 好氧池、混合池〔水〕 → 二沉池、出水〔水〕 → 化学沉淀单元（铁盐）侧流/尾水兜底〔辅助〕 → 污泥回流分级（缺氧至厌氧、二沉至缺氧）〔回流〕
- 设计参数: 出水 TP<0.2 mg/L 可达; SRT=10–20 d; 化学投加量仅为纯化学除磷的 20–40%
- 适用: 荷兰等 TP<0.2–0.3 mg/L 极严排放场景
- 优点: 生物+化学双保险，出水极限低
- 缺点: 流程长、自控要求高；荷兰本地化经验依赖强

### 变种: 侧流强化生物除磷 S2EBPR | Side-Stream EBPR (S2EBPR)

- 年份: 约2010s
- 差异点: 将 10–30% 回流污泥引入侧流厌氧发酵罐（HRT 12–48 h），原位产 VFA 富集 PAO 后回主流厌氧区；显著提升碳源不足厂区的除磷稳定性；美国 Barnard 等推动工程化
- 流程: 主流：厌氧→缺氧→好氧→二沉→出水〔水〕 → 回流污泥支路（10–30% RAS）〔回流〕 → 侧流发酵罐（厌氧水解产酸）〔泥〕 → 发酵污泥回主流厌氧池〔回流〕 → 剩余污泥去污泥线〔泥〕
- 设计参数: 侧流比 10–30% RAS; 侧流 HRT 12–48 h; 出水 TP 可稳定 <0.5 mg/L（视进水）
- 适用: 低碳源既有 EBPR 厂提标；冬季除磷不稳场景
- 优点: 就地造碳、少加药；改造量小
- 缺点: 侧流罐释磷风险需控制；长期微生物机制仍在研究

### 变种: 内碳源发酵与外加碳源精细投加 | Internal Carbon / External Carbon Optimization

- 年份: 约2000s 起系统化
- 差异点: 用初沉污泥在线发酵罐产 VFA 替代商品碳源；或以在线 NO₃⁻/NH₄⁺ 传感器闭环投加甲醇/乙酸钠/甘油，碳源成本降低 20–50%
- 流程: 初沉污泥〔泥〕 → 发酵罐（HRT 1–3 d，产 VFA）〔泥〕 → 发酵上清液投加至缺氧池〔辅助〕 → 主流脱氮〔水〕 → 发酵污泥去消化线〔泥〕 → 外加碳源按传感器闭环计量〔辅助〕
- 设计参数: 发酵罐 VFA 产率 0.1–0.3 kgVFA/kgVSS; 外加碳源 C/N 3–5 gCOD/gN; 甲醇投加典型 2–3 kgCOD/kgNO₃⁻-N
- 适用: 一切需反硝化碳源的厂；碳源费用高的深度脱氮厂
- 优点: 碳源自给、药耗下降；减排与降本双赢
- 缺点: 发酵罐占地与臭气管理；传感器维护要求高
