# 35. 新兴物化与电化学工艺 | Emerging Physicochemical & Electrochemical Processes

- 诞生: 1999（磁混凝 CoMag，Cambridge Water Technologies/MIT 概念）/ 2007 首座（Concord, MA）
- 成熟度: 商业化初期
- 族/周期: 预处理物化 / 1990s
- 定位: 磁加载、电混凝、硫自养等小众但高增长的物化路线
- 简介: 本类汇集 20 世纪末以来商业化的一批物化/电化学工艺：磁加载混凝（CoMag/BioMag）以磁粉强化絮体沉降与回流，电混凝以牺牲阳极现场生成混凝剂，硫自养反硝化以单质硫为电子供体深度脱氮，铁碳微电解以原电池反应破环断链预处理难降解废水，PAC-MBR 耦合吸附与膜分离。多数用于提标、除磷、深度脱氮与工业预处理细分市场。
- 来源:
  - EPA lc-wastewater 报告
  - aquaenviro（Billerica 磁混凝案例）
  - wsimg CoMag 产品资料 PDF

共 6 个变种。

### 变种: 电混凝 | Electrocoagulation

- 年份: 19世纪末概念 / 约2000s复兴
- 差异点: 铝/铁牺牲阳极电解溶出金属离子现场生成混凝剂，兼气浮与氧化
- 流程: 进水〔水〕 → 电混凝反应器（极板）〔水〕 → 气浮/沉淀〔水〕 → 出水〔水〕
- 设计参数: 电流密度 10–50 A/m²; 极板消耗 0.05–0.3 kg Al/m³
- 适用: 工业废水除油除浊、除磷、垃圾渗滤液预处理
- 优点: 无需加药；污泥量少；启动快
- 缺点: 电耗与极板成本；钝化需倒极/酸洗；规模放大受限

### 变种: CoMag 磁加载混凝 | CoMag Ballasted Flocculation

- 年份: 1999 / 2007 首座
- 差异点: 投加磁粉（Fe₃O₄）为絮体核，沉淀快、可磁回收循环；2007 年首座 Concord, MA
- 流程: 进水〔水〕 → 混凝+磁粉投加〔辅助〕 → 絮凝池〔水〕 → 高速沉淀（斜板）〔水〕 → 磁粉回收〔回流〕
- 设计参数: 磁粉 5–10 g/L; 表面负荷 20–40 m/h; TP 出水 <0.05 mg/L
- 适用: 深度除磷、CSO 溢流处理、提标扩容
- 优点: 占地省 70%；出水 TP 极低；抗冲击
- 缺点: 磁粉损耗需补充；药剂+磁粉双成本；依赖专有设备

### 变种: BioMag 生物磁加载 | BioMag

- 年份: 约2000s末
- 差异点: 磁粉直接投加进活性污泥曝气池，强化二沉池沉降与污泥浓度
- 流程: 进水〔水〕 → 曝气池（含磁粉污泥）〔水〕 → 二沉池〔水〕 → 出水〔水〕 → 磁粉回收回流〔回流〕
- 设计参数: MLSS 可达 8000–10000 mg/L; SVI 显著降低
- 适用: 既有活性污泥厂原位扩容
- 优点: 不改土建即可扩容；沉降性能大幅提升
- 缺点: 磁粉回收系统复杂；长期运行数据有限

### 变种: 硫自养反硝化 | Sulfur Autotrophic Denitrification

- 年份: 约1980s
- 差异点: 以单质硫/硫代硫酸钠为电子供体，自养菌将 NO₃⁻ 还原为 N₂，无需有机碳源
- 流程: 二级出水（NO₃⁻）〔水〕 → 硫填料滤床〔水〕 → 出水〔水〕
- 设计参数: 硫粒 2–6 mm; 空床停留 0.5–2 h; 出水 NO₃⁻-N <1 mg/L
- 适用: 深度脱氮提标、饮用水脱硝
- 优点: 无碳源投加；污泥产量低；运行费用省
- 缺点: 产酸耗碱度；出水硫酸盐升高；滤床板结需反洗

### 变种: 铁碳微电解 | Iron-Carbon Micro-electrolysis

- 年份: 约1970s原理 / 1990s中国规模化
- 差异点: 铁屑+活性炭构成原电池，微电解产生新生态 [H] 与 Fe²⁺ 破环断链、混凝共沉淀
- 流程: 难降解工业废水〔水〕 → 铁碳微电解床〔水〕 → 中和絮凝〔水〕 → （接生化）〔水〕
- 设计参数: pH 3–4 进水; 停留 0.5–2 h; Fe:C 体积比 1:1
- 适用: 印染、制药、化工等难降解废水预处理（中国应用最广）
- 优点: 提高可生化性 B/C 比；材料廉价；兼具脱色
- 缺点: 铁泥量大；填料板结钝化；pH 调节药剂费

### 变种: PAC-MBR 粉末炭膜生物反应器 | PAC-MBR

- 年份: 约1990s–2000s
- 差异点: MBR 池内投加粉末活性炭，吸附难降解有机物与微污染物，膜截留炭粉
- 流程: 进水〔水〕 → 曝气池+PAC 投加〔辅助〕 → 膜分离〔辅助〕 → 出水〔水〕
- 设计参数: PAC 浓度 1–10 g/L; 炭随剩余污泥排出
- 适用: 微污染物去除、工业废水深度处理
- 优点: 吸附+生化+膜三重屏障；出水水质极高
- 缺点: 炭消耗成本高；膜污染风险叠加
