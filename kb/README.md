# 环境工程（污水处理）工艺知识库

## 总览

本知识库覆盖污水处理领域自 1840s 至今的主要工艺，共 **37 个大类、171 个变种**。其中 36 大类/165 变种由两份草稿（`research/mature_processes.md`：成熟工艺 20 大类/84 变种；`research/frontier_processes.md`：前沿工艺 17 大类/87 变种）交叉审核、合并去重、年份核实后整合而成；**大类 37（AOA 厌氧-好氧-缺氧工艺）为 2026-09-18 专项文献增补**，来源与依据见下文「后续增补记录」。

- 主数据源：`site/data/processes.json`（结构化 JSON，37 大类/171 变种，含诞生年、族、成熟度、简介、来源与每个变种的流程/参数/优缺点）。
- 可读文档：`kb/processes/NN-{slug}.md` 共 37 个文件，由 `build_kb.py` 从 JSON 一键生成（`python3 build_kb.py`），**修改请改 JSON 后重新生成，不要直接改 md**。
- 每个大类一个文件，序号 01–37 按**诞生年升序**排列。

## 字段与图例

每个大类文件包含：诞生年（year_label，部分含双注口径）、成熟度、族/周期、定位、简介、来源，以及每个变种的：年份、差异点、流程、设计参数、适用、优点、缺点。

**流程步骤线型图例**（步骤后缀标注介质类型）：

- `〔水〕` 水线（污水主流）
- `〔泥〕` 泥线（污泥/固体）
- `〔回流〕` 回流线
- `〔辅助〕` 辅助线（投药、供气、碳源、产物输出等）

**成熟度取值**：成熟经典（历史工艺，仍在用或已退居小众）/ 成熟主流（当前工程主流）/ 商业化初期（已有商业案例但未普及）/ 前沿研发（实验室/中试为主）。

**era 周期取值**：`1840s-1870s`、`1880-1909`、`1910s-1940s`、`1950s-1960s`、`1970s`、`1980s`、`1990s`、`2000s`、`2010s-至今`。前两个 19 世纪段是对常规分期的扩展，用于容纳土地处理（1840）与化粪池/双层沉淀池（1860）。

**重要提示**：所有设计参数为文献与厂商资料中的**典型范围**，仅作快速参考，工程设计必须按项目水质、规范与厂商数据复核。

## 后续增补记录

### 2026-09-18 · 新增大类 37：厌氧-好氧-缺氧工艺（AOA，`aoa`）

**增补理由**：AOA 是把传统 A²/O「厌氧—缺氧—好氧」重排为「厌氧—好氧—缺氧」的结构性改进，其技术源头、功能菌机理（PAOs/GAOs 胞内储碳 → 后置内源反硝化）与工程体系（BEAOA、12 座污水厂）均已成型，且 2025 年《给水排水》为其出了专栏，具备独立成类的条件，故未并入大类 23（bnr-ebpr），单列为大类 37，并在大类 23 的简介中互注交叉引用。

**关键事实与来源**：

1. **技术源头**：北京工业大学彭永臻院士团队。2012 年处理垃圾渗滤液时发现后置缺氧区可强化内源反硝化脱氮（贡献 25% TN 去除）；2014 年简化为 AOA 运行模式；2015 年建立污泥双回流 AOA 系统（SDR-AOA），进水 C/N=3 时出水 TIN 约 2 mg/L。2018 年首次公开技术。
2. **机理**：厌氧段储碳（PHA/糖原）并释磷、好氧段硝化与好氧吸磷、后置缺氧段内源反硝化与反硝化除磷，即「一碳两用」。三项判别特征：无好氧→缺氧硝化液内回流；好氧 HRT 远小于缺氧区；碳源全部来自原水。
3. **代表性论文**：Water Research 223:118991（2022，首座百吨级中试，C/N=5、TN 3.60±1.55、TP 0.24±0.13 mg/L）；Chemosphere 252:126624（2020，SDR-AOA，C/N=2.67 时 NRE 97.7%）；CEJ 335:330（2018，SDR-AOA 短程硝化，TN 去除 91.40%→95.60%）；Water Research（2023，AOA-SDR 集成短程硝化+内源反硝化+亚硝型反硝化除磷，出水 TIN 1.8、PO₄³-P 0.3 mg/L）。
4. **工程化**：2019 年北控水务与北工大在海口建成国内外首座 AOA 中试（100 m³/d）；2020 年万吨级生产验证；2021 年首座 3 万 m³/d 污水厂投运；2022 年发布 BEAOA 技术产品；至 2025 年全国已有 12 座新建/改造污水厂采用（深圳、中山、**东莞**、贵阳、宜兴、济南、洛阳等）。深圳滨河水质净化厂 30 万 m³/d 生产线二沉池出水 TN 日均 2.19 mg/L、脱氮率 94.8%，较同厂 AAO 电耗降 15.1%、药剂成本降 91.2%、污泥处理处置成本降 17.1%。
5. **综述**：高歆婕, 彭永臻. 厌氧-好氧-缺氧(AOA)污水处理工艺的原理、发展与应用[J]. 给水排水, 2025, 51(10): 27-35.（该文获第十六届「威派格杯」《给水排水》优秀论文唯一特等奖）

**6 个变种**：污泥双回流 AOA（SDR-AOA，初代模型）；单污泥回流 AOA；AOAO（后置好氧型）；后置内源反硝化除磷 AOA（好氧区投载体，post-EDPR）；浓缩污泥双回流 AOA；AOA 耦合短程硝化-厌氧氨氧化（PN/A-AOA）。

**待补方向**：超越污泥 AOA（厌氧→缺氧旁路）、AOA-MBBR、SBR-AOA（分段进水/间歇曝气）等迭代形式本次未单列变种，已在大类简介中提及；除磷稳定性、低温调控与 N₂O/CH₄ 温室气体评估尚无统一定论。

## 使用说明

1. **查工艺**：按上表序号或族找到 `kb/processes/NN-slug.md`，或直接搜 JSON。
2. **改内容**：编辑 `site/data/processes.json` 后运行 `python3 build_kb.py` 重新生成全部 md；若要同步到网页，还需运行 `python3 site/tools/embed_data.py` 重新生成 `site/data/processes.js`（顺序：改 JSON → embed_data.py → build_kb.py）。md 与 js 均为生成物，不应手改（会被覆盖）。
3. **新增大类/变种**（保持按诞生年排序与序号对应关系），完整清单：
   1. 编辑 `site/data/processes.json`，在 `categories` 数组**按 `year` 升序的位置**插入新大类（大类序号 = 数组下标 + 1，`build_kb.py` 按数组顺序编号）。
   2. 运行 `python3 site/tools/embed_data.py`（同步网页）→ 运行 `python3 build_kb.py`（同步 Markdown）。
   3. 更新本文件：总览里的「N 个大类、M 个变种」、分类树表格、按族汇总、并在「后续增补记录」写清增补理由与来源。
   4. 更新根目录 `README-使用说明.md` 的「数据规模」与目录结构描述。
   5. 更新 `site/js/app.js` 顶部的 `EXPECTED = { cats, variants }` 基准值。
   6. 验证：打开站点，浏览器 console 应打印 `[校验] 渲染卡片数 … ✔ 一致` 与 `变种总数 … ✔`；也可用 jsdom 跑一次无头渲染检查。
4. **引用**：每个大类与变种均带来源列表；凡「交叉审核结论摘要」中列出的双注年份，引用时应同时给出两种口径。
